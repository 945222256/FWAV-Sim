# 计算流体力学线求解器选型论证（I-119）

## 结论

选定 OpenFOAM（ESI 发行版 v2506）作为本线唯一流场求解工具，已在
Windows 的 Linux 子系统环境（Ubuntu 24.04）内安装建成并冒烟通过。
SU2 不采用。

## 候选与事实依据

两条候选都是开源、非结构有限体积法求解器，均可解不可压缩与可压缩
流场。差异集中在大幅值刚体运动的网格技术、安装通道与文献复现先例。

### 大幅值运动能力（决定性差异）

扑翼绕流的翼面运动是平移叠加正负四十五度量级的俯仰，翼面扫过区域
远超自身弦长。这类问题的通行解法有三条：

1. 滑移界面（任意网格接口，OpenFOAM 中称循环 AMI）：翼面装在
   圆柱形网格区内，圆柱区整体刚体转动，与外围静态网格沿圆形界面
   滑移插值耦合。网格永不变形，转动幅值无限制。
2. 重叠网格（嵌套网格，OpenFOAM 中称 overset）：翼面网格块自由
   浮动在背景网格上，挖洞插值耦合。平移与转动幅值均无限制。
3. 网格变形（弹簧法、逆距离加权法、径向基函数法）：固定网格拓扑，
   结点随翼面位移重排。大幅值转动时前缘附近单元被剪切成劣质单元，
   品质随幅值恶化，无构造级保证。

OpenFOAM 两条路线都内置：循环 AMI 与 overset 均为发行版原生功能，
本基准二算例即用循环 AMI 加表驱动刚体转动建成。SU2 发行版的运动
网格以变形类方法为主（SU2_DEF 模块含径向基函数、弹簧、逆距离加权
三种），重叠网格在发行版内不成熟，二零一五年斯坦福团队的公开报告
（AIAA 2015-3428）为把外部重叠网格装配器 OPERA 与 SU2 对接而作，
其立论起点正是纯变形网格在大幅值翼面运动下失效。扑翼工况恰好落在
该失效区。

### 安装与运行通道

OpenFOAM 由 ESI 官方仓库提供 Ubuntu 二十四点零四的安装包，一条
apt 命令装成，与 Windows 的 Linux 子系统环境直配；本次实装含运行
时、教程两包，冒烟算例（顶盖驱动方腔流）全流程通过。SU2 官方不提
供 Ubuntu 安装包，需下载二进制或源码编译，维护成本高一条路。

### 文献复现先例

二维扑翼悬停基准（Wang、Birch、Dickinson 二零零四年《实验生物学
期刊》二零七卷四四九页）的复现文献中，有限体积类复现多基于
OpenFOAM 或其同族开源码；SU2 侧以谐波平衡法解周期流场为主，与
时域逐拍力时程复现的口径不同。

## 不采用 SU2 的理由汇总

大幅值刚体运动在 SU2 发行版内缺少成熟的非变形路线；安装通道劣于
apt 直装；时域复现先例少于 OpenFOAM。谐波平衡法对周期性扑翼有
吸引力，但基准验证阶段需要的是与文献同口径的时域解，谐波平衡属
后期加速选项，不构成选型理由。

## 环境与版本记录

- 宿主：Windows 的 Linux 子系统，Ubuntu 24.04.2，三十二逻辑核，
  四十五吉字节内存。
- 求解器：openfoam2506（二五零六版，二六年零一月二十七日构建），
  来源 dl.openfoam.com 的 apt 仓库。
- 环境故障与修复：子系统的域名解析服务没有上游域名服务器（域内
  作用域为空），apt 无法解析软件源；以静态解析配置（阿里、腾讯、
  谷歌三域名服务器）替换原符号链接后恢复。此修复仅动子系统内
  /etc/resolv.conf 一个文件。
- 冒烟证据：教程方腔流算例从建网格到求解全程无错，日志见
  cfd/results/smoke/。
