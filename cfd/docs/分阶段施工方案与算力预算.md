# 计算流体力学线分阶段施工方案与算力预算（I-119 交付物）

## 目标回顾

为七百克及更大构型重建气动系数表并给出误差范围，替换现行的平板
理论公式与仅在当前翼形速度范围内有效的台架系数。本文件给路线、
各阶段验收口径与算力预算。预算的每格每步成本与并行效率全部来自
本次预研的实测，不作无依据外推。

## 实测成本基线（本次预研，本机三十二逻辑核）

- 单核单格每步耗时约一点五乘十的负六次方秒（一万一千五百二十格
  的定常扫掠单案五千一百步八十九秒反推；细网格与平板案一致）。
- 定常二维扫掠单案（一万一千五百二十格、十对流时间）：椭圆剖面
  约九十至一百三十核秒；端圆平板剖面因涡脱落约五百三十核秒。
- 二维扑翼单案（一万四千七百二十格、五拍二十无量纲时间，含任意
  网格接口滑移与动网格）：约两千一百至六千六百核秒，相位差越
  大越慢（转翼端速度更高、时间步受库朗数压得更细）。
- 上述为单核串行计时；并行分解另计（二维算例规模小，本预研未
  分解）。

## 阶段划分

### 阶段一（本事项 I-119，已完成）：工具链建成与双基准验证

验收：开源求解器在 Linux 子系统内建成冒烟；平板法向力斜率与公开
发表值偏差两成内；公开扑翼算例三相位角平均升阻力系数偏差两成内。
结果见基准一、基准二报告。

### 阶段二：二维系数表重建（前飞剖面族）

内容：对项目实际使用的剖面族（平板与现翼形近似剖面）做攻角乘
雷诺数乘厚度的定常扫掠，产出二维法向力、切向力、俯仰力矩系数表
及网格收敛误差栏。雷诺数覆盖当前构型巡航与七百克构型预期区间
（约一千至五万）。雷诺数高于一万区间需先做十乘十的小验证（层流
对涡粘模型的对照，择一并登记口径）。

规模与预算：约十五攻角乘四雷诺数乘二剖面共一百二十案，每案三百
至一千核秒（高雷诺数脱落更强取上限），合计约十至三十三核时，
本机数小时。风险低。

### 阶段三：三维单翼扑动验证（对台架实测）

首项（机主二零二六年十月零九日令）：悬停扑翼基准的加密复验——
周向二百五十六、径向六十四网格加八拍时长重跑三相位角，把超前与
滞后两相位角复验到与发表计算值两成以内；该项未过线前不放量跑
后续三维工况。

内容：把任意网格接口动网格方案从二维推广到三维单翼（旋转拍动加
俯仰），先复现机械翼台架的已发表系数（项目已有台架实测数据可对
表），再跑项目翼的数个代表性工况。网格生成器需扩展三维（或改用
切割网格路线，二选一，届时按小时级试探定案）。

规模与预算：单翼网格约一百五十万至三百万格；每案步数约六万
（十拍以上）；按实测每格每步成本，每案约七十五核时，十六核并行
约五小时一案。验证加代表性工况共八至十二案，约六百至九百核时，
本机十六核连跑约两至三天。中风险项：三维接口网格质量与三维拍动
的数值稳定性（二维阶段已定位稳定组合：外迭代两轮加关动量预测，
三维沿用并复核）。

### 阶段四：七百克构型系数表重建与误差范围

内容：七百克构型的翼几何与预期波形族，做波形乘前飞速度乘攻角的
扫掠，产出三维系数表（法向力、切向力、俯仰力矩、展向分布）加
每格的误差范围（网格收敛级差与重复工况散布）。产出物为版本化
系数库文件，经参数登记库的既有通道移交（登记库属三线独占区，
本线只交文件不动库）。

规模与预算：三十至六十案乘每案七十五核时，约两千三百至四千五百
核时；本机三十二核满载连跑约三至六天；若压到一百五十万格一档，
减半。高价值高成本，建议单独立项排期，先出三案试点定网格档位
再放量。

## 已知风险与对策登记

一、任意网格接口两侧环网格的周向分布必须配对（本预研实证：不
配对时逐步插值扰动喂出对称位形的反对称压力模态，力曲线逐步翻
转直至发散；配对加稳定组合后消失）。三维阶段网格生成器按此
约束设计。

二、表格驱动六自由度运动的旋转表单位是度不是弧度（本预研标定
实验实证，四十五度表值实测精确得四十五点零零零度）。运动表
生成器已按度输出并加注释。

三、雷诺数一万以上二维扫掠存在转捩模型选择问题，阶段二开工前
做小验证定口径，不在本预算外扩。

四、三维算例若任意网格接口稳定性不达验收，后备路线是切割网格
（重叠网格），求解器发行版原生带该功能，代价是插值误差栏要
另立一格。
