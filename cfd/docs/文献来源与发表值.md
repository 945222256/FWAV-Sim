# 基准算例文献来源与公开发表值（I-119）

本文件登记两个基准算例引用的全部公开数值及其出处，作为偏差判定的
对照原点。原文副本存于 cfd/_literature/。

## 基准一：平板法向力斜率（二维定常平移）

### 对照原点：Wang、Birch、Dickinson（2004）

出处：Z. J. Wang, J. M. Birch, M. H. Dickinson, "Unsteady forces
and flows in low Reynolds number hovering flight: two-dimensional
computations vs robotic wing experiments",《实验生物学期刊》
（Journal of Experimental Biology）二零七卷四四九至四六零页，
二零零四年。原文：cfd/_literature/wang_2004_jeb_hovering2d.pdf。

其二维计算的准定常力系数拟合式（原文式十四、十五，由同一剖面的
定常平移计算拟合，力在起动后无量纲时间二处取样）：

- 升力系数 C_L(α) = 1.2 · sin(2α)
- 阻力系数 C_D(α) = 1.4 − cos(2α)

由此导出的翼面法向与切向系数（α 自弦线起量）：

- C_N(α) = C_L cos α + C_D sin α
- C_T(α) = C_D cos α − C_L sin α

小攻角法向力斜率（本基准的主判据量）：

- 发表值 dC_N/dα|₀→₀.175rad = 2 × 1.2 + C_D(0) = 2.4 + 0.4
  = 2.8 / 弧度
- 峰值附近：C_N(45°) = 1.838，C_N(90°) = 2.4

剖面与雷诺数（同文计算方法节及其方法源 Wang 2000《流体力学期刊》
四四九卷一五三页）：

- 剖面：薄椭圆，厚度比 0.125（弦长百分之十二点五），来源
  cfd/_literature/wang_2000_jfm_flps.pdf 图一说明"厚度比取
  0.125"。
- 雷诺数：扑翼算例七十五至一百一十五；准定常拟合的定常平移源
  数据在其方法源文献为 Re=192。
- 取样协议：定常平移起动后 t = 2（弦长除以来流速度的无量纲时间）
  处读力，即"初次瞬态后的暂时平台"。

### 背景锚点（不作为过线判据，仅登记）

- 薄翼理论（无粘、附着流）：升力线斜率 2π = 6.28 / 弧度。
- 失速平板理论（von Kármán 与 Burgers，经 Wang 2004 式十六、
  十七转录）：C_L = π sin2α/(4 + π sinα)，C_D = π sin²α/(4 + π
  sinα)，小于实测值但形状正确。
- 三维旋转翼实验拟合（Sane 与 Dickinson 2001，《实验生物学期刊》
  二零四卷二六零七页；果实蝇机械翼，雷诺数百量级）：
  C_N = 3.4 sin(2.13α − 7.2°)，小攻角斜率 7.18 / 弧度；同族升力
  拟合 C_L = 0.225 + 1.58 sin(2.13α − 7.2°)、阻力拟合
  C_D = 1.92 − 1.55 cos(2.04α − 9.82°) 亦经 Wang 2004 式十二、
  十三转录。该值属三维旋转翼，与二维平移不可直接对表，登记为
  本项目力律现状的背景。

## 基准二：公开扑翼文献算例（二维悬停，Wang 2004 原工况）

### 运动学（原文"翼运动、参数选取与无量纲化"节，式十、十一）

- 平移：x(t) = (A₀/2) cos(2πft)，A₀/c = 2.8（端到端行程二点八
  弦长）。
- 俯仰：α(t) = α₀ + β sin(2πft + φ)，α₀ = π/2，β = π/4，
  f = 0.25。
- 相位差 φ 三个工况：π/4（超前翻转）、0（对称）、−π/4（滞后
  翻转）。
- 雷诺数 75（来流最大速度二点一九九弦长每无量纲时间，运动粘度
  零点零二九三二）。
- 剖面：同基准一，厚度比 0.125 薄椭圆。

### 发表的平均力系数（原文结果节，归一化为 0.5ρU²_rms·c，

U_rms = U_max/√2；水平力取绝对值再平均）

二维计算值（本基准的对照原点）：

| φ | 平均升力系数 C_L | 平均阻力系数 C_D |
|---|---|---|
| +45° | 1.10 | 1.36 |
| 0° | 0.82 | 1.44 |
| −45° | 0.19 | 1.21 |

机械翼实验值（原文同段，作背景）：

| φ | 平均升力系数 C_L（实验） |
|---|---|
| +45° | 0.93 |
| 0° | 0.86 |
| −45° | 0.38 |

幅值序列补充（φ=+45°，发表计算值）：A₀/c = 2.8、3.6、4.2、4.8
对应 C_L = 1.07、1.00、0.90、0.90 与 C_D = 1.36、1.34、1.24、
1.16（用于归一化口径的联合判定）。

### 归一化口径说明

二零零四年主文图注称力按"对应准定常力的最大值"归一化；同年同
作者的姊妹篇（Wang，《实验生物学期刊》二零七卷四一四八页，"悬停
中阻力的角色"，cfd/_literature/wang_2004b_role_of_drag.pdf）方法
节明确写"瞬时力按 0.5ρU²_rms·c 无量纲化、水平力取绝对值平均"。
本复现以姊妹篇口径为主标尺，两口径并报，用与归一化无关的比值
检验（三个相位角之间 C_L、C_D 的相对大小）先行判定复现质量。

## 判据表述

事项判据原文（I-119 关闭口径）："复现两个有公开答案的基准算例，
平板法向力斜率与公开发表值偏差在两成以内"。本线的执行定义：

- 基准一主量：小攻角（零至十度）法向力斜率，与发表值 2.8/弧度
  的偏差小于百分之二十为过。
- 基准二主量：三个相位角的平均升力、阻力系数，与发表计算值
  （上表）的偏差小于百分之二十为过。
