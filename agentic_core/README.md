# agentic_core：架构提取与范用化线领地

本目录是多智能体治理架构的提取产物与试点，属 L10 路线独占领地。

## 目录

- template/：可复用模板包，三层结构。registry 机制层、governance 制度文本层、board 触达层。零领域词，新项目拷走填空即运转。
- template/ADAPTATION_GUIDE.md：适配指南，实例化固定步骤。
- pilot_mot/：试点项目，视觉激光雷达多目标跟踪，只到治理骨架。判据脚本 verify_skeleton.py 是统一验收入口。
- scan_template_domain_words.py：模板零领域词验证工具。
- selftest_template.py：模板全链路自测工具，临时目录实例化并走完提交到关闭全程。
- TIMING.md：计时档案。

## 试点骨架的判据

python pilot_mot/verify_skeleton.py 八项全绿即骨架可用：路线表、看板命令、依赖图、领地自检、语言检查双向、首批事项在册、制度文本在位、看板服务可用。
