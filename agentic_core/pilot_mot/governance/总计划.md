# 总计划

本文件是项目唯一计划文件。完成以总账为准，不以汇报为准。

## 一、方向总述

三层结构：感知前端层负责传感器数据接入与目标检测；跟踪内核层负责数据关联与轨迹维持；数据与评测层负责数据集、评测指标与基准。骨架期三层只建到可运行骨架，不做真活。

## 二、当前卡点的定性

项目从零开始，尚无数据、无代码、无基准；第一优先是把治理骨架与三层代码骨架立起来。

## 四、完成机制纪律

1. 未登记的怀疑禁止出现在汇报里。
2. 关闭必须附证据链接与时间。
3. 每个事项有唯一负责人字段。
4. 汇报只允许引用事项编号，废止一切并行编号。
5. 产物登记进事项的证据栏。
6. 叙事文档只引编号不复制内容，消灭多份真值。
7. 汇报前必须先运行总账摘要。

## 五、计划修订

计划修订属于指挥部决定，修订走待审队列并留痕，旧版内容不删除只标记作废。
