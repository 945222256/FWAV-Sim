# 汇报标准

本文件定义施工汇报的固定格式与语言纪律。

## 一、格式：七段

1. 总账摘要：汇报开头必须先运行总账摘要命令并附上输出。
2. 本次认领：写明本次认领的事项编号与标题。
3. 结论：只允许三种固定措辞之一，判据通过、判据不通过、证据不足无法判定；没有证据的结论自动作废。
4. 证据：列出证据链接，至少一条。
5. 判据对照：逐条列出登记判据的原文与判定结果，每条标注过或不过。
6. 新发现：施工中发现的新问题只写待审编号，不展开叙述。
7. 阻塞与需求：写明当前阻塞与需要决策者提供的输入，没有则写无。

## 二、语言纪律

1. 结论先行，第一句话必须回答结果。
2. 离散实验数字禁止进入汇报句子，只允许公式、拟合关系、符号与排序；数值只进档案。
3. 每句话必须主语谓语宾语完整，禁止箭头链与算式片段充当句子。
4. 术语首次出现必须给出全称与定义。
5. 全文必须通过语言检查：python registry/langcheck.py --msg "汇报文本"。

## 三、强制点

状态词汇只允许四种：待认领、进行中、已关闭、卡住。架构师收到格式不符的汇报直接退回，不读内容。
