# 指挥部原则

## 一、项目的需求

用视觉与激光雷达两类传感器做工程可信的多目标跟踪：先骨架可信，再指标可测，后算法可选型。

## 二、原则

1. 不返工：一次做对，返工成本高于思考成本。
2. 判据先于数据：开工前先写完成判据，判据未写不许跑。
3. 不过早优化：先可信，再可测，后快速。
4. 确定性到底：同输入必须同输出，非确定性当作缺陷对待。
5. 单一可信来源：每类事实只有一个登记源，汇报不复制内容只引用编号。
6. 证据强制：没有证据的结论自动作废。
7. 机器可读：能进数据文件的事实不留在叙述里。
8. 书面出处优先于口头约定。

## 三、决定规则

决策者只保留两类决定：外部资源的取得与项目目标的变更。其余事项由指挥部按本文件原则自决，决定写进总账留痕，否决也留痕。

## 四、首批示范决定

- D-001：骨架期一律不做真活，一切事项的判据只到骨架可用；依据原则第二条。
- D-002：感知前端线与跟踪内核线的接口契约先于实现；依据原则第五条。
