# 触达层说明

本目录是触达层模板：本地只读看板。

## 已含组件

- server.py：只读看板服务，监听 127.0.0.1，默认端口 8890；端口可用环境变量 BOARD_PORT 覆盖。启动命令：python board/server.py。
- static/index.html：单文件看板页，十五秒自动刷新；路线分组、待审队列、事件流全部从 /api/state 动态渲染，本页不含任何项目专属数据。

## 纪律

看板只读不写。认领、关闭、批准等写操作一律走 registry 命令行工具，保证原子锁与证据强制不被绕过。

## 扩展占位（模板不含，按需自建）

- 云端托管：多会话异地共账时建云端服务，本地文件降级为只读缓存，写操作断网排队重放。
- 移动端触达：把看板页封装为移动端可访问的形态，只读优先。
- 派活工具：从总账生成派工简报并推送到各路会话的常驻机制。
