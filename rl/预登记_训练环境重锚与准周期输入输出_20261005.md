## 一、问题定义

训练环境 `rl/hover_env_v2.py` 存在两类缺陷。

第一类是构型漂移缺陷。该环境冻结在 2026-09-18 悬停辨识对应的
2.3 米翼展、700 克质量构型上，与现行飞机（0.6 米、215 克）不一致。
2026-10-05 排障 I-071 时实锤了一例同类漂移的实害：环境翼幅值 A0
从 `config.FlapKinematicsConfig.AMPLITUDE` 读取，主线提交 39cfb9a
（2026-09-26）把该配置从 35.0 度改为 17.73 度，环境实际拍幅随之漂移，
而逆映射数据集与前代复核仍锚定 35 度，预测与实际力旋量脱钩，闭环基线
15/16 在漂移后的代码树上不再复现（当日已把 A0 钉回 35 度作为应急，
出处：rl/hover_env_v2.py 头部注释与 I-071 施工记录）。教训的一般形式是：
训练环境的构型参数凡是跟随可变配置走的，迟早与数据集和辨识契约脱钩。

第二类是输入输出框架过时缺陷。现行观测（7 维逐控制步向量）与动作
（逐控制步绝对波形参数）产生于周期平均框架。理论框架已于 I-050 升级为
准周期框架：拍动按周期包络处理、停拍按事件处理（冻结出处：
ltv/hybrid_flight_spec.json，2026-10-02 冻结）。训练输入输出必须跟着
改，否则学习管线表达不了模态切换与拍内事件语义。

## 二、构型重锚方案

### 2.1 参数来源唯一化

训练环境的构型参数此后从参数登记库（params_registry）读取现行值，
不再写死、不再跟随 `config/sim_config.py`。读取入口唯一：
`rl/env_config_source.py` 的 `current_config()` 函数。构造级保证：
登记库缺键时立刻抛出带键名的错误退出，不提供任何静默默认值
（对应机主"构造级保证拒收装门"的既定规则）。

读取键与用途对照表：

| 登记库键 | 现行值 | 用途 |
|---|---|---|
| vehicle.mass.total | 0.215 kg | 基准质量，域随机化中心值 |
| aero.geometry.span | 0.32 m | 气动模型翼展 |
| aero.geometry.root_chord | 0.2 m | 翼根弦长 |
| aero.geometry.tip_chord | 0.14 m | 翼尖弦长 |
| vehicle.inertia.composite.body_frame | [0.0027, 0.0042, 0.0068] kg·m² | 滚转惯量 Ixx 取第一分量，随机化中心值 |
| wave.kinematics.amplitude | 17.73 度 | 翼拍动幅值 A0 |
| aero.wing.cn_fit_amp | 3.59 | 法向力拟合幅值，随机化中心值 |
| aero.wing.ct_fit_amp | 1.86 | 切向力拟合幅值，随机化中心值 |
| vehicle.wingspan.total | 0.6 m | 仅记录对账用，气动不使用 |

### 2.2 域随机化的重锚规则

随机化展开系数不变（质量 ±10%、升力系数 ±30%、惯量区间按中心值
等比缩放），中心值全部改为从上表读取。展开系数属于训练契约，改动需
另行上报，本件不动。

### 2.3 数据集契约一致性断言

前向数据集（θ 到周期平均力旋量）必须与环境同锚。正式切换时重建
`wave_inverse.npz` 数据集并重训逆映射网络。脚手架内置断言：环境构造
时记录所读键值快照，`forward()` 类工具从同一入口取锚，两处不一致即
报错，从构造上消灭"环境与数据集各拍各的"这类静默脱钩。

## 三、训练输入输出重设方案（准周期框架）

### 3.1 观测编码：周期包络段 + 模态事件段

观测向量分两段拼装。

拍动周期包络段（扑动模态语义，逐控制步更新）：

| 分量 | 定义 | 出处 |
|---|---|---|
| 拍频 f | 实测拍频（执行器滞后后的实际值） | 现行环境已有 |
| 拍相位 sinφ、cosφ | 拍相位环形量的正余弦编码 | 现行环境已有，保留 |
| 拍计数 n mod 32 / 32 | 事件定序用拍整数计数的归一化 | 新增 |
| 占空比 ρ | 拍内作动时间占比，零到一 | 对应 I-050 占空比词汇 |
| 包络变化率 df/dt | 拍频指令变化率（受速率限制约束的实际值） | 新增 |
| 周期平均力旋量估计 Ŵ | 前代模型给出的上一拍周期平均 [Fz, Mx, My] | 新增，等 I-055 换辨识模型 |

模态事件段（停拍事件语义）：

| 分量 | 定义 | 出处 |
|---|---|---|
| 模态独热 [FLAP, GLIDE] | 当前模态 | I-050 模态层 |
| 距上次事件时间（秒，截断十秒归一） | 事件节奏感知 | 新增 |
| 保持姿态角 | 停拍钉定的翼姿态角 | I-050 停拍事件参数 |
| 事件计数（截断四归一） | 窗口内已发生模态事件数 | 新增 |

### 3.2 动作编码：包络连续通道 + 事件离散通道

动作空间为复合空间 `Dict{"envelope": Box, "event": Discrete}`。

包络连续通道（扑动模态内持续生效，归一化到 [-1,1]）：
拍频、翼差动 dA、占空比 ρ、幅值分数（相对登记幅值的乘数）。
占空比是模态内连续量，调占空比不构成事件，占空比持续为零也不构成
滑翔模态——这两条直接引用 I-050 占空比语义切割第一、二条。

事件离散通道（三选一，每控制步至多发一个事件）：
不发事件；发停拍事件；发复拍事件。事件参数取自 I-050 事件词汇表
四参数：停拍时刻 t_stop（拍相位零到一，落钉点为最近拍边界）、驻留
时长 hold_duration（秒制或拍数制二选一）、侧别 side（both/left/
right）、复拍剖面 resume_profile（step、linear_ramp、
per_stroke_fraction 三族附逐拍幅值分数表）。事件参数在脚手架里
暂由固定登记值提供，学习头输出事件参数属正式切换后的扩展，先冻结
接口不冻结维度。

### 3.3 事件施加语义与动力学接口

停拍事件按 I-050 冲量层执行：目标拍相位最近的拍边界落钉，钉定后
动力学切换到滑翔模型类；复拍按登记剖面逐拍恢复幅值；模态切换在
机体状态上的瞬时增量走过渡冲量表（十五列格式，来源字段区分主动
机动与外部扰动），表数值属测量资产，脚手架只实现表接口，读到空表
即报"等 I-055 测量数据"，不许编造冲量数值。

滑翔段与扑动段的模型实例按版本化纪律从参数登记库只读引用，
弗洛凯读数只在模态驻留段内有效（I-050 弗洛凯边界第一条），
环境暴露模态驻留段区间供 ltv/hss_floquet.py 工具消费。

### 3.4 动作屏蔽的构造级实现

滑翔模态下包络连续通道被构造性屏蔽（解码器直接忽略并置中性值），
扑动模态下复拍事件被构造性忽略——非法组合在解码层消灭，不靠
奖励惩罚。

## 六、风险与边界

1. 现行构型（0.6 米、215 克、幅值 17.73 度）的悬停辨识未做过，
   重锚后环境的周期平均力旋量量级会变（旧构型升力律 1.95·f² 不再
   适用），在 I-055 数据落地前环境只可用于接口测试，不可用于训练
   结论——这条是硬边界，脚手架里用启动横幅与文档双处声明。
2. 准周期观测维度增大后，模仿学习基线需重新采集演示数据（第九项），
   旧 V2 基线数字只对旧契约有效，不得跨构型引用。
3. 事件通道引入后回合语义从"固定十秒"扩展为"任务剖面内模态序列"，
   奖励函数要不要给模态切换加代价属训练契约层，本件不冻结，
   正式切换前另行预登记。
