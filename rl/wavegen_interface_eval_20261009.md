# 波形发生器与包络骨架接口评估（I-140）

评估日期：2026-10-09。事项：I-140。施工：L6 队。
评估对象：四队 I-139 定稿（ltv/wavegen_prereg_20261009.md 预登记文书、
ltv/wavegen_family.py 参考实现、六判据全过验收档案）。
被接驳方：I-088 包络级决策环境骨架（rl/env_envelope.py）与
I-073 冻结编码（rl/预登记_训练环境重锚与准周期输入输出_20261005.md，

配套可执行核查：rl/wavegen_interface_check.py（本报告各表的运行证据）。

## 第一节 发生器五自由度与骨架包络通道的映射表

骨架包络连续通道四个（冻结件 3.2 节）：拍频 freq、翼差动 dA、
占空比 duty、幅值分数 amp_frac。发生器五自由度 p = (mu, A, f, s, psi)
（I-139 第三节）加差动微差族（每翼独立的 mu、A、s、psi 微差，I-139
第 8.5 节）。

| 发生器量 | 骨架通道 | 映射关系 | 状态 |
|---|---|---|---|
| f 频率 | freq | 相等；骨架归一化反变换 f=1.5+1.0×(a+1)/2 给出 [1.5,3.5] 赫兹，发生器侧 f 恒正无上界，域被骨架域覆盖 | 直配 |
| A 振幅 | amp_frac | A = amp_frac × radians(登记幅值 wave.kinematics.amplitude)；骨架 [0,1] 分数乘登记值得 [0, A_reg] 弧度 | 直配带换算 |
| mu 中置偏置 | 无 | 骨架无此通道；现行键映射 mu = radians(MEAN)+radians(BIAS)（I-139 第三节），登记库有对应键族 | 缺口一 |
| s 行程不对称 | 无（duty 不是 s） | 骨架 duty 是拍内作动时间占比（I-050 占空比词汇），发生器 s 是正负半行程时间比（I-139 第三节），两者语义不同且 duty 属闸门族（见第二节第七条） | 缺口二 |
| psi 相位漂移 | 无 | 现行键 PITCH_LAG_S 换算 psi = 2*pi*f*PITCH_LAG_S（定频标定点口径，I-139 第三节） | 缺口三 |
| 差动微差族（mu/A/s/psi 四维） | dA（一维） | 骨架 dA 对应发生器 A 微差这一个成员；mu/s/psi 微差无骨架通道 | 部分对应 |
| 无（发生器无此机制） | duty | 发生器结构性排除闸门与逐拍二值调制（I-139 第 7.4 节），duty 通道在发生器驱动下不可达 | 缺口四 |

## 第三节 不一致清单与修订建议（不改动冻结件）

以下八条按影响排序，全部只列建议，不动冻结文本；冻结件修订须走
其自身的重新冻结流程。

1. 缺口一（中置偏置无通道）：五自由度之一 mu 在骨架动作空间无对应
   通道。建议：冻结件修订时在包络连续通道增补中置偏置项，域取登记
   幅值同族的偏角范围；在此之前适配层用登记缺省值顶位并声明。
2. 缺口二（行程不对称无通道且与 duty 语义不同）：s 是正负半行程
   时间比，可达域 [0.1493, 0.8507]（I-139 第 4.4 节，安全边际 0.1）。
   建议：增补行程不对称通道；两概念（作动占比与行程比）在文档层面
   显式区分，防混用。
3. 缺口三（相位漂移无通道）：psi 无通道。建议：增补相位漂移通道，
   与登记库 PITCH_LAG_S 换算关系按 I-139 第三节。
4. 缺口四（duty 通道不可达）：发生器结构性排除闸门与二值调制
   （7.4 节）。建议：若发生器路线定为正式作动层，duty 通道与
   DUTY_MOD 机制一并经机主决定处置；骨架期保留通道不删（构造级保证
   不因预留通道受损）。
5. 缺口五（差动维度不匹配）：骨架单 dA 对发生器四维微差族。
   建议：动作空间差动部分扩为四维（mu/A/s/psi 微差），或由 I-138
   指令字典先收拢为低维子空间。
6. 缺口六（更新节律不匹配）：骨架逐控制步（二十毫秒）施加动作，
   发生器边界三要求参数逐拍改写且轨迹连续（斜率上限归 I-138）。
   建议：适配层做拍边界锁存（控制步内参数冻结、拍边界才提交新值），
   该锁存属适配层职责，不改骨架接口。
7. 缺口七（事件词汇与发生器结构互斥）：停拍/复拍事件在发生器驱动
   下不可达。建议：冻结件事件段保留词汇（混合飞行规范 8.4 先例），
   发生器路线下事件通道由适配层报告恒为不发事件；滑翔模态的存废
   归机主后续决定。
8. 缺口八（相位零点基准未对齐）：发生器相位零点 = 行程中点
   （I-139 第三节），骨架相位 = (f·t) mod 1 的积分起点，事件词汇的
   拍相位以其自身零点表达。建议：适配层声明两零点的换算常数并入
   槽位契约（本评估不替两队裁零点语义）。

## 第四节 发生器作为环境动力学接口的槽位定义

骨架现有力旋量槽族（wing_state_model_FLAP/GLIDE）是气动层。发生器
是作动层，插在动作与气动层之间：包络参数 → 发生器波形 → 气动模型
力旋量。三层各一个槽，占位格式如下（并入 rl/env_envelope.py 的
FormalDataSlots 词表时照此登记）：

1. 槽名 waveform_generator（作动层）：
   有状态对象，方法三只——reset(p0)（初值规则按 I-139 第 5.4 节，
   r0 = A 在环启动）；set_params(p, diff)（五自由度 dict 加四维微差
   dict，逐拍调用，拍内非法）；step_outputs(dt) → dict，键为
   phi_L、phi_R、alpha_L、alpha_R、phi_dot_L、phi_dot_R、
   alpha_dot_L、alpha_dot_R（弧度与弧度每秒，双侧）。实现载体推荐
   I-139 第 5.6 节约化形式（纯相位积分器）。
2. 槽名 envelope_to_generator_map（适配层）：
   callable(scaffold_channels: dict, registry_cfg: dict) →
   (p: dict, diff: dict)。职责三条：缺通道（mu/s/psi）以登记缺省值
   顶位并声明；duty 通道恒映射为语义一的满作动；参数在拍边界锁存
   后提交（缺口六的适配责任）。
3. 既有槽 wing_state_model_FLAP/GLIDE（气动层）签名扩展声明：
   正式接发生器后，theta 入参从包络参数 dict 变为波形采样 dict
   （键同槽一定义）；这是签名演进项，登记进两槽的占位格式说明，
   I-055 模型定型时一并裁。

## 第五节 核查脚本与运行结果

rl/wavegen_interface_check.py 五项核查（本次运行全部通过，输出随
证据入档）：
1. 域覆盖：骨架频域 [1.5,3.5] 赫兹在发生器 f 恒正域内；幅值换算
   闭式成立；
2. 可达域边界：占空比越界指令按预期抛错（c_to_b 上限 1.1017）；
3. 适配演示：骨架四通道代表值经映射得五自由度，发生器整周期采样
   波形有限且周期精确（time_map 闭式 t(1)−t(0) 与 1/f 相对误差
   小于 1e-12）；
4. 差动展开：dA 映射为左右 A 微差后双翼波形分离且对称；
5. 槽位签名：三类槽以本报告第四节的格式登记进骨架词表后，
   未填充请求即报错的构造级保证复验通过。

## 第六节 结论

发生器与骨架在频率与幅值两自由度上直配；中置偏置、行程不对称、
相位漂移三个自由度在骨架动作空间无通道；duty 通道与停拍事件词汇
和发生器结构互斥（I-125 教训的结构化后果，属预期内冲突而非缺陷）；
更新节律与相位零点两处需适配层处理。上述八条清单供冻结件修订与
I-138 指令契约吸收，本评估未改动任何冻结件。
