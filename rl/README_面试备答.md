## 总架构（生产口径，2026-09-19 确定）

**可解释外环 + 学习内环**，而不是端到端黑盒：

```
轨迹/目标 → [外环 TECS+串级PID（经典，可解析验证）] → 期望力旋量 W*=[Fz,Mx,My]
          → [内环逆映射（学习）] → 波形参数 θ=[拍频f, 翼差动dA, 分裂比split,
                                     俯仰相位lag, 拍动平面偏置mean]
          → [扑翼执行机构 9 关节] → 真实力/力矩
```

为什么内环是学习的正确位置：θ→W 的前向映射**强非线性**（分裂比/相位滞后
改变周期内波形）、**多值**（拍频和幅值都能出升力）、**随飞行状态漂移**
（增益随风速/姿态变）——解析反解不存在，学习边际收益最大；
外环慢、可解释、要认证，经典控制没有替换价值。这是"面向生产"的分层，
端到端黑盒化 TECS 的方案只具有教学演示价值。

**数据基座**：2026-09-18/19 两轮台架辨识（状态锁定台架 + 30Hz 进程内记录 +
瞬时力三分离测量）——升力曲线 L̄=1.95f²、舵效三通道增益、周期内瞬时力
波形（峰峰 47N、S&D 消融 53/47/0）、肩关节惯性力矩 ±0.36N·m（尾翼差动
权限的 7 倍，扰动预算主体）、B_dA(f) 翼差动增益（24/32/47 N·m/rad，
滚转主通道必须用翼差动的定量依据）。

## 第零环：逆映射演示（最贴近面试方向，2026-09-19，rl/waveform_inverse.py）

- 数据集：1.2 万组波形参数 θ → 周期平均力旋量 W=[Fz,Mx,My]（前向物理，
  参数包线全部在台架辨识覆盖范围内）。
- 逆映射网络 W*→θ（256×2 多层感知机（Multi-Layer Perceptron，MLP）），前向物理复核：**Mx 相对误差 3.5%、
  Fz 9.3%**；My 通道在当前波形参数组下操纵权限为零（如实展示，
  说明俯仰力矩需要尾舵/质心等其他通道）。
- **经典基线对比（rl/wave_inverse_baseline.py，图 `figs/wave_inverse_vs_linear.png`）**：
  与"工作点雅可比伪逆"（台架辨识线性化+控制分配的经典做法，即逆映射
  在经典体系里的提供者）在同一物理复核协议下对比——
  **Fz 通道：线性伪逆 23.8% vs 神经网络 9.7%（2.5 倍优势）**；
  Mx 通道：线性伪逆 5.2% vs 神经网络 3.6%（近线性通道两者相当）。
  结论口径：神经网络的优势精确出现在线性化失效的非线性区域
  （升力 ∝ f²、split/lag 的波形耦合），在近线性区域不损失精度——
  学习版逆映射不是不可解释的方法，是对经典控制分配的可量化升级。
- **生成式升级（rl/wave_inverse_cfm.py，图 `figs/wave_inverse_cfm.png`，
  2026-09-21）**：复用 WSL 最优传输条件流匹配（OT-CFM）生产配方
  （OT 小批量配对 + 直线插值路径 + 分类器无关引导 10% 条件丢弃 +
  50 步 Euler 常微分方程采样 + K=8 拒采），同一物理复核协议下三方法对比：
  **Fz 通道 线性伪逆 21.1% → 判别式网络 8.8% → CFM 生成式 1.4%**；
  Mx 通道三者持平（4.5%/3.6%/3.9%）。这直接验证了"生成式前置"论证：
  Fz 是多值通道，判别式的条件平均伪影正是其 8.8% 残差的来源，
  CFM 通过分布采样加拒采覆盖多模态解集；Mx 单值通道上生成式无额外
  收益——前提决定收益，与理论预判完全一致。
- **闭环验收（rl/closed_loop_cfm.py，图 `figs/closed_loop_cfm.png`，
  2026-09-21）**：经典外环（加速度空间 PID + 迟滞型防坠应急 +
  MIT 规则在线升力比校正）输出期望力旋量，CFM 逆映射（K=8 拒采）
  反解波形参数，V2 环境全随机化契约下 16 种子基准：
  **生成式内环闭环 15/16 存活（与经典专家 15/16 持平），
  稳态高度误差均值 0.059 m（优于专家的约 0.20 m，自适应校正
  消除了 PD 静差），CFM 采样耗时均值 44.9 ms/步**。
  失败种子 708 为最大质量 0.77 kg 加迎风 −1.17 m/s 的组合极端工况。
  工程发现：±30% 升力抽负下固定增益级联会拍振撞界，
  在线升力比校正（MIT 规则最小版）是挽救关键——这正是
  "在线适应层存在理由"的实证。
- 图：`figs/wave_inverse_scatter.png`（逆映射验证）、
  `figs/wave_forward_map.png`（前向映射的多值性与非线性热图——
  "为什么解析反解不存在、必须学习"的单图论据）。

## 面试可能追问与回答要点

**Q：为什么内环映射适合学习，外环不适合？**
内环是高频、强耦合、模型最不准确的环节（拍动-机体耦合、执行器滞后、
柔性翼效应），学习收益最大；外环（位置/轨迹）动态慢、可解释性要求高，
经典控制足够且安全可证。这正是 SparrowHawk 用周期平均（cycle-averaged）模型配
串级 PID、而 Purdue Flappy Hummingbird 用 DDPG（深度确定性策略梯度）学习内环的原因。

**Q：仿真到真机怎么迁移？**
三件事：域随机化（中心值来自台架辨识而非经验估取）、观测通道对齐真机
（IMU 噪声特性用 FWAF-VID 数据集的真实标定 YAML）、以及先做
Real2Sim 校准（用真机台架数据反调仿真参数）再 Sim2Real。
参考 Purdue 论文 §III 的力映射拟合 + 随机化清单（∆Vamp/∆δV/∆V0/∆σ）。

**Q：模仿学习在你的链路里是什么角色？**
模仿学习承担冷启动职能。BC 把可解释的专家控制律（或真机手动飞行数据）蒸馏成策略网络，
让 PPO 从"已经会飞"开始微调，而不是从零探索——样本效率和安全性都跨越量级
提升。我自己做过行为克隆项目，这里的差异化是我能把**专家的物理结构**
（PD 增益、滤波、限幅、速率限制）讲清楚，BC 只是更换了实现载体。

**Q：RL 还能推理出哪些参数？**
台架能测的是静态线性参数（k_f、舵效增益）；RL 在线适应（快速电机适应
（Rapid Motor Adaptation，RMA）式潜变量）
能推理的是台架测不了的状态耦合参数：拍动下洗中的尾舵真实增益、
大滚转速率下的阻尼非线性、执行器高频滞后、以及环境风场。
（2026-09-19 环境调试实证：|wx|>3 rad/s 后准定常模型的阻尼反号，
这类区域正是需要学习去覆盖的。）

**Q：目前环境的诚实边界（主动交代是加分项）**
- 周期平均口径：瞬时波纹不进刚体积分（重点思考2的瞬时模型是下一步）；
- 静气悬停尾舵无效（模型无下洗项），滚转用翼差动；
- |vz|>2.5 m/s 的垂直通道加了动量理论修正，防止准定常模型外推失真；
- 运行时 3×mg 力限幅会把高拍频升力压到体重以下（该限幅形成升力上限，已量化），
  训练环境用 10×mg——这也是自由飞之前必须处理的仿真侧问题。
