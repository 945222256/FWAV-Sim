## 一、v4 相比旧版的变化（为什么这次不会黑屏）

旧壳把页面显示完全托付给手机浏览器，你的手机没有能承接的浏览器
组件时，旧壳直接停在黑屏。v4 壳内置了自带渲染引擎：任何手机都能
显示看板，不再挑浏览器。图标与打开键问题也已随入口声明修复。

## 二、机主五步（v4 专用地址，2026-10-05 第三次更新）

> 本次更新原因：机主装到的 1.0 是第一次下载时留在手机里的旧文件
> （下载列表或缓存存货，服务器端实测为 1.3 且哈希一致）。已给下载
> 目录加禁止缓存头并换带版本号新地址，旧存货不可能再被撞上。

0. **清旧**：卸载手机上显示 1.0 的"LP 看板"；再到下载目录与文件
   管理器"安装包"分类，把 lp-board 开头的旧文件全部删除。旧地址
   lp-board.apk 已在服务器端删除（访问返回 404），手机里若还能从
   旧地址"下载"到东西，那必是本机存货缓存，一律不用。
1. **下载**：手机浏览器打开（全服务器唯一下载入口，认准 **v4**）：
   `https://personal.karmicsword.com/downloads/lp-board-v4.apk`
   风险提示选"仍要下载"，未知来源按引导允许。
2. **安装打开**：装完点"打开"（按钮应为可点），登录页输入看板账号，
   应看到作战地图首页（深色界面、九条逻辑线卡片）。
3. **版本核对**：设置 → 应用 → LP 看板，版本号必须显示 **1.3**
   （不是 1.3 说明又撞上旧文件，回第 0 步）。
4. **豆包语音实测（冻结判据一）**：对豆包说：
   **"用 LP 看板打开事项 I-055"**
   预期：应用被调起，直接展开 I-055（机翼态结构辨识）的详情抽屉，
   含判据、证据链、时间线。
