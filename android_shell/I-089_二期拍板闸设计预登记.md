# I-089 安卓二期拍板闸设计预登记（L5 队，2026-10-06）

> 性质：只写设计不动工。**施工前置门：I-064 机主手机实测通过之前，
> 本文件描述的任何施工不得开工**（含试验性代码）。实施事项为 I-062，
> 其两条冻结判据为验收唯一口径，本文件是它的设计依据与判据细化草案。

## 一、问题定义

一期壳把全部写操作交给云端页面完成，任何能点按钮的主体（含读屏
模拟点击型手机助手）都能完成拍板类决策。二期目标：拍板类写操作
必须经过机主本人的物理确认，助手模拟点击无法完成。

### 拍板动作清单（实施开工时与 HQ 冻结）

| 接口 | 动作 | 须过闸 |
|---|---|---|
| /api/ledger/close | 打勾关闭 | 是 |
| /api/intake/decide | 批准/驳回/合并 | 是 |
| /api/ledger/owner_reply | 机主答复 | 是 |
| /api/ledger/set_criterion（verified=true） | 子项验证勾选 | 是 |
| 证据追加/申报/认领释放 | 非决策类 | 否 |

## 二、实现路线：三档闸

**A 档·生物识别强闸（默认档，壳内路径）**
Android Keystore 生成一把 setUserAuthenticationRequired(true) 的
密钥；拍板时页面经 JS 桥调用 window.LpGate.requestApproval(载荷)，
原生层弹 BiometricPrompt + CryptoObject，生物识别通过后用该密钥对
载荷哈希做 HMAC，返回 {token, ts}；页面把 token 随写请求提交；
云端用设备注册密钥验签。模拟点击无法通过生物识别扫描，判据一的
"助手无法完成"由物理层保证。

**B 档·密码复验中闸（浏览器与 TWA 路径、无生物识别设备）**
无 JS 桥环境（TWA、桌面浏览器）拍板时，服务端把写请求转成复验页：
重输看板账号密码（输入框掩码，读屏只见掩码）→ 服务端签发六十秒
会话绑定确认票 → 写请求携票生效。助手不持有密码，无法代过。

**C 档·长按确认弱闸（仅机主明示裁决后可启用）**
原生三秒长按确认。设计如实声明：读屏助手的模拟输入可以模拟长按，
**C 档单独不满足 I-062 判据一**，只能作为无生物识别且机主接受
风险时的体验降级，或与 B 档串联使用。启用与否属机主裁决项。

## 三、与一期外壳的接口

1. BoardWebViewActivity（壳内 WebView 路径）：addJavascriptInterface
   注册唯一桥对象 LpGateBridge，页面加载前注入 window.LpGate 探测。
   桥内只有确认与铸token，无网络调用，token 为离线 HMAC。
2. TwaLaunchActivity / TWA 路径：无桥（TWA 平台限制），页面探测
   window.LpGate 不存在即走 B 档服务端复验。
3. 云端服务：拍板类端点加确认校验中间件（A 档验设备 HMAC，
   B 档验确认票）；拍板事件在云端事件流携带 confirmation 字段
   {method: biometric|password|longpress, ticket 指纹}——满足云端
   托管需求 FR-6 审计要求，即 I-062 冻结判据二。
4. 设备密钥注册：壳首启时 Keystore 生成密钥，调一次
   /api/device/register（账号会话绑定）。**契约修订提案**：I-064
   判据三"壳不含任何网络请求代码"需修订为"不含任何账本写接口调用
   （设备密钥注册一次性除外）"——属验收文本变更，须机主批准后随
   I-062 开工生效，本设计不默认生效。

## 四、验收判据草案（I-062 实施时冻结细化）

1. **助手不可达性**：模拟点击工具（adb input 脚本 + 无障碍点击
   脚本）对拍板按钮持续点击一轮（模拟器与真机各一遍），云端事件
   流零拍板事件、logcat 零确认通过记录，双证留档。
2. **生物识别一次通过**：真人指纹/人脸一次通过后写生效，事件流
   confirmation.method=biometric。
3. **审计完整**：全部拍板事件携带确认方式字段（FR-6）。
4. **降级路径**：无生物识别设备上 B 档可用；C 档仅在机主裁决后
   存在。
5. **双路径一致**：壳内 A 档与浏览器 B 档产生的事件格式一致。
6. **静态检索**：壳无账本写接口调用（密钥注册除外，以批准后的
   修订文本为准），tools/verify_i064.py 扩展断言。

## 五、风险与开放问题（开工前须答）

- Keystore 密钥随卸载销毁：重装后须重注册设备（流程已含）。
- 多设备并存：注册表允许多设备密钥，任一可签。
- B 档肩窥风险：与网页登录同级，接受。
- 老设备无 BiometricPrompt：自动落 B 档。
- 离线拍板：不支持（拍板本就需要云端落账）。
