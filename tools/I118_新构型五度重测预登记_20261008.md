# I-118 新构型五度重测预登记(2026-10-08,L1 队)

> 判据先于数据(工程备注要求)。本预登记先于采集执行。

## 一、构型与配方

构型:现行树(尾翼补强后:舵面总面积 0.0225,差动力臂 0.224,
舵效调度三键重标,骨架面板外移,组合通道比 0.5)。

工况与注入(沿用 I-085 配方语义,适配现行构型):
- 盘旋工况:坡度指令 5 度,切入 5 秒,斜坡 0.05
- 偏航抵消组合关闭(不设键),方向舵注入 0.07
- 差动与升降舵注入 0.03,拍频调制 0.25,幅值差动 0.02
- 错相双音 2.33 与 2.6 各 0.04,逐拍相位跳变 1.3
- 多正弦 16 点网格,窗 60 秒

采集通道:统一入口(锁四项强制盖章,双跑整档字节比对,不一致
即作废重跑)。

## 二、判定线(先写明)

1. 通道判据:双跑逐字节一致(入口内置,不一致即作废重跑)。
2. 数据判据:三通道双半净劣者读数入档(读数无过线要求,本事项
   交付为合规数据资产非验收);拟合窗=起点 5.0,终点取崩点前
   (同 I-085 与 I-113 口径);16 频点,六输入。
3. 质量说明随档:崩点时刻、稳定段时长、三通道饱和占比如实记录。
4. 有效期标注:本数据在构型再变更前有效;构型变更即须按 I-113
   同法复验或重采。
