# I-103 网格预登记(2026-10-07,L1 队)

> 工程备注要求网格范围与步长先于执行入档。

## 网格设计

中心点(KP_A=1.7, PITCH_TRIM=−0.10):二十一点八秒孤峰,其余参数
WING_MIX_RATIO=0.5(config 现值)、YAW_DAMP=2.5、PITCH_DAMP=0.3、
KI_A=0.15、组合开、坡度指令十度切入五秒、斜坡零点零五、三十五秒窗。

半宽依据:KP_A 轴上 1.7 至 1.9 崩(差零点二),1.7 至 1.3 崩(差零点四),
取保守半宽零点二;步长上限零点零四。

- KP_A 轴:1.50 至 1.90,步 0.04,共 11 点(含中心 1.70)
- PITCH_TRIM 轴:−0.08 / −0.10 / −0.12,步 0.01 至 0.02,共 3 值
  (TRIM 轴无邻域数据,以中心值对称展开)

全图 11×3=33 点,每点一次三十五秒在环跑。

## 判读口径

- 存活时间=高度首次跌破二点五米的时刻(窗尾存活记三十五秒)
- 达标=满窗存活,采样归档文件名加两颗全角星
- 有意义=存活超过孤峰二十一点八秒或构成边界特征点,加一颗全角星
- 稳定边界线=存活二十秒以上的参数点连成的包络,数值表入档

## 星标纪律执行方式

数据流文件由仿真进程自动命名不可改;达标与有意义的采样在其数据
流 CSV 旁建立带全角星前缀的归档副本,并在汇总表标注。
