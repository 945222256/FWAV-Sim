# I-055 采集协议预登记:盘旋工况降幅值长稳定窗(2026-10-03,L1 队)

> 本文件依据指挥部 D-018(采集协议升级)、D-020(工况补正)、D-021(四路
> 分派)写定,先于采集执行。D-018 两条件:注入幅值不得小到淹没进噪
> 声;协议改动先写预登记文件再执行。本文件即条件二的执行物。

## 一、工况(依 D-020 工况补正)

在案最优矩阵(hop 组)的数据实测滚转角中位 12.5 度,属盘旋(压坡度
转弯)工况;本队 2026-10-03 采集协议升级班的两跑为平飞巡航(滚转
中位约零度),工况不匹配,其数据退出验收证据。本协议恢复盘旋工况:

- 基础配置:现行 config 默认(几何法新惯量六十秒巡航族,I-037 重锚
  后生效配置),不加 WAVE 族覆盖。
- 转弯进入:FLAPPER_BANK_TEST=1,FLAPPER_BANK_DEG=10,FLAPPER_BANK_T=5
  (五秒切入常值坡度,与《压坡度转弯试验_判据与方案》科目一口径一
  致),FLAPPER_WING_MIX=1(偏航抵消组合通道,方案要求开启)。

## 二、注入(D-018 降幅值,沿用 2026-10-03 已验证六十秒稳定配方)

- FLAPPER_MULTISINE_ON=1,16 点网格
  0.2,0.5,0.8,1.0,1.3,1.6,2.0,2.33,2.6,2.9,3.2,3.8,4.5,5.5,6.5,8.0
  (与拟合网格一致)。
- FLAPPER_AIL_PROBE_AMP=0.03,FLAPPER_ELEV_PROBE_AMP=0.03,
  FLAPPER_RUD_PROBE_AMP=0.03(rad)。
- FLAPPER_FREQ_PROBE_AMP=0.25(Hz),FLAPPER_DA_PROBE_AMP=0.02(rad)。
- FLAPPER_MODAL_TONES=2.33:0.04,2.6:0.04(错相多音)。
- FLAPPER_MS_HOP=1.3(逐拍相位跳变协议保持)。
- FLAPPER_MAX_S=60。

## 三、预声明目标与判读

- 目标:单跑稳定二十五秒以上(坡度切入后计),全程不坠地。
- D-018 条件一的信噪检验:三通道饱和占比各不超一成;超一成即警告
  限幅污染,数据降级为诊断用不入验收。
- 判读:估计器用缝感知修复版(tools/ident_fd_estimator.py,拼接缝
  分段相位),16 频点,净口径双半并列与冻结口径平行报告,判据为已批
  准的净口径放行门文本。
- 稳定段裁取:坠地前或窗尾前的连续稳定段直接使用(本协议为单跑长
  窗,不经拼接器,无缝)。
- 负结果同样按完成通道交付,不许为过关改判据或挑窗。

## 四、与本队上班两跑的差异声明

上班跑缺 FLAPPER_BANK_TEST 族(平飞),本跑补齐;其余注入键逐键相
同。工况差异与差动限幅极限环两个因素的分离判读:本跑若差动饱和仍
超一成,则限幅因素独立于工况成立,须另裁决滚转环结构;若饱和回落,
则上班读数退步主因判为工况不匹配。
