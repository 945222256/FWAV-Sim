flight_features.py 原地保留。该脚本为飞行记录波形特征提取的标准化实现，2026-09-29 随转弯线阶段性总账提交，此后全库无引用。其归属取决于转弯线后续是否继续使用该特征标准，判定不了，按不许猜的纪律保留并登记在此。

## 四、断链复扫结论

搬移后对七十二个被移脚本做全库复扫，扫描范围为除 tools/archive、缓存目录、日志区与备份区外的全部入库文本文件。第一，import 与动态加载形式的命中数为零。第二，精确文件名的命中共一百零九处，全部位于 docs 目录文档、根目录过往计划记录、编译日志与登记库闭环事项证据，没有一处位于活跃代码或配置。第三，主程序与配置中凡点名 tools 脚本处，点名对象均为保留件。断链清零达成，余量按本清单第一节历史引用对照列换算新路径即可。
