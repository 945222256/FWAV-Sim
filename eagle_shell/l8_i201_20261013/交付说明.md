# I-201 交付说明：Eagle X 翼轴修正、原尾三分与完整关节动作预览（L8 队，2026-10-13）

本交付为离线视觉资产候选，不改动生产模型，不启动仿真器，不写入物理配置。
冻结质量、惯量、气动参数与现行二百一十五克物理机构（URDF）保持原值。

## 一、本轮相对既有预览的三项实质变化

1. 翼轴重定位。依据 wing_root_tail_audit_20261013.json 与 wing_root_axis_diagnosis.png，
   修正前扭转轴在翼根关节站位处于百分之八十八点七弦长处（贴近后缘）。本交付按冻结
   URDF 内翼面板声明的前缘（x=0.029 米）作为对齐基准，把视觉翼根前缘对齐到机构轴附近，
   修正后轴在关节站位处于百分之二十点一弦长处，与 URDF 面板自身的百分之十五点五
   参考值同量级。四分之一弦点（x=0.092 米）仅作为参考数据登记，未用作铰点。
   缝合线（原模型翼根开放边界）的范围中点与顶点质心作为参考数据一并登记。
   左右翼各记录 dx、dz 修正量（约 -0.099 米、-0.004 米），左右对称。
2. 原模型尾部三分。原尾部风扇网格（沿错误命名 head.obj）按 y=±0.012 米切分为
   左水平作动面、右水平作动面与中央竖脊方向舵。切分依据为展向剖面数据：竖脊仅
   存在于 |y|<0.012（最高 z=0.069 米），侧带 |y|>=0.012 平坦（z 最大 0.005 米）。
   三个铰点全部取自风扇根部缝合线（原模型与机身的连接边）分侧质心。
   三个节点同为 base_link 子节点，互不为父子，任一角度只作用于自己的网格，
   机检证明其余网格位移为零（见 delivery_checks.json 与报告 verification 节）。
3. 外观无补建件。交付中合成网格数量为零，URDF 的方盒尾翼 visual 未进入任何
   预览或交付件；尾部全部使用原模型网格。

## 二、正式判据对应

判据一（分件与守恒）：左右翼各主翼与翼尖，切面过 |y|=0.14 米折叠关节平面；
切分前后表面积相对误差与投影轮廓差异面积见 verification 节，均低于判据阈值
（相对误差小于百万分之一、差异面积小于十亿分之一平方米）。尾部三分同阈值。
贴图坐标在切面上按线性插值生成，切面为开放边界，不补生成表面。

判据二（绑定清单）：geometry_and_binding.json 的 bindings 逐件记录源文件、角色、
连杆、零位原点、切分平面与修正量；左右主翼挂 innerwing_L/R，左右翼尖挂
outerwing_L/R，与现行机构一致。尾部三件的铰点、轴向、限位与 URDF 参考关节
逐项登记；其父子拓扑与 URDF 不同（无共用的偏航父节点），已作为候选标注。

判据三（几何数据）：翼展、投影面积、表面积、前后缘、弦长分布、截面厚度范围
及截面方向数据在 geometry 节与 chord_stations.csv，附单位、计算方法定义
（definitions 节）与源文件校验值（provenance 节，二十一项 sha256）。
质量与惯量保留空值。后掠参考线按修正朝向重算（sweep_reference_lines 节）。

判据四（动作预览）：固定机身，二十秒主视频含拍动、扭转、折叠、尾左单动、
尾右单动、方向舵单动、左右同向、左右差动与组合九段；另附八个分动作视频
（clips/ 目录）。逐帧角度记录在 joint_commands.csv，全部命令在机构限位内
（复验脚本逐帧断言）。仿真驱动跟踪验证未做，如需在环验证走统一入口。

判据五（复核与回退）：原资产与物理配置未改动；回退方法为本目录整体删除即回退，
上一轮 Jane 预览目录保留作对照。翼根对位、折叠接缝与尾部重叠的剩余偏差在
limitations 节逐条明示。重要独立复验材料见 复验说明.md；复验未完成前
本项不得认定通过。

## 三、明确标注的假设与限制

实物铰点位置无资料；翼轴对齐规则为按 URDF 面板声明对齐的离线候选，不宣称真实机构
通过。折叠铰在翼尖段弦向位置与 URDF 外板声明存在形状性偏差（数值在报告
wing_axis_realignment 节）。方向舵大角度偏转时风扇后缘会扫入左右水平面所在
平面。尾部三角度候选与冻结 URDF 拓扑不同，新构型物理接入另办验证。
当前尺度沿用旧壳装配值，未确认七百克实物尺寸。

## 五、2026-10-13 接续：机构层级版与图证修正

依据 logs/jane_dispatch_20261013/尾部机构复核与接续要求.md（记录已随档并挂回
I-201），本轮接续四项：

1. 机构层级版。output/mechanism_hierarchy/ 提供符合冻结机构层级的离线预览：
   整尾偏航基座（视觉候选铰点取风扇根部缝合线质心，与冻结机构铰点 x=-0.26 米
   分开标注）下挂中央竖片（仅随整尾偏航）与左右独立俯仰节点。二十秒十段
   主视频与九个分动作视频演示左右单动、同向（共同迎角）、差动、整尾偏航、
   偏航叠加差动与组合；joint_commands.csv 三百零一帧逐帧在限位内。机检：
   整尾偏航探针角下三件尾部网格全部跟随（最大位移约四点四厘米）；左右俯仰
   各自只动自己网格（其余网格位移小于 1e-12 米）；父子合成与逐点变换一致。
   原独立方向舵候选版保留为对照，两版差异在报告 relation_to_delivered_candidate
   节明示。
2. 无伸缩结论。冻结 URDF 九个关节全部为转动关节，无移动关节；原网格外形
   不能证明独立方向舵、舵机、铰轴或伸缩机构，不从外形补造该动作。
   机主问题（两侧差动加整体偏航，还是协同转动加偏航加伸缩）的答案：
   现行机构为两侧独立尾面（可同向可差动）加整尾偏航，没有伸缩自由度。
   同向运动是左右尾面共同改变迎角（俯仰候选），不能称为整尾绕机身纵轴
   滚转；气动与滚转效应需另行验证。
3. 图证坐标修正。make_figures.py 尾部俯视图此前铰点按 x、y 落点而轮廓横轴
   为 y、纵轴为 x，切分线误用水平线；已改为铰点按 y、x 落点、切分线用竖线，
   注记防重叠后重出 tail_split_and_hinges.png。机构层级版另附
   tail_topology_and_axes.png（父子图加轴线图）。
4. 翼根后续核查（如实登记代价）。修正把扭转轴从约百分之八十八点七弦长移到
   约百分之二十（机构对齐），代价是翼根周界埋入机身投影轮廓（含两毫米缓冲）
   的比例从百分之百降到左翼百分之五十一、右翼百分之四十一：冻结机构拍动
   扭转铰位于 x=0，比原模型翼身连接线（缝合线质心约 x=+0.075 米）靠后约
   七点五厘米，单一视觉平移无法同时满足轴位对齐与翼根贴合。机构对齐版
   保留为主交付（绑定判据要求与现行机构一致）；缝合线对齐数值在主报告
   wing_axis_realignment 节登记为对照。折叠接缝动态缝隙：刚性分件在
   零点四、零点八、一点二弧度折叠时切面点最大位移分别为六点八、十三点四、
   十九点四厘米（无柔性蒙皮，缝隙随角度增大）。两端同时满足需要实物机构
   资料（原始照片、机构图、铰点位置），为当前最高优先缺项。
