# 照片到壳鸟：视觉外壳流水线引导

> 版本：2026-10-12（首版，基于 eagleX 全程实跑）
> 原则：平行资产、零改存量代码；生成资产只进视觉，永不进物理取数（质量、惯量、气动一律以实测与论文为准）。
> 产出：一只带贴图的壳鸟，挂进现行扑翼仿真的关节机构上，跟着拍动与扭转关节运动，随时一个开关退回原版外观。

---

## 一、工位总览

| 工位 | 名称 | 输入 | 输出 | 运行环境 | 耗时 |
|---|---|---|---|---|---|
| 0 | 资产获取 | 一张照片 | 融合网格 + PBR 贴图 | 3D 大模型（人工操作） | 视外部工具 |
| 1 | 环境与工具链 | — | 可运行的分割环境 | 一次性建设，已建成 | 已完成 |
| 2 | 特征推理 | GLB 网格 | 逐点 32 维特征场 npy | PartField 环境（GPU） | 约 3 秒 |
| 3 | 聚类分件 | 特征场 | 20 级粒度部件树标签 | PartField 环境（CPU） | 秒到分钟 |
| 4 | 量化验收 | 标签 + 网格 | 部件统计、镜像检验、目检图 | PartField 环境 | 分钟 |
| 5 | 壳层装配 | 选定级标签 + 网格 | 带 UV 分件 OBJ + 壳层 USD | 两个环境各跑一步 | 5 分钟内 |
| 6 | 挂载验证 | 壳层 USD | 对位数字、镜像核验、截图 | Isaac 环境 | 一次仿真运行 |

关键设计：最贵的工位 2 每个模型只跑一次；换粒度、换拆法只动工位 3 之后的便宜环节。

## 四、工位 3：聚类分件

```bash
cd G:/Playground/PartField
"G:/Playground/PartField/venv/Scripts/python.exe" run_part_clustering.py \
  --root exp_results/partfield_features/<名字> \
  --dump_dir exp_results/clustering/<名字>_knn \
  --source_dir data/<名字> \
  --use_agglo True --max_num_clusters 20 --option 1 --with_knn True
```

要点：
- `--option 1 --with_knn True` 是 AI 生成网格的推荐档（几何近邻定义邻接）；`--option 0` 是默认档，生成件上左右不对称且中央糊，仅作对比用。
- 产物：`cluster_out/<名字>_0_01.npy` 至 `_20.npy`（级数越小部件越少），`ply/` 下是逐级着色网格。

## 五、工位 4：量化验收

对每个候选级跑四道数（对话中已用脚本，可复制）：

1. 部件数曲线：逐级 `np.unique(labels)` 计数与最大件占比，看树形是否健康（如第 6 级 6 件、最大占比 24%）。
2. 每件画像：面数、质心、包围盒、薄度因子（面质心奇异值 `s3/s1`，翼面薄片应小于 0.1）。
3. 镜像配对：质心 X 取反后最近件、面数比（0.9 以上为佳）、双向最近距离（毫米级为佳）。
4. 目检图三张：类别着色三视图、黑线分界版（`face_adjacency` 提取件间边）、分件面板版。

选级判据：构型件齐（头、身、左右翼、尾）、镜像配对干净、中央不糊。eagleX 选了近邻档第 4 级。

## 六、工位 5：壳层装配

第一步分件重导（改 `prep_parts.py` 顶部三个常量后运行）：

```bash
cd G:/Playground/isaac_flapper_sim/eagle_shell
"G:/Playground/PartField/venv/Scripts/python.exe" prep_parts.py
```

需按新模型修改的常量：
- `LABELS`：指向选定级的标签 npy；
- `PARTMAP`：部件号到件名的映射（部件号 = 标签 `np.unique` 升序序号，注意标签本身是聚类代表元编号不是 0、1、2、3）；
- `MIRROR`：哪个件由母版镜像生成（左右翼强制对称用）。

第二步 USD 装配（改 `build_shell_usd.py` 后用 Isaac 环境跑）：

```bash
cd G:/Playground/isaac_flapper_sim/eagle_shell
"G:/Playground/isaac_sim_5.1.0/python.bat" build_shell_usd.py > build_log.txt 2>&1
```

需按新模型修改的常量：
- `SCALE`：缩放系数（翼展对齐口径，eagleX 为 1.133 米对 0.64 米取 0.56）；
- `Z_FINE`：竖向微调（目检后调高低）；
- `BINDING`：件到连杆的绑定表（注意资产 +X 翼件映射到机构左侧连杆，因机构 y 轴指左）；
- `LINK_ORIGINS`：连杆零位原点（从 URDF 关节链读，勿凭记忆写）；
- `M_ASSET2MECH`：资产轴到机构轴的映射矩阵（资产惯例 X=翼展、Y=上、Z=前；机构 x=前、y=左、z=上）。

验收：`out/eagle_shell.usd` 与 `bind_manifest.json` 生成；日志中每件三角形数与分件一致。

## 八、坑集（实跑踩过，换模型前先读）

1. Kit 应用的输出不要接管道过滤（grep、tail 会缓冲吞进度），一律重定向到文件再看；Kit 关闭偶发悬挂，脚本要加保底关闭。
2. pxr 矩阵是行向量约定：numpy 矩阵喂 `Gf.Matrix4d` 前旋转部分要转置，否则鸟竖着装。
3. `CreatePrimvar` 不在 Mesh 对象上，用 `UsdGeom.PrimvarsAPI(prim).CreatePrimvar`。
4. 标签 npy 里是聚类代表元编号（如 14660），必须 `np.unique(..., return_inverse=True)` 归一成 0 起序号再用。
5. UV 是逐面三顶点口径（行数为面数乘三），布尔掩码要 `np.repeat(mask, 3)` 扩三倍再索引。
6. 隐藏旧视觉件必须藏满整条翼链（基座、左右翼根连杆、左右内翼、左右外翼共七处），漏藏外翼盒体会以折叠动作（绕 z 转）叠在壳翼下方，观感为主翼拉伸加安装位旋转；尾链不藏（尾无壳件）。
7. 无头截图依赖渲染回调，个别部署可能不触发；已内置物理回调看门狗兜底退出，对位数字仍然有效。
8. bat 文件内容必须纯 ASCII。
9. 面心包围盒读回诊断时，`Gf.Matrix4d` 转 numpy 后按列向量乘是转置错误，须按行向量约定处理（该诊断读数曾因此作废一次）。
