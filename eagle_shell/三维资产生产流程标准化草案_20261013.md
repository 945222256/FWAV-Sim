# 三维资产生产流程标准化草案

日期：2026-10-13。负责人：Jane。状态：依据 EagleX 实际故障提出的流程草案，尚未全部自动化，也不代表新资产获得物理或 CFD 资格。

## 目标与现行边界

以一份可追溯的静态几何基准和一份明确的机构定义为源头，派生视觉、流体边界和动力学所需的产物。各用途允许不同分辨率或表面表达，但必须共享坐标、单位、部件身份和动作含义，并保存转换记录。

现行《流水线引导》已打通照片、生成模型、特征推理、聚类分件、壳层装配与挂载。现行生成资产仅进入视觉；质量、惯量和气动仍按现有实测与论文来源。本文提出独立的几何资格分支，不自动修改存量物理模型，不将生成网格直接升级为真实构型。

EagleX 暴露的缺口是：聚类边界被当作机构接口，右翼镜像替换左翼没有同时检查机身接口，切割没有同步细分邻面，动作验收遗漏了翼根与机身。新流程应把这些检查变成每个资产的必经步骤。

## 工序与通过条件

| 工序 | 应保存的内容 | 进入下一步的条件 |
|---|---|---|
| 1 源资产登记 | 不可变源文件、哈希、参考图、来源与许可、单位、显示尺度及真实标定状态 | 文件能复现；未知尺寸明确标注，不能混作实测 |
| 2 原始质量诊断 | 无贴图图、边界与非流形检查、自相交、连通分量、厚度与轮廓检查、材质透明度 | 已分类设计开口、真实缺损、未知部分；不靠透明贴图遮盖 |
| 3 语义分件与接口定义 | 部件 ID、功能、左右来源、邻接关系、连续膜面或接触或设计间隙、关节参考 | 聚类标签经过机构解释；每次镜像有装配匹配检查 |
| 4 局部几何修复 | 修复前后文件、映射、新增几何与假设、前后缘及面积变化 | 接口的面与边划分一致；形状变化有依据；禁止盲目补洞和平滑 |
| 5 绑定与坐标转换 | 关节父子关系、轴、原点、零位、角度正号、限位、联动约束、权重、逆绑定矩阵 | 同一转换规则作用于点、法线、旋转与矩阵；检查实际导出文件 |
| 6 全动作验收 | 零位、单轴正负极限、组合动作、接缝与碰撞数据、截图或视频 | 动作方向正确；逐接口按定义验证；索引、蒙皮与整体曲面检查合格 |
| 7 几何取数 | 面积、翼展、弦长站位、后掠、截面、厚度和定义，来源表面版本及标定依据 | 来源曲面合格；未知材料、质量、惯量与系数保持未知 |
| 8 分用途发布 | GLB 与 USD、预览；流体表面与边界定义；动力学参数及各自资格记录 | 每个用途分别通过；版本可核对、可回退、消费者明确 |

“检查过”与“通过”分别记录。某个用途仍待核验，不阻止其他已经满足要求的用途试用，但必须在展示或取数入口保留资格状态。视觉动作正确不能替代流体边界验收；参数字段存在不能替代实际消费路径确认。

## 资产包与复现

每个资产包至少保存 asset_id、revision、源文件哈希、工具版本与配置、单位和标定依据、坐标定义、部件与接口表、机构及约束、几何数据、导出文件哈希和逐用途验收结果。来源纹理中的材质外观、物理材料参数、流体边界条件分别保存，不能相互推断。

原始文件只读保留。原始网格哈希、模型权重版本与推理配置共同标识特征缓存。几何修复改变点面索引后，旧标签和权重必须有显式映射，或者重新推理与绑定；“每个模型只推理一次”仅适用于该份未改变的输入网格。

几何改变后，重新进行曲面与几何取数检查；绑定、坐标或机构改变后，重新进行实际导出和全动作检查；渲染或媒体发布改变后，重新检查实际页面、视频与缓存版本。所有验收指向具体哈希，不能沿用其他版本的截图或结论。

## 当前 EagleX 的实施顺序

先恢复左右翼根的可靠匹配，并定义动态翼根接口，再消除尾根边划分不一致。随后在全动作下检查翼根、主翼与翼尖、尾翼与机身、两侧平尾与垂尾等接口，补齐整体曲面核验。完成这些后，再重新提取与登记几何；现阶段的提取值只作候选数据。

审计依据见 `logs/jane_dispatch_20261013/surface_lineage_audit/边缘与接缝诊断_20261013.md`。当前没有因为本草案而改变模型或发布新网格。

实际施工可沿原 I-201 接续 L8 的几何与绑定，L5 接入合格的预览与媒体，L3 追溯几何来源与登记。未来需要真实三维流体边界时，再由 CFD 业务线确认薄片或实体表达及边界检查要求。独立验收由未参与方案设计和实现的人承担；不得用流水线自行报告代替。

## 复用于巨龙资产

在当前研究阶段完成后，巨龙可以作为流程复用案例。复用源资产登记、质量检查、语义分件、接口定义、坐标、导出与验收工序；机构配置需要重新建立，不能直接套鸟的关节拓扑。

如果选定的资产包含翼指骨、连续翼膜、长颈和长尾，就分别定义骨链、膜面连续性与变形约束，先完成视觉和动作版本。若再研究气动与动力学，应将尺度、质量、材料和驱动能力作为独立的有来源数据或明确设计假设，不从幻想生物的外形直接推断。

当前不创建巨龙研究项目，也不让它挤占 EagleX 修复。先用 EagleX 将接口与资格流程跑完整，再把模型专属的路径、部件映射和机构配置移入独立资产配置，供下一种构型复用。
