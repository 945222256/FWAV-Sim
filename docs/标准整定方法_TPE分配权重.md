# 标准整定方法：分配权重的 TPE 整定流程（2026-09-28，可复用）

本文件定义一个标准流程。新增通道或新模态需要整定分配权重时，
按本流程执行，不重写工具。

## 一、输入（整定前必须齐备）

1. 通道响应函数登记表：《分配层规范_通道函数与状态门控.md》。
   新通道入表的条件：响应函数已实测拟合、域界已定、副作用已登记。
2. 评估核：tools/allocator_kernel.py 的 AllocTurnSim（持坡度闭环核，
   物理全部复用 v1 框架函数，分配层为唯一新增）。
3. 本文件第三节的入选判据（先于数据，运行后不改）。

## 二、整定域与目标

待整定量：四条滚转通道的分配权重 w_ail、w_dA、w_lag、w_rho，
各取 [0, 1]；分配规则 u_i = w_i·mx/eff_i(state)，按域界裁剪，
响应函数值非正的通道在当前状态下权重强制为零（不用反号通道）。

目标函数：J = 存活秒数 − 罚项（滚转误差中位、高度出带占比、
拍频越界、通道贴限占比）。TPE（tools/unified_search_v3.py 在案）
最大化 J。状态持久化在 logs/allocator_tune_state.json，
分轮续跑，不重跑已评估点。

## 三、入选判据（先于数据写定，运行后不改）

离线层（评估核内，坡度 10°、时长 20 秒）：
- 判一：全程存活（不触地、不发散终止）。
- 判二：t≥5s 段滚转误差中位数 ≤ 0.05 rad。
- 判三：高度带 [2, 4] m 内时间占比 ≥ 95%。
- 判四：拍频全程在 [1.0, 2.2] Hz 内。
- 判五：各通道行程不越各自域界（尾翼 ±0.30 rad、dA ±0.175 rad、
  滞后 ±0.02 s、密度 [0,1]）。

联合实测层（叠加性教训）：入选组合在巡航邻域点与转弯工作点各做
一次"全开实测对分配预测"，偏差 ≤ 20%（自定容差）。

在环层：《压坡度转弯试验_判据与方案.md》五条原文，不改。

## 四、产出形态

最优权重向量、整定曲线（J 随轮次）、入选组合的联合实测记录。
权重写入 config 的 ALLOC 节（默认关闭），在环经环境变量桥接。

## 五、复用规程（新通道或新模态）

第一步，新通道按《分配层规范》第一节格式登记响应函数与域界。
第二步，在 allocator_kernel.py 的通道表加一行（通道效能函数句柄、
域界、施加函数）。第三步，在 allocator_tune_tpe.py 的权重域加一维。
第四步，重跑整定。评估核、判据、TPE 流程均不改。
