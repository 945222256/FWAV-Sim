# 压坡度转弯·隔壁团队测试方案（2026-09-28 交付版）

> 用途：兄弟团队在本仿真工程内独立复现与判别。本方案自足，不需要
> 阅读项目历史。每个试验给出目的、配置、判据（先于数据，运行后不改）、
> 数据要求与结果解读分支。
> 工程根目录：G:\playground\isaac_flapper_sim。

## 零、运行方式与数据纪律（先读）

运行命令模板（Windows 环境变量前缀写法）：
```
FLAPPER_HEADLESS=1 FLAPPER_FLIGHT_LOG=1 FLAPPER_MAX_S=35 <试验开关> ^
  "g:/Playground/isaac_sim_5.1.0/python.bat" main_sim.py 2>&1 | tee logs/_run_<名字>.log
```
每次运行产出：logs/ident_stream_flight_时间戳.csv（高密度数据流，
姿态列为四元数 qw/qx/qy/qz）与 tee 的完整控制台日志。两条纪律：
其一，姿态一律从四元数换算欧拉角，不直读 roll/pitch 标签列
（历史错误来源）。其二，任何标定类数字必须与工况（姿态、速度、
角速度、拍频）同档记录，否则不可复现（首日教训）。

控制器健康自检已在库：自动驾驶仪缺席时仿真启动即终止并打印
[AUTO-FAIL]；看到该输出表示配置或代码有问题，不要拿那次运行的
数据下结论。试验开关全部默认关闭，关闭时行为与验收基线逐位一致。

## 一、E0 基线复现（半天）

目的：确认你们的运行环境复现我们的基线。
配置：不加任何开关跑巡航六十秒（FLAPPER_MAX_S=60）；
再按《docs/压坡度转弯试验_判据与方案.md》跑原科目一
（FLAPPER_BANK_TEST=1 FLAPPER_WING_MIX=1）。
判据：巡航八判据见 docs/巡航模态总结记录.md；科目一五条见判据文档。
解读：复现不了先查环境与资产版本，不要改动任何配置。

## 二、E1 阻尼保留版形态复现（半天）

目的：复现"巡航段干净、切入后失败"的形态分界。
配置：FLAPPER_BANK_TEST=1 FLAPPER_DUTY_MOD=1 FLAPPER_DM_PGATE=1
FLAPPER_DM_COEXIST=1 FLAPPER_WING_MIX=1。
预期形态（我们的记录在 logs/ident_stream_flight_0928_105343.csv）：
前五秒巡航段横向完全干净，切入后滚转不应指令，十二秒量级发散。
解读：复现则形态分界成立；若切入成功，直接转入 E4 报喜。

## 三、E2 无密度组合转弯（判别试验，一天，最关键）

目的：判别两个竞争假设——甲："时序死结"（密度权限只在低头区，
转弯进不去）；乙："俯仰稳健三通道（尾翼加幅值加滞后）增益整定
得当即可转弯"。本试验完全不用密度通道。
配置：FLAPPER_BANK_TEST=1 FLAPPER_WING_MIX=1 FLAPPER_DA3D=1
FLAPPER_DM_COEXIST=1（FLAPPER_DUTY_MOD 不开）。
增益档位：从整定首轮最优（logs/allocator_tune_20260928_105239.json
的 best_weights，注意其离线未入选、仅作起点）出发，KP_R、
ROLL_DAMP 各扫三档。
判据：科目一五条原文。
解读：任一增益组合过五条，则乙成立、甲不必要，转弯能力直接达成；
全部不过且失败形态均为权限饱和贴限，则甲升级为主导假设；
若失败形态为偏航发散而非权限饱和，则先查偏航抵消比在高拍频档
的退化（docs/压坡度转弯_归因测量.md 候选三在案）。

## 四、E3 俯仰下探转弯（甲的机理验证，不动基线，一天）

目的：把"权限随俯仰过零"的离线结论变为在环曲线：固定配置
（E1 配置加 FLAPPER_BANK_PHOLD=1），FLAPPER_BANK_PHOLD_DEG 取
−10、−14、−18 三档，逐档记录掉高与滚转跟踪质量。
产出：两条函数曲线——掉高(俯仰指令档) 与 滚转误差(俯仰指令档)。
判据：科目一五条原文（预计掉高判据在深档不过，属预期，记录曲线
形态比单次过不过更重要）。
解读：若滚转跟踪随下探单调改善而掉高单调恶化，则权限-高度权衡
成立，甲的收益代价函数直接可读出；若滚转跟踪不改善，甲的机理
链条断裂，转丙（构型级）。

## 五、E4 甲本体（动生效基线，契约级，需机主签字后执行）

内容：修复俯仰环稳态误差（积分门与稳态误差的匹配缺陷，第四十四轮
登记在案），使实际俯仰跟随指令。
前置判据（先于数据）：修复后先跑巡航六十秒，八判据不许有任何
一条退化；通过后才允许跑科目一。
风险提示：该改动触碰已验收配置，必须有可一键还原的开关形态。

## 六、E5 现场标定规程（半天，穿插在各试验前）

凡引用权限类数字，在你们的环境里重测一遍：停翼权限、幅值差动
效能、滞后差动线性域。工具：tools/quantum_async_check.py 与
tools/authority_response_grid.py 直接可跑。工况必须同档记录
（姿态、速度、拍频写进报告表头）。

## 七、已知陷阱清单

1. 标签列陷阱：姿态只信四元数换算。
2. 口径陷阱：配平俯仰根在不同工具间不一致，引用必须注明工具来源。
3. 力律不确定带：气动权限量级有三倍不确定带，符号类结论稳健。
4. 视觉不一致：停拍闸门只作用于气动力模型，关节画面照拍不误，
   不要拿画面判断停拍。
5. 叠加性：通道权限在高权限区可近似相加，在巡航姿态附近不可相加，
   组合必须联合实测。
6. 离线核口径差：离线闭环核的横向发散比在环快，离线结论对在环
   只作定性参考。
