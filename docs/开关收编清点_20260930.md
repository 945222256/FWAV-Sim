## 一 权威总数声明与清点方法

权威总数的声明如下。本仓库活代码中去重后的 FLAPPER_ 前缀环境变量开关共计一百一十个。此数是本清点的权威口径。

清点方法分四步执行。第一步检索直接字符串读取，检索式匹配 os.environ.get 与 getenv 两种调用形态中双引号内含 FLAPPER_ 前缀变量名的行。第二步检索下标读取，检索式匹配 os.environ 加方括号下标的读取行，此类行多数是先守卫后取值的同一开关的第二读取点。第三步核读循环间接读取，人工通读全部以循环变量为键的 os.environ.get 调用，并提取其循环元组内的变量名清单，此步发现三处循环间接读取族，分别是 modules/sim_env_bridge.py 起于第275行守卫在第281行的波形参数桥六项、起于第303行守卫在第347行的增益与激励桥三十项、modules/env_builder.py 第270行至第282行的场景属性桥二项。第四步核对通配读取，main_sim.py 第700行存在一处以 k.startswith 方式遍历全部 FLAPPER_ 前缀环境变量并写入台账元数据的通配读取，该处不引入新变量名，仅作记录。四步合计得直接与下标读取点一百零一处，涉及七十三个变量名，循环间接读取新增三十七个变量名，七十三加三十七得一百一十。

## 七 与此前调研数的对账

此前调研给出全仓去重后 FLAPPER_ 前缀环境变量开关约七十三个。本清点的直接字符串读取去重数恰为七十三，与此前调研完全一致，此前调研计数未包含循环间接读取项。权威总数一百一十等于七十三加三十七，三十七为三处循环桥内的间接变量数，其中波形参数桥六项、增益与激励桥三十项、场景属性桥一项。增益与激励桥在本清点进行期间由并行施工新增三项，即 FLAPPER_COORD_I_MAX 与 FLAPPER_K_DA 与 FLAPPER_K_DA_R，若按此前调研的时点口径计算，当时的总数应为一百零七。
