# 位置外环重整定预案（215 g 口径）

- 工作令：七项清单第六项预备（work/track-prep 分支，2026-09-20）
- 性质：**预案文档，不改配置**。执行前置条件＝路线 A 的在环 60 s 巡航
  验收过线；届时按本预案单变量推进。
- 验收工具：`tools/wp_acceptance.py`（"位置误差收敛且有界"操作化：
  稳态 95 分位 < 0.5 m 且收敛后超界占比 < 5%，阈值可调）。

## 一、现状声明

现有位置外环四参数（`config/sim_config.py:564-572`，Position 外环段）：

| 参数 | 现值 | 语义 | 整定对象 |
|---|---|---|---|
| KP_XY | 0.40 1/s | 位置误差→期望速度 | **700 g** 旧被控对象 |
| KI_XY | 0.15 1/s² | 位置积分（消 Fx(θ) 截距残差静差） | **700 g** |
| XI_MAX | 5.0 m·s | 积分限幅（pitch 触限时冻结） | **700 g** |
| TILT_MAX | 0.35 rad | 期望姿态角限幅 | **700 g** |

四个参数全部整定于 700 g 旧被控对象；215 g 切换（0920 夜班十四步）后
**均未重整定**。在环新被控对象上直接沿用旧增益无任何验收依据。

## 二、215 g 口径初值建议

**初值＝全部维持现值起步**。依据：

1. KP_XY 的安全上限由串级带宽比决定（外环 ≪ 速度/姿态内环），不直接随
   质量缩放。215 g 质量减轻 → 同推力加速度能力增大约 3.3 倍 → 内环更快，
   外环上限只会更宽裕而不会更紧；无证据支持预先缩放。
2. KI_XY 针对的静差源是 Fx(θ) 截距残差（~0.09 N，700 g 口径注释）。质量
   减轻后同残差力的加速度效果×3.3——静差敏感性升高，但积分需求方向
   （加/减）无法先验判定，须实测静差再动。
3. TILT_MAX 是安全限幅（悬停配平前倾 0.206 rad + 机动余量）。第 13 轮
   0.45 试验已证伪回退（静差同步扩大、净低头不变），无新证据不重开。
4. 盲目按质量比缩放（×0.31 或 ×3.3）无理论依据，违反单变量纪律的
   起步原则：基线未知时从已知点出发。

## 三、单变量扫描顺序（每步 50 s、全量记录、先记录后归因）

1. **KP_XY** ∈ {0.40（基线）, 0.55, 0.70}
   判据：位置阶跃/巡航跟踪无振荡发散；`wp_acceptance` 收敛指标改善或持平。
2. **KI_XY** ∈ {0.10, 0.15（基线）, 0.22}（在 KP_XY 定值后）
   判据：稳态静差消除且不引入超调/积分风暴。
3. **TILT_MAX** ∈ {0.35（基线）, 0.45}（仅当 1–2 步表明权限不足）
   历史警示：0.45 曾无效回退（见 sim_config 注释），重开需新证据。
4. **XI_MAX**（仅当静差残量仍在且积分饱和）
   视实测残量调，方向不定。

纪律提醒（测试纪律既有裁定）：单变量；timeout 50；增益无关同点坠毁＝
结构信号；欠采样均值不可作证据；日志声明对账交付。

## 四、执行清单（路线 A 过线后）

1. 复核 TRACKING_MODE＝"aero"（本预案全部针对气动跟踪模式；kinematic
   桥接联调不涉及本四参数）。
2. 加载 `data/wp_circle_r5.json` 巡航圆，按第三节顺序逐参数扫描，
   每组跑满 50 s 并全量记录。
3. 每组跑 `python tools/wp_acceptance.py <该组CSV>`，报告归档
   logs/wp_acceptance_*.md。
4. 定值后连续 3 组复验（防单次偶然），再进入下一参数。
