## 时钟与生成器

真实服务提供未回绕累计拍数。适配器读取

\[
\dot\chi_L=f_c+\Delta f,\qquad
\dot\chi_R=f_c-\Delta f,\qquad
\dot\chi_{fold}=f_c.
\]

右翼固定偏移已包含在服务的 `chi_R` 中，生成器不再加一次。`shape_phase_rate` 的单位是 rad/beat，不能当作 Hz。单次进度为

\[
p=(\chi_c-\chi_{origin})/B,\qquad \dot p=f_c/B.
\]

`B` 是程序明确声明的拍数预算；本版首个程序声明 3 拍。它是可选合作动作的新程序参数，不冒充既有以秒定义的线性启动斜坡。本版单次 DMP 作为启动幅值包络，使用此程序时不能再额外乘旧启动斜坡。

周期 DMP 从参考函数的值与相位导数导入初始状态。可执行示例采用基频加二次谐波，保留独立归一化版本、形状权重和参考导入记录；这是一份可选动作资产，尚无飞行性能结论。工厂参数 `flap_backend="analytic"` 仍可选择解析拍动资产。

## 装配、导数与现有控制器

`constant_coefficients()` 将 I-219 已采用参数声明为本段保持的程序，分别保留：

- 拍动中心 `center`，包括已有中置上反；
- 幅值与幅值差动 `scale + amplitude_differential`；
- 旧角偏置与控制修正 `legacy_angular_offset + control_correction`；
- 尾舵的已采用绝对目标、已有配平身份；
- `lag_s` 和门控请求原值，不把秒滞后偷换成角偏置，也不擅自把气动力门控改成关节幅值。

对时变程序，调用方必须传入 `ScalarJet(value, velocity, acceleration)`；缺少的导数填 `None`。明确光滑程序用 `continuity="smooth"`，保持段之间的值跳变按事件边界处理。对真实输出

\[
q=\operatorname{sat}(\mu+a z+c)
\]

沿用原统一输出规则和链式导数，并在 `outputs[joint].unsaturated` 保留请求量。无法求出的导数、频率跳变、相位事件和参数跳变不会作为普通零导数发布；真实常值、冻结段和饱和段的零导数仍有其正常含义。声明近似身份保持，不自动升级为精确可用。

非零秒滞后必须由 I-222 的历史/预测解析器通过 `clock_overrides` 提供同一物理步的规范坐标及导数；材料不足则明确拒绝该步并保留生成器最后有效帧，不能用“当前频率乘滞后”代替真实历史。本次没有更改已有滞后控制或默认行为。门控请求的气动力采用仍归 I-223。

## 状态、事件与预览

| 触发 | 本次实现的策略 |
|---|---|
| 普通读取、同一输入重复读取 | 返回已提交动作，不再推进；同一步冲突输入拒绝 |
| 周期回绕 | 未回绕相位继续，DMP 状态不重置 |
| 停拍/复拍 | 时钟与基元继续；输出幅值包络关闭/开启；跳变边界导数不可用 |
| 冻结/解冻 | 子时钟和单次进度随共同服务冻结/恢复；冻结段真实导数为零 |
| 复位 | 采用实际消费的 reset 事件，恢复所声明的原始时钟锚点和形状初值；运行中接入需显式提供原始锚点 |
| 锁相修正 | 重定位周期坐标，保留内部形状状态；仅积分本次真实步预算，边界导数不可用 |
| 模式切换/释放 | `switch()` 采用调用方已准备、在当前步边界初始化的程序；下一步前仍可读取上一个实际动作；过渡/保持由替代程序显式选择 |
| 耦合反馈 | 周期基元入口检查单位、已声明的唯一 owner 和出口；解析/保持提供者不能默默吞掉反馈 |
| 异常 | 在隔离副本计算后发布，失败保留本生成器的最后有效状态；共同服务的原子提交由其所有者负责 |
| 预览 | `clone()/on_preview_step()` 接入 I-220 真实 PreviewEngine；权重、缓存和帧均隔离；`preview_actions()` 返回明确带 preview 身份的动作帧 |

预览执行副本上的已排定频率程序与事件；未知未来闭环输入、系数和未排定的模式动作保持当前值。非零滞后解析器未提供时不生成伪预览。
