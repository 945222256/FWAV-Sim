# I-043 前向力与侧力取列口径决定（2026-10-03）

> 事项 I-043：Fx 与 Fy 列同源分摊口径待裁。销项判据为决定取列口径
> 并统一全部取列点、决定书面登记。总部把决定权交本事项执行，本文件
> 即书面登记。

## 一、决定

决定为：判据与评估工具的前向力取 Frx 列（每步合计），侧力取 Fry 列
（每步合计）；Fx 与 Fy 保留为诊断列并在取列处注明分摊口径；旧时代
记录缺合计列时按二倍分摊值回退。决定理由与升力列决定（I-030 记录）
同一物理依据：判据的物理含义是每步实际受力总和，分摊值是记录侧的
触发次数均摊，不是物理量本身。气动回调每物理步触发两次，分摊列与
合计列之比实测为二，与升力两列比值同源同值。

## 二、执行范围与残留

全库活跃取列点中消费前向力与侧力的共两处，本轮统一：其一，
tools/analyze_ident_stream.py 扫频表的前向力展示列由 Fx 改 Frx；
其二，tools/analyze_bench.py 配平表与风表的前向力回归列由 Fx 改
Frx。两个工具的加载层同步补齐三组合计列（Frx、Fry、Frz），旧档案
无合计列时按二倍回退，回退式与记录器列头声明一致。

取列点定性：回放台与基准运行器此前已取合计口径，无前向力判据消费；
离线考卷族的 Fx 为离线模型自评命名，非数据流列，冻结豁免；历史带
日期档案留痕豁免。侧力列在活跃判据工具中暂无消费点，本次仅在加载
层补齐合计列备用，属预防性统一。

验证：两个工具在新旧两代记录上实跑冒烟通过，新记录与旧记录的配平
表均正确输出 Frx 与 Frz 列，语法检查通过。

## 三、判据对照

销项判据三项：决定取列口径（本文件第一节，前向力与侧力取每步合计，
明确列名与回退式）；统一全部取列点（第二节执行范围，活跃消费点两处
已改，豁免类逐类定性）；决定书面登记（即本文件）。
