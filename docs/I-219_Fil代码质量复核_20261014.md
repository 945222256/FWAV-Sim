## F01 尾舵配平被重复加入

**优先级 P1。涉及判据三、四及首配方尾舵绑定。** 位置：[参数装配第 250 行](G:/Playground/isaac_flapper_sim/modules/motion_action/parameters.py:250)、[左右尾参数第 262 行](G:/Playground/isaac_flapper_sim/modules/motion_action/parameters.py:262)。

装配器把尾舵中心设为配平值，又把缺省升降命令设为同一个配平值，然后把升降命令加入控制修正。按该模块声明的“中心加尺度乘形状加控制修正”规则，即使保持通道不贡献周期形状，配平也会加两次。显式自动升降指令在旧驱动中是绝对需求，新装配却仍额外加上配平。

当前配置的配平为 0.08 弧度，真实函数对照如下：

| 输入 | 新装配左尾／右尾 | 旧真实驱动左尾／右尾 |
| :--- | :--- | :--- |
| 无尾舵指令 | 0.16／0.16 | 约 0.08／0.08 |
| 明确升降与副翼为零 | 0.08／0.08 | 0／0 |
| 升降 0.11、副翼 0.03 | 0.22／0.16 | 约 0.14／0.08 |

旧侧使用原生写入的单精度类型，“约”表示该转换的数值尾差；缺陷是整项 0.08 弧度偏差，不是精度尾差。复现结果对应 `tail_no_command/tail_explicit_zero/tail_auto_command`。

**最小修订：**明确尾舵绝对命令与相对配平修正的身份。沿用当前旧语义时，无指令选择一次配平，有显式升降指令则按原升降加减副翼构成目标；不能再加第二次配平。保持提供者和参数装配也要约定由谁唯一持有该命令，防止后续再把同一命令放入形状项。增加缺省、明确零值和非零自动需求的最终目标检查。

## F02 配方校验没有覆盖真实关系图和单位

**优先级 P1。涉及判据六及节律补充一。** 位置：[节点字典与关系检查](G:/Playground/isaac_flapper_sim/modules/motion_action/types.py:243)、[父链遍历](G:/Playground/isaac_flapper_sim/modules/motion_action/types.py:253)、[装载异常转换](G:/Playground/isaac_flapper_sim/modules/motion_action/types.py:324)。

当前校验从节点的 `parent` 字段检查环，却没有对 `parent_child` 关系本身构建并检查完整图，也没有检查两份父子定义是否一致。通过真实 `load_recipe` 得到以下结果：

| 非法变体 | 实际结果 |
| :--- | :--- |
| 节点父引用改为不存在的 `ghost` | 抛原始 `KeyError`，没有配方文件／节点的定位错误 |
| 增加同名节律节点 | 被接受；字典构造会覆盖同名定义 |
| 保持节点坐标为累计拍数，将其单位改为弧度 | 被接受 |
| 同一子节点重复声明父子关系 | 被接受 |
| 只在关系表中加入反向边，形成父子派生环 | 被接受 |
| 差动来源改为不存在的 `ghost` | 被接受 |
| 重复同一提供者和节点绑定 | 被接受 |
| 节点加入错误字段 | 抛原始 `TypeError`，没有配方定位错误 |
| 频率比例为非有限数 | 被接受 |

“提供者读取坐标等于节点坐标”的现有检查可以保留，但它没有验证节点坐标与单位是否对应。当前校验也不能支持交付清单声称的全部未知引用、父子环、单位冲突和重复写入诊断。

**最小修订：**先检查名称唯一性、必需字段、引用及坐标／单位组合，再检查派生关系；统一父子定义，或验证两处定义一致。对关系图检查环和重复出口，耦合环仍按已批准语义单独处理。差动来源的命名空间须明确并验证。结构错误统一转换为包含文件、字段、节点或通道的 `RecipeError`；避免引用不存在节点时先触发字典异常。

## F03 折翼相位在两处重复定义

**优先级 P1。涉及判据二、四及首配方共模折翼关系。** 位置：[派生偏移](G:/Playground/isaac_flapper_sim/config/motion_recipes/cooperative_v1.json:98)、[左折翼参考](G:/Playground/isaac_flapper_sim/config/motion_recipes/cooperative_v1.json:215)、[右折翼参考](G:/Playground/isaac_flapper_sim/config/motion_recipes/cooperative_v1.json:231)。

折翼子节点相对共模已经声明偏移 0.3508 拍，参考函数又写为 `sin(2*pi*chi_fold + 2.2)`。按两条声明同时采用，偏移是 `2*pi*0.3508+2.2 = 4.4041414058` 弧度；已批准首配方保留的是 2.2 弧度一次。交付清单也同时描述了这两项，没有定义某一项只是显示注释。

这确认的是配方定义冲突；节律和轨迹执行器尚未交付，不能说真实机翼已经发生这项相移。

**最小修订：**选择一个唯一位置存储偏移。若保留参考函数中的 2.2，子节点偏移为零；若把偏移纳入子节点，参考函数只读该子节点，不再加 2.2，并使用明确转换来源，避免四位小数近似另外引入偏差。装载后的规范表示应能说明偏移只采用一次。

## F05 通道策略函数存在但没有接到实际装配

四种策略函数可以单独计算，但实际装配输入没有逐通道策略、模式转换或上一采用值。装配入口只在升降缺省处理中调用缺省策略，其余指令多直接缺省为零。真实复现中，方向舵先装配 0.2，下一次缺失指令直接得到零；保持策略单独调用可以得到 0.2，却没有入口把这个选择应用到该通道。这不代表缺省方向舵必须保持，而是交付尚不能执行不同通道声明的保持和模式退出策略。

**最小修订：**逐通道登记并传入策略、模式和必要历史，或明确由入口先执行策略，再让装配器接收已采用值。后者需有可验证的生产调用接口，而不能只留下一个独立工具函数。缺失、未支持、明确零值应进入采用记录；门控和差频属于哪个输出或独立输入，也须固定。

## F07 关节限位来源与已有机构资产不符
