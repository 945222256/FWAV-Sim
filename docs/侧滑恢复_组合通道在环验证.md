# 侧滑恢复：偏航抵消组合通道在环验证（2026-09-27）

> 验证对象：尾翼差动为主、机翼幅值差动与滞后差动按实测偏航效能比值
> 混合（一比一抵消偏航注入）的组合通道。
> 方法：巡航状态六十秒升格配置原样不动，五秒时施加横向速度脉冲
> 正一点五米每秒，对照组与试验组各跑二十秒完整仿真。
> 纪律：组合通道默认关闭（配置开关 WING_MIX_ON，缺省 False）；
> 脉冲功能默认关闭（环境变量驱动）；两次运行除开关外配置逐位相同。

## 二、结论与边界

结论：组合通道把侧滑脉冲响应从"发散坠地"改为"存活且姿态有界"——
滚转角峰值降到三分之一，偏航角速度峰值降到十三分之一，触地消除。
这是偏航注入作为失稳放大器的直接证据：抵消偏航注入后，同一扰动
不再被放大成旋转发散。

边界（如实申报）：其一，恢复不完整——试验组在十五秒后仍有约二米
每秒的残余横向速度，姿态稳住了但侧滑没有消除，飞机处于"受控漂移"
状态；其二，两组尾翼差动指令都顶到零点三零弧度限幅，权限余量在
大扰动下仍然薄；其三，末段仍有缓慢爬升（末高四点八二米），与巡航
模态的末段爬升现象同族；其四，本验证只覆盖单一扰动幅值与单一
工况点，扰动幅值与工况的扫描是后续工作。

## 三、与测量预测的一致性

离线测量预测：幅值差动的偏航副作用（正零点二零九）与滞后差动的
偏航效能（负零点二零九）等大反号，一比一混合可消除偏航注入。
在环结果与该预测方向一致（偏航角速度峰值降到十三分之一）。
一致性是定性的；定量复核（偏航力矩逐项对账）列为后续工作。

## 四、实现位置（平行新增，默认全部关闭）

- config/sim_config.py：FlightControllerConfig 新增 WING_MIX_ON、
  WING_MIX_RATIO、WING_MIX_DLAG_MAX 三项，缺省关闭。
- modules/flight_controller.py：滚转通道在组合开关开启时附带滞后
  差动输出（dlag 键），缺省输出零。
- main_sim.py：环境变量桥接（FLAPPER_WING_MIX、FLAPPER_SIDESLIP_PULSE
  三件套）、dlag 力模型注入、侧滑脉冲施加块。
- 全部改动在开关关闭时与生效行为逐位一致。
