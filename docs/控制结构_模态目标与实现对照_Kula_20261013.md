# 扑翼控制结构：模态目标与实现对照

> 整理：Kula · 核对日期：2026-10-13（Asia/Shanghai）  
> 范围：当前工作区的自动驾驶调用链、相关模型与规格。表中“已有”分别标明接入实现、局部实现或规格；不据此推定整机验证通过。本文是技术解释与知识档案，建议部分尚不构成已批准工程方案。

> **本轮独立核实更正：**工作区已出现提交 `054e0f9` 的有效拍频选择实现；新发生器输出现在可以在开关启用且数值有效时进入驱动。原“没有生产消费者”的说明由本次更正替代。开关默认关闭，现有隔离测试不能替代实际关节、气动效果及整机收益验证。后续方案见[下一步升级表达](Kula_下一步升级表达方案_20261013.md)。

**判断：以可实现的目标集合或流形描述一种运动，再设计闭环使系统保持在目标上、偏离后能够返回，是成立的控制设计方向。目标是否不变、是否具有吸引性，必须相对于指定的系统、控制律、参数和适用范围核实。**

## 一、先区分四件事

| 概念 | 具体含义 | 本项目需要回答的问题 |
| :--- | :--- | :--- |
| **目标集合或流形** | 用状态之间的关系规定所需运动，例如周期运动轨道、轨迹跟踪的零误差集合。流形还要求局部具有合适的光滑结构；一般集合不必满足此要求。 | 目标包含哪些机体、翼、执行器和控制器状态？位置漂移和拍相位如何处理？ |
| **不变性** | 在指定闭环下，从集合内开始的状态持续留在集合内。候选目标必须先能由受约束的执行器产生。 | 存在什么可执行的输入，使目标关系一直成立？参数变化和模态切换如何改变这个关系？ |
| **吸引性与稳定性** | 吸引性说明附近状态逐渐靠近目标；稳定性说明小偏离不会先变成过大的偏离。二者需要分别核实。 | 哪些误差收敛、允许多大初始偏离、沿途是否满足运动和执行约束？ |
| **模态切换** | 连续动力学体制改变时，还须处理切换条件、状态变化及新目标的适用范围。 | 前一模态的离开状态能否进入后一模态的可恢复范围？ |

对周期运动，通常要求横向偏离衰减，允许状态继续沿周期轨道推进；若任务还要求指定时刻的相位或左右翼同步，则需另加相位约束。可参考[麻省理工学院的轨道稳定性与横向坐标说明][T1]及[周期轨道横向收缩研究][T2]。混合系统还须处理事件与连续段共同组成的闭环，见[混合周期轨道研究][T3]。

**适用条件：**不应把任意画出的几何集合直接称为不变集；也不应要求所有有限时长机动都成为长期吸引子。移动的轨迹、变化的速度或坡度参考，适合在跟踪误差或扩展状态中定义目标。扰动存在时，还需明确是在证明精确收敛，还是只能保持在目标附近的误差范围内。

**结构上的关键关系：**任务与参考运动 → 根据状态误差提出控制需求 → 分配并生成翼动作 → 执行与动力学 → 测量状态并反馈。若使用显式冲量，可在控制需求与动作分配之间定义期望冲量，在动力学侧核实实际冲量；现有控制不必为此先改写成冲量形式。

## 三、已有吸引结构具体在哪里

由 Hopf 参考内核的连续时间右端式可得，令 r 为发生器内部状态 (x,y) 的半径：

$$
\dot r=\kappa(A^2-r^2)r.
$$

在 **A>0、κ>0、参数固定且相位速度剖面有效** 时，目标圆 r=A 是这个连续时间发生器的不变轨道，非零半径的邻近状态会向它靠近；原点 r=0 仍是另一个不变状态。这一结论来自内核方程的解析推导，离散步进仍须检查数值误差。[S5] [洛桑联邦理工学院的可编程发生器研究][T4]也采用稳定极限环表达周期动作。

**这里的目标圆位于发生器内部状态空间。** 飞机的目标运动还涉及机体速度、姿态、执行器响应、气动力和控制器状态；当前新发生器输出已有拍频条件消费，但完整轨迹、实际动作和机体恢复未由此成立，因此不能由这个圆推出整机已有相应飞行吸引子。A 或其他参数变化时，目标也随之变化，需要另行分析跟踪和切换过程。

本轮数学核实还发现两项范围限制：参考输出映射按目标幅值 A 生成翼角，没有直接使用实际内部半径 r；当前控制器移植在步首计算半径项和相位速度，再固定供四个数值子步使用，与参考内核每个子步重算右端不同。因此参考连续方程的径向收敛不能直接作为当前离散实现、真实翼幅或整机恢复的证明。[S5][S7]

## 四、候选目标怎样选才贴合运动

以下为 Kula 的设计解释，尚未构成冻结目标定义或工程批准。

| 运动或体制 | 合适的候选表达 | 需要核实什么 |
| :--- | :--- | :--- |
| **稳定巡航** | 在去除沿航向位置漂移的状态或跟踪误差中，定义含拍相位的周期运动。 | 波形、平均运动和控制器内部状态是否一致；偏离后是否稳定恢复。 |
| **稳定转弯** | 在参考路径或旋转坐标中，定义速度、曲率、姿态及周期翼动作的关系。 | 目标是否同时满足所需平动与转动动力学；不能仅凭坡度目标判断路径成立。 |
| **停拍滑翔** | 定常滑翔关系，或有限驻留时长内的轨迹与允许误差范围。 | 滑翔中的能量变化、驻留条件、保持姿态和复拍后的恢复；不预设恒高恒速目标可持续。 |
| **切入／停拍／复拍** | 带切换条件的过渡轨迹，以及前后目标之间的状态映射。 | 切换后状态是否进入下一段的适用与可恢复范围；连续段稳定不能代替切换验证。 |

## 五、这份表支持的结论

**已有：**能量协调、姿态与角速率反馈、参数化周期波形、多个执行通道、周期平均气动力、局部逐拍控制，以及模态／事件规格和分析工具。

**尚未由当前主链成立：**统一运动族、明确的整机模态目标不变集及吸引范围、新发生器完整轨迹与实际关节效果取证，以及经过实际动作和状态变化核实的统一冲量预测／反向分配。新发生器的拍频消费者已经存在，不再列作零消费者缺口。

下一份目标定义材料至少应明确：目标属于哪个状态空间、固定哪些参数、允许哪些输入、偏离量如何计算，以及用什么依据判定保持与恢复。此建议不要求把所有运动都强行设计成同一种长期吸引子。

另有导航轨迹跟踪支路，在 kinematic（运动学）模式下直接写机体速度；它的轨迹表现须按该执行方式解释，不能作为以上扑翼气动闭环的证明。[S16]
