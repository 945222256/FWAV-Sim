# 新机器接入云端账本三步手册（I-031 第四期配套，2026-10-06）

> 需求文档 FR-5：新机器接入动作固定为三步——安装代理、领取令牌、
> 注册自身。完成后自动出现在任务板并开始认领。本手册把三步落成
> 可照抄的命令，服务第四期第二台机器的接入验收。

## 前提

新机器装有 Python 三点十以上与项目仓库的 git 检出（任何一路施工队
形态），能访问云端域名 personal.karmicsword.com。

## 第一步：安装代理

代理即仓库内的 items_registry/cloud_client.py，无第三方依赖。
在仓库根目录建同步目录与模式开关：

    mkdir lp_sync
    在 items_registry 目录新建模式开关文件，内容写 cloud 一词

该开关文件内容为 cloud 时，本地账本工具（dispatch、ledger）自动切换为云端
客户端：读走快照缓存，写走接口，断网入队恢复重放。

## 第二步：领取令牌

令牌由机主在服务器侧签发（明文只出现一次，库里只存哈希）。
机主在服务器执行：

    cd /opt/lpboard && python3 -c "import auth; print(auth.issue_token('<机器名>', ['L1','L2','L3','L4']))"

路线清单按该机器的施工分工裁剪。把打印出的令牌字符串交给新机器，
写入文件 lp_sync/agent_token（单行）。凭证文件已被 git 忽略，不会
入库；泄露即吊销重发。

## 第三步：注册自身

任意一次心跳即完成注册（认领、看板、同步都会触发心跳）：

    python -c "import sys; sys.path.insert(0,'items_registry'); import cloud_client; cloud_client.sync_cache(force=True)"

成功标志：任务板的代理清单出现该机器名（注册事件入事件流），
且本地 lp_sync 下生成缓存文件。

## 接入后验收（第四期多机判据用）

两台机器各认领一个不同事项，互不干扰；同抢一个事项恰一成功。
双代理并发试验脚本 tools/verify_i031_dualagent.py 可在新机器上
重跑，命令与判据见该脚本文件头。

## 安全边界

令牌只授该机器需要的路线；认领路线一致性校验（I-093）在服务端
强制，跨路线认领一律拒绝；一切写操作走令牌或机主会话，匿名全拒
（I-042 审查在案）。
