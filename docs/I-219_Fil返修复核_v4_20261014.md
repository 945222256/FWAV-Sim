### 原判据五：扭转角速度需求已补齐

[求力需求表](G:/Playground/isaac_flapper_sim/modules/motion_action/types.py:410)新增左右扭转通道的扭转角速度，单位 rad/s；旋转力开启时该量必需，不可用时记为消费无效，关闭时不强制。已有拍动导数需求保留，附加质量与旋转力两个开关各自控制相应需求。

Fil 使用真实生产模型构造函数分别设置两个开关，对照同一真实力核的有效值与不可用值，四种组合均与需求表相符：

| 附加质量力 | 旋转力 | 拍动角加速度需求 | 扭转角速度需求 | 真实函数与表相符 |
|---|---|---|---|---|
| 关闭 | 关闭 | 不强制 | 不强制 | 是 |
| 关闭 | 开启 | 不强制 | 必需 | 是 |
| 开启 | 关闭 | 必需 | 不强制 | 是 |
| 开启 | 开启 | 必需 | 必需 | 是 |

所有组合仍需拍动角速度；本轮没有要求扭转角加速度或尾舵导数。关闭附加质量力不会取消旋转力开启时的扭转角速度需求。

原 v3 反例在新版上保留复测：扭转角速度由 0 改为 2 rad/s 时，旋转力开启下机体系力变化为 `[0, 0, 0.06223808]` N，力矩变化为 `[-0.0127826163, 0.0030741260, 0]` N·m。该值不可用时真实求力失败，与本版“消费无效”契约一致；旋转力关闭时可缺失，改变扭转角速度不会改变输出。这次需求表确实覆盖该消费者，而非只记录已存在的表行。
