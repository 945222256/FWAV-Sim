# 术语标准与现行结论（强制使用版）

本文件是后续全部汇报与文档的强制用词标准。任何人（含代理）向用户汇报时必须使用本文件的表述方式。移交前自查三次措辞。

## 一、强制句式规则

1. 每句必须具备主语、谓语、宾语。
2. 首次出现的术语必须当场用一句话定义；没有定义过的词禁止使用。
3. 每个结论必须给出数字或数据出处。
4. 禁止使用下列内部用语：考卷、上环、全绿、锚点、定证、挂账、钉固、翻案、秒表、族（单独使用时）、亏损项（须按本文件定义展开）、打脸、拍脑袋。
5. 禁止比喻与口语。

## 二、核心术语的标准定义

**波形参数**：描述翅膀拍动姿势的五个数值（攻角设定、扑动面偏置、上下扑时间比、时间相位、拍动幅值）。一组数值代表一种拍动姿势。

**波形类别**：按物理性质相近划分的姿势群体。例如上下扑时间比大于零点五的姿势构成一类（下扑快的一类），小于零点五的构成另一类（上扑快的一类）。两类之间的力学行为可以完全相反。

**控制器参数**：决定自动驾驶仪如何根据飞行状态调节舵面与拍频的数值，共十二个。

**简化计算**：用降阶数学模型快速评估大量候选参数的方法。它的评估速度快但精度有限。

**完整仿真**：把候选参数装入全物理仿真软件（Isaac Sim），让虚拟飞行器完整自主飞行六十秒并按事先声明的标准评定。它是最终裁定手段。本项目不存在任何真实物理飞行器试验。

**力矩差值修正项**：真实飞行实测的力矩与简化计算算出的力矩之间的固定差额（实测值约负零点零九一牛米，即真实抬头力矩比简化计算承诺的少这个数）。该差额在第六十班被作为固定修正加入计算。

**姿态建立**：飞行器从释放瞬间的受冲击姿态恢复到工作姿态角的过程，时长数秒。

**判据**：事先声明的、裁定候选参数通过或不通过的数值标准。现行八条：力矩需求不超舵面能力七成、升力比不低于零点九五、六十秒存活、高度在二至八米带内、姿态偏差不超零点零五弧度、舵偏均方根不超满偏七成、拍频偏差不超零点三三赫兹、推力随拍频变化为正方向。

## 三、现行结论的标准表述

**结论一（已通过事项）**：升力、拍频稳定、横向零扰动三项已在完整仿真中达标（第五十班数据）。

**结论二（现行唯一障碍）**：姿态建立过程的力矩收支存在约百分之九的赤字（抬头需求比舵面实际能力多百分之九），导致机头抬不到工作角度、飞行器缓慢下沉。该赤字在参数可调范围内未找到解（第六十班，三千余组评估）。

**结论三（该结论的已知风险）**：上述百分之九的赤字数值只在同一类别（下扑快的一类）的两次失败飞行上实测过，被当作了全部类别的共同数值使用——各真实折扣可能不同。跨类别实测检验正在进行。

**结论四（历史教训）**：本项目曾出现四次"宣称不可行、最终查明是计算或口径错误"的事件（数据列读错、公式符号写反、两套计算器口径不一致、仿真器符号错误）。因此任何"不可行"结论在被跨类别检验前，一律不得视为最终定论。

## 四、待用户裁定的三选项

1. 起飞阶段施加零点零三至零点零五牛米的临时辅助抬头力矩（需修改主程序，属结构改动）。
2. 按波形类别分别实测各自的力矩差值修正项（需两至三次新的完整仿真实测，然后重搜）。
3. 放宽姿态判据的适用时段（只考核平稳巡航段、豁免姿态建立段；属降低验收标准）。
