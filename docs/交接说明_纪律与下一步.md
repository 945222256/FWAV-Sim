## 一、工作纪律（不可协商，全部来自已付过的代价）

1. **判据先于数据。** 任何试验的通过标准写成文档并提交之后，才允许
   运行；运行后不允许修改判据。
2. **失败证据先行存档，配置用完即还原。** 每次失败先保存记录再分析；
   试验开关全部默认关闭，关闭时行为与生效配置逐位一致。
3. **平行新增，不动生效基线。** 新模型、新通道、新功能一律以开关或
   新文件形式加入，旧文件与旧配置保持可一键还原。
4. **先查代码与逻辑，后归物理。** 本项目历史上多处"物理障碍"最终被
   证明是程序错误或读数口径错误；遇到异常先检查符号、口径、单位、
   作用域，再谈物理。
5. **测量纪律三条。** 时间轴全局单调推进（拍动相位是积分状态，时间
   不许重置或回跳）；每次求值显式设定拍频；配平终值与冲量类结果
   用每周期二百八十八点采样，粗扫可用七十二点。
6. **约束必须是函数。** 约束以状态为自变量的函数或拟合曲线表达；
   没有拟合出函数的条目不写具体数字，只登记占位并写明缺什么测量；
   策略性取值集中在声明段并逐条标注"自定、可调"。
7. **语言纪律。** 每句话主谓宾完整；术语首次出现给完整定义；不使用
   比喻，不使用自创缩略词；禁用词：伪影（改用模型失真分量）、记账
   （改用逐项登记并留痕保存）、定案（改用确定取值）、"账"的比喻
   （改用损失）、锚点（改用考核工况或校准检验）、钩子（改用检查项）、
   滚转权限（改用滚转操纵效能）。
8. **每个提交一句话说清改了什么、为什么。** 提交信息写结论与依据，
   不写过程感受。
9. **每次验证假设的测试必须看得见（2026-09-28 用户令）。** 凡开数据流
   的在环运行，事后必须能用 tools/flight_replay_gui.py 双击回放全自由度
   （机体六自由度+翼面关节+闸门），并给记录补 tag 与 description
   （GUI 内编辑保存）；无 tag 的记录在侧栏红标，视为测试未收尾。
   **执行机制（2026-09-28 升级为启动必填）**：开 FLAPPER_FLIGHT_LOG 的
   运行必须在启动时声明 FLAPPER_TAG 与 FLAPPER_DESC，缺一在仿真启动前
   即被 [TAG-FAIL] 拒绝；元数据随数据流开档自动写入 sidecar。豁免口
   FLAPPER_ALLOW_NO_TAG=1 仅限纯排障，其数据不得用于下结论。
   数据流自 2026-09-28 起共九十三列完整档案：逐叶素快照（每翼十四站
   行程位姿+站上力，瞬时子样口径）、全关节位置与驱动力矩（九自由度
   全量）、每翼频率/闸门/滞后差动、总合力与分翼分尾力矩；关节约束力
   接口在本 Isaac 版本触发原生堆损坏已弃用（恒空列，获取途径登记
   待办）；老记录缺列由回放端补默认。

## 二、接下来四步（按顺序，每步含执行方法与产物）

### 第一步：归因测量——持续坡度保持工况的滚转环响应

- 目的：把科目一失败的三条归因候选（横侧增长模态被持续激励、拍频
  顶上限后工作点失效、坡度姿态下混合比值失效）定到一条。
- 方法：离线钉固状态测量，不飞。在坡度十度姿态、拍频取科目一实测
  轨迹段内的值（一点九四至三点五赫兹逐档）、侧滑角零至正负十二度
  网格下，测三条通道的滚转与偏财力矩响应，并与机翼水平姿态的
  《侧滑工况横侧通道效能》数据对照。
- 工具：以 tools/scan_sideslip_channels.py 为骨架复制新文件，
  加坡度角维度；原版不动。
- 产物：测量报告，写明哪条候选成立或都不成立。
- 通过标准：三条候选中至少一条被数据明确支持或被明确排除。

### 第二步：按归因结果修正并重跑科目一

- 方法：第一步定到哪条就修哪条——模态激励则调整阻尼分配，工作点
  失效则把坡度工况的拍频基准移出变号区，混合比值失效则在坡度姿态
  下重测比值。修正后按原判据重跑科目一，判据不改。
- 产物：新的运行记录与结果报告；无论通过与否，证据先行存档。
- 通过标准：《压坡度转弯试验_判据与方案.md》五条。

### 第三步：科目二——盘旋中扰动恢复

- 前提：科目一通过。
- 方法：科目一配置加十五秒时的横向速度脉冲（环境变量三件套），
  对照组与组合通道组各跑一次。
- 产物：两组数据流与对照报告。

### 第四步：转弯模态并入搜索框架与文档口径合并

- 方法：在 tools/unified_search_framework_v2.py 里新增"压坡度转弯"
  模态模板（协调盘旋角速度函数、滚转力矩需求对联合效能的函数、
  侧滑升力方向函数为约束）；统一两份文档的权限预算系数口径
  （七成对五成）；把 v2 补入《巡航模态总结记录》第六节脚本清单。
- 产物：模板代码与口径合并提交。
