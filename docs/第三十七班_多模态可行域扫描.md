# 第三十七班：多模态可行域边界扫描框架（2026-09-25）

本班按用户指令建立多模态可行域边界扫描框架，替代/升级单点寻优：不再逐跑
修改一个控制量观察结果，而是把丙组九控制参数与波形五参数容差方向张成
变量空间，对四个飞行模态分别做网格扫描、判据布尔归类与边界提取，最后
求模态交集。产物三件：`tools/feasibility_map.py`（通用框架）、
`logs/feasibility_map.json`（全部逐点结果与半径表）、本报告。

## 一、方法论

- 模态 = 三元组（工况、判据函数、输入）。四模态并行（multiprocessing
  四进程），逐模态独立扫描后求交。
- 变量 = 丙组九控制参数（各 7 点轴向网格 + 两片二维切片
  KP_A×PITCH_DAMP、TECS_KF_P×TECS_KV_F）+ 波形五参数容差方向
  （波形本身固定为甲组签核值，只测 ±5%/±10% 容差被闭环吸收的能力）。
- 每模态两轮：第一轮以第九跑现值（名义点）为中心扫轴向与切片；第二轮
  以第一轮最优可行点为中心再做九轴补测，供内切球半径用。
- 边界提取 = 轴向可行/不可行归类 + 保守边界（符号变化处取不可行侧）。
  鲁棒半径 = 以最优可行点为中心、参数按各自半范围归一化后，无穷范数
  度量下可行域最大内切球半径（= 逐轴到最近不可行样本距离的最小值）。
- 判据先于数据（各模态判据函数固化在框架内，见 §四）。

## 五、扫描结果（20260925_190026 运行，dt=4 ms，M1~M3 视界 60 s、M4 3 s）

### M1 定高定速巡航：非空，可行 52/244 点，内切球半径 0.333（归一化）

- 名义点（第九跑九参数）不可行：14.2 s 缓沉坠地（z_min 0.20），失效
  模式与在环第九跑一致（在环 5.6 s 缓沉触地）；拍频贴 1.0 Hz 保护带
  （带内占比 14%）、俯仰未达配平（带内 27%）、舵 RMS 48%。
- 第一轮可行轴段：ALPHA_FF_GAIN∈{0.2, 0.3}（其余八轴名义点全轴
  不可行）；波形容差点 split −5% 单点可行。
- 第二轮以 aff=0.3 为中心九轴补测：逐轴半径 ALPHA_FF_GAIN 0.333、
  TECS_KV_F 0.333、PITCH_DAMP 0.333、KI_A 0.667、其余 1.0 →
  内切球半径 0.333（绑定点：前馈增益、速度项、俯仰阻尼）。
- 名义点到域的归一化无穷距离 0.667（唯一必要移动 = ALPHA_FF_GAIN
  0→0.2，占其半范围 0.667）。
- 机理：机翼+驱动矩直流 −0.0399 N·m 为低头偏置，名义组靠 KI_A 慢积分
  （需 ≈30 s 收敛）顶出，配平建立前升力缺口累积成缓沉；ALPHA_FF_GAIN
  为瞬时前馈通道（0.3×0.32 rad 攻角×0.49 N·m/rad ≈ +0.047 N·m 抬头），
  一步对消直流偏置。此即"前馈抵消攻角项"设计意图的正号方向；第十跑
  试过的 −0.08 为反号。

### M2 压坡度转弯：空，0/181 点

- 名义点 14.3 s 缓沉（同 M1 纵向原因）；把纵向修好后（aff=0.3）坡度
  跟踪良好（指令 15° 稳态 14.8°）但转弯率仅达协调值的 56.9%。
- 全网格最优 turn_ratio=0.755（KP_A=0.85、PITCH_DAMP=0.05 切片点），
  距 ±15% 带下沿 0.85 尚差 0.095——九参数扫到边也进不了带。
- 机理：偏航率-滚转耦合项 D13=−0.0233 N·m·s/rad（matrix_05）在协调
  转弯率下产生复原（退坡）矩 ≈0.0233×0.75=0.0175 N·m，而滚转环路
  比例增益仅 KP_A×KP_R=0.1 N·m/rad，稳态坡度被压到指令的六成。
- 不确定度注记（重要）：D13 的符号与幅值出自新工作点台架辨识；旧工作
  点（V=4.0/f=1.75/旧波形）的 docs/尾舵滚转权限极限与现行参数记档.md
  给出 15° 需求矩 −0.007 N·m（量级同源、符号口径相反，且该文档判
  5°~15° 可行）。两口径未在本班调和；M2 的空域结论以 matrix_05 为据，
  移植到在环前应先复测 D13。修复方向与该权限文档及 synth_cruise_gains
  解耦器建议一致：滚转第二权限（翼差动增益）或 D13 解耦前馈。

### M3 控制下降：非空，可行 70/244 点，内切球半径 0.333

- 第一轮可行轴段：TECS_KV_F∈[−3.0,−2.33]（速度阻尼加倍方向）、
  KP_A∈{0.7,0.85}、ALPHA_FF_GAIN∈{0.1,0.2}。
- 第二轮以 TECS_KV_F=−2.33 为中心：绑定点 KV_F 0.333、KP_A 0.333、
  KI_A 0.333；名义点到域距离 0.333（单参数 KV_F −1.0→−2.0 即入域）。
- 波形吸收：alpha_set +5%/+10%、split −5% 三向可吸收。

### M4 起飞：近空，56 发射输入格 0 可行（用户预期成立）

- 输入网格结局：45/56 数值发散（高仰角+高速外推域，同
  scan_launch_window 的 v_end 149~1494 现象）、10/56 触地（最长存活
  1.11 s @ (3.5 m/s, 0.3 rad)，全程爬升率峰值 0）、1/56 三秒存活但
  末速倒退 −3.2 m/s、末段已转入 −5.8 m/s 坠落（气球态，判据门外）。
- 最近边界量化：以气球输入 (3.5 m/s, 0.1 rad) 为底，九参数补测中
  KP_A=0.55 一格与波形 alpha_set −10% 一格过判（爬升率 +3.9/+3.8
  m/s、末速 2.1 m/s），但形态为急冲爬升（zoom climb，俯仰末端
  0.74 rad 贴姿态门、速度换高度），可信度低，不作为可用起飞方案；
  维持弹射配平直入口径（与第五步升格结论一致）。

### 交集

- 全四模态交集：空。卡点两处：M2 转弯带不可达（0/181）；M4 起飞
  输入域为空。M1∩M2∩M3 亦空（M2 空）。
- 最深非空子集 = M1∩M3，共 2 个采样点：`axis|ALPHA_FF_GAIN|0.2` 与
  `wavetol|split|-5%`。
- 交集参数组（M1∩M3，其余八参数=第九跑现值）：
  **ALPHA_FF_GAIN=0.20；TECS_KF_P=−0.030、TECS_KF_I=−0.010、
  TECS_KV_F=−1.0、KP_A=0.40、PITCH_DAMP=0.30、KI_A=0.033、
  INTEG_GATE=0.25、RATE_FILT_TAU=0.08。** 该点同时满足巡航四判据与
  下降带跟踪。轴向证据还显示两域可叠进更强组合：M1 在 aff=0.3 中心沿
  KV_F 负向全域可行（至 −3.0），M3 域 KV_F 段 [−3.0,−2.33] 落在其
  内，故 (aff∈[0.2,0.3], KV_F∈[−3.0,−2.33]) 按两域轴向边界推断均
  在交集中；该二维组合区未直接采样，列为下一班网格目标。

| ALPHA_FF_GAIN | 0.333 | 0.333 | 空（M2 最近边界 0.755 vs 0.85；M4 输入域空） |

| TECS_KF_I | 1.0 | 0.667 | — |

| INTEG_GATE | 1.0 | 0.667 | — |

读法：半径 0.333 = 中心点沿任一参数移动其半范围的 1/3 即可能出域；

（±5%/±10%）在 M1 名义组仅 split −5% 一向可吸收；M3 另吸收
alpha_set +5%/+10%；M2/M4 因基准点本身在域外，吸收度不适用。

## 七、与在环寻优代理的对照

正在跑的寻优代理（第十三跑"姿态刚化"，logs/ident_stream_flight_
0925_182445.csv）结果：存活 9.79 s（第九跑 5.58 s → 逐跑延长但仍
坠）、俯仰中位 0.194 rad（配平 0.374 未建立）、拍频恒 1.179 Hz、
升降舵深度饱和（中位 −0.325，RMS 占 0.30 限幅 110%）。与本框架名义
点结论一致：第九跑参数族仍在 M1 域外（本模型名义点 14.2 s 缓沉、
俯仰带内 27%、拍频贴带），且指向同一缺口——纵向配平建立太慢。框架
给出的下一步不是继续加 KP_A（第十三跑方向，M1 轴向显示 KP_A 单独
加到 0.85 仍不可行），而是把 ALPHA_FF_GAIN 移到 +0.2~+0.3 档。

## 八、敏感性与局限

1. 舵效口径（0.49 vs 飞行回归 0.13）：B=0.13 时名义点崩溃加快到
   4.6 s、舵 RMS 76% 超预算、M4 最优输入末段 −5.4 m/s——各模态判定
   方向不变，可行域显著收缩（环路增益失配因子从 2.68 降到 0.71）。
   两口径并存记档（决断总表甲组 0.49 为签核值；synth_cruise_gains
   飞行窗回归 0.13），上环前建议台架复测裁决。
2. 线性力图只在配平邻域（±0.5 m/s、±2° 俯仰、vz ±0.5 m/s）有效；
   M4 已改真模型在线积分规避外推，M1~M3 的弹射直入初态在邻域内。
3. 静态周期平均图与在环升力簿记存在系统差（在环 Fz 列 ≈0.48W 而总
   力平衡 ≈1.0W，见本班核对：缓沉 −0.5 m/s 与静态图自洽），框架按
   总力口径建模；该差不影响域的相对结构，影响绝对存活时长（本模型
   名义 14.2 s vs 在环 5.6~9.8 s，同失效模式）。
4. M2 的横侧向符号不确定度见 §五 M2 注记；M3 稳态下降窗仅约 2 s
   （巡航高度限制），带内占比判据对此窗敏感。
5. 交集只覆盖共同采样点；M1 域（aff=0.3 中心）与 M3 域（KV_F=−2.33
   中心）的二维组合区未采样，是下一班网格的明确目标。

## 九、处置建议（丙组自由空间内，非契约变更）

1. 首选移动：ALPHA_FF_GAIN 0→+0.20（M1∩M3 交集参数组），一次改一
   参数、在环一跑验证；备选 +0.30（M1 域中心，M1 半径绑定点）。
2. M3 强化：TECS_KV_F −1.0→−2.0~−2.33（速度阻尼加倍方向）。
3. M2 前置：复测 D13 符号后，按解耦器建议（synth_cruise_gains
   mimo.decoupler）或翼差动第二权限立项；九参数整定解决不了 M2。
4. M4 维持弹射配平直入；起飞模态不设为闭环验收目标。
