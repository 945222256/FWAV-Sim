# 口径对齐手段时基复核（处置复核一/二，2026-09-20 夜间施工）

## 一、复核任务

处置清单复核项：0.1 s 输入状态低通滤波与输出力拍周期滑动平均这两项
口径对齐手段，其时间常数语义必须在第 12 轮的新时基（步数×步长，替代
权威物理时钟）上复核一次，结论为"保持/修改"二态之一。

## 二、代码事实

1. 输入低通（`modules/aero_solver.py` AeroPhysicsCallback._call_inner，
   状态滤波段）：`self._v_air_filt += min(1.0, dt/0.1)·(v_air−filt)`。
   步进因子由回调入参 `dt`（物理步长）计算，不读取墙钟或
   current_time。
2. 拍周期滑动平均（同函数，拍周期平均段）：
   `_nwin = round(1/(f·max(dt,1e-4)))` 步，窗口长度按 dt 与当前拍频
   f 换算，同样不读墙钟。
3. 第 12 轮时基修正（main_sim 权威物理时钟 = step_count×PHYSICS_DT）
   影响的是以 current_time 为自变量的波形相位与控制器；上述两项均以
   回调 dt 为自变量，位于时基修正的影响域之外。
4. 第 13 轮证明的 1.75 倍墙钟膨胀只作用于 GUI 模式下 current_time 的
   推进；dt（step_size 回调入参）为固定物理步长 1/120 s，不膨胀。

## 三、复核结论

**两项均"保持"。** 依据：0.1 s 时间常数与一个拍动周期的窗口语义都以
物理步长 dt 换算，dt 在新旧时基下同值（1/120 s），语义不变；两项均
不受墙钟膨胀路径影响。附加记录：无头模式下墙钟膨胀本身不出现
（main_sim.py:437 注释），在环验收建议无头口径。
