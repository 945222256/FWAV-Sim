# 一页纸技术进展通报·素材收集清单（2026-10-11）

> 用途：机主委托执行者按本清单收集素材并产出一份素材报告，
> 主会话（或机主指定的执笔人）据此撰写对外的一页纸技术进展通报。
> 执行纪律：本任务是只读与提取，不修改版本库任何文件，不运行任何
> 仿真；所有数字必须带出处（提交号或文件路径）；每句话主谓宾完整，
> 不使用比喻，不使用自创缩略词。

## 一、这份通报服务什么

通报的读者是扑翼公司团队（流体力学与机械背景）。通报的目的不是
炫耀工作量，而是让对方产生一个判断：这个候选人在面试之后把运动
控制方向真实推进了，而且推进到的问题恰好是真实飞机要面对的。
通报的结构固定为三段：面试时我手上有什么；现在我手上有什么；
剩下哪些问题只有真机能回答。素材收集必须围绕这三段组织，凡是
不进这三段的内容一律不收。

## 三、素材报告的格式要求

素材报告为一份 Markdown 文件，文件名
备忘录素材报告_20261011.md，放在 docs 目录。结构就是八项的顺序，
每项一小节；每节先给提取的数字与结论，句末用括号给出处；不评论、
不发挥、不删减不利信息；遇到找不到的条目，如实写"未找到，查了
哪里"，禁止编造。完成后提交版本库，提交信息写"备忘录素材报告"。
