# 工作方式整改：函数化与可视化纪律（2026-09-28，机主批评后立）

## 一、机主批评的事实认定

其一，我连续两天用孤立的离散数字汇报，没有给出任何响应函数、
拟合曲线或图。机主无法判断任何量在其他参数与状态变动时的走向，
等同于抓瞎。其二，我多次使用项目内部词汇汇报（生效基线、老幅值
差动、权限反号边缘）而不给定义与图。其三，我在没有权限包线图
的情况下就请求裁决，让机主在看不见地形的情况下做决定。

## 二、整改纪律（立即生效，逐条可检查）

1. 任何对外汇报的结论量，必须同时交付其在相关自变量上的响应
   函数：解析式、拟合曲线或采样网格图，三者至少其一。禁止孤立
   数字单独出现在汇报正文。数字只能出现在文件与图表内。
2. 任何"权限够不够""能不能成"类问题，先出稳定性地图或裕度
   曲线，再谈在环试验。预测必须画在图上并标注假设与不确定带。
3. 向机主提出的每个选项，必须配图说明它在地图上的位置。
4. 汇报正文使用全称与图，不使用内部缩略词；无法回避的项目
   术语首次出现给一句话定义。
5. 拟合必须给残差或可信度说明，禁止无误差带的曲线外推。
