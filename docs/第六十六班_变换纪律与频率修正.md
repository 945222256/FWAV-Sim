## 一、任务一：统一变换纪律（tools/ 两件，零行为变化）

### 1.1 唯一换算函数族（tools/unified_search_framework.py 模块级区域）

函数族四枚 + 欧拉构造反函数，全部旋转调用收敛于此（区域外 grep 零
直接换算调用）：

| 函数 | 变换 | 籍贯（入→出） | 方向断言（正扰动→正响应） |
|---|---|---|---|
| rot_body_to_world | R_bw@v | BODY→WORLD | 正俯仰（纯 +qy，低头）下机头 world z 分量为负 |
| rot_world_to_body | R_bw.T@v | WORLD→BODY | 正俯仰下 world 上向量体轴 x 分量为负（向机尾倾）；与上者互逆往返 ‖Δ‖<1e-12 |
| quat_pitch | asin(2(qw·qy−qz·qx)) | 姿态标量 | 纯 qy=+0.10 必得俯仰 +0.10（用户令示例） |
| gravity_moment_body | R_CG_BODY×(R_bw.T@[0,0,−W]) | WORLD 重力跨界进 BODY | 与闭式 M_y=x_cg·W·cosθ 逐点一致（65 班查证式）；正 qy 扰动 M_y 单调增大（趋零） |
| euler_to_quat（反函数，modules/aero_solver.py 单源） | 欧拉→四元数 | 构造 | 经 quat_pitch 往返一致 |

断言函数 `_assert_transform_directions()` 于模块 import 时执行
（执行点在 quat_norm 定义后），失败即 AssertionError 终止、禁静默
通过。系别籍贯逐处注释：WORLD 系（z 上）=vel_world/om_world/F_world/
尾矩 Tt；BODY 系（x 前）=*_body 后缀量与积分状态 w/Tq；姿态语义
（正俯仰=低头、θ*<0=抬头爬升）与 65 班勘误同源。换算调用点改造
八处（wing_forces_body/forces_total×2/stroke_avg×3/ClosedLoopSim.run
×3），重力矩跨界式收敛为 gravity_moment_body 唯一入口。
tools/unified_search_v3.py 自身零旋转调用（grep 证据），经框架导入
收敛，件内声明注释落档。

## 二、任务二：modules 频率通道符号修正 + 框架内验证

### 2.1 修正本体（modules/ 全班唯一改动，一处+注释）

modules/flight_controller.py 巡航频率律（原 L254 域）：

```
freq = f0 + KF_P·e_E + KF_I·ei − KV_F·(vxd − vx)     # 原为 +KV_F·(vxd−vx)
```

依据（注释入码）：本被控对象油门频响为正（∂Fx/∂f>0，第四十九班
实测、统一框架 dfx_df>0 硬预滤同源），速度缺口的正确响应=升频补
推。原式对历史部署的负值 KV_F（四三班组 −2.611、五十班组 −0.6，
_patch_run50.py 按 −akvf 落 config）构成速度正反馈：速度缺→降频→
推力减→更缺，经 clip[1.0,3.5]×斜坡 2.5 Hz/s 整流为极限环、拍频钉死
1.1792（63 班 §四A 四重不变证据）。翻转后 KV_F 按搜索侧符号约定
解释：负值配置给出正频响有效增益 |KV_F|。KF_P/KF_I 能量项符号
不变（e_E>0=能量缺、正系数升频，本就是正频响语义）。**记档：config
缺省 TECS_KV_F=+1.0 的默认路径行为随本修正反转（本班一切在环部署
经补丁机制写负值，不受影响；缺省值重锚需批面，见 §四.1）。**
