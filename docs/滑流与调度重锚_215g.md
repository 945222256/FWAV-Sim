# 滑流系数重新标定与控制调度量重推导（步骤11+13，2026-09-20 夜间开发）

原始数据：`logs/reanchor_scheduling.json`（求值方式为锁定机体状态并给定来流条件，该求值方式与台架试验的求值方式相同；计算工况为 2026-09-20 首次标定的配平点，即 V=4 m/s、f=1.55 Hz、θ=−6.2°）。

## 一、滑流两系数（处置改动第三项）

- 结构保留：本结构保留 v_slip = SLIP_K·SLIP_V_PER_HZ·f 的形式（一阶动量理论）。
- **SLIP_V_PER_HZ：1.25 → 0.472 m/s/Hz**。标定方程在新配平点重新推导：
  v_i = √(W/(2ρ·A_disk)) = √(2.109/(2×1.225×1.61)) = 0.731 m/s，
  除以 f*=1.55 Hz。旧值 1.25 是 700g/2.3m 巡航配平点的标定值（W=6.87 N）。
- SLIP_K=1.0 维持，真机标定事项维持遗留未决状态。
- 标定工况清单（本文件即该清单）：本次标定工况为新被控对象的巡航配平点
  （V=4 m/s、f=1.55 Hz、θ=−6.2°、W=2.109 N、A_disk=1.61 m²）；该工况为
  2026-09-20 首次标定的配平点。2026-09-21 工况点重新标定（新工况点为
  4.5 m/s、−0.05 rad）之后，两个滑流系数没有随之重新推导；该项列为
  遗留未决事项。
- 逐档来流台架补测的诚实声明：台架与力模型使用同一套气动模型
  （IDENT_20260919.md:76），
  项目内不存在独立测量滑流的通道；"补测"所能提供的上限即本节的理论
  重新标定，在真机尾舵权限完成实测之前，SLIP_K 不具备标定条件。

## 三、重要发现（该类发现不阻塞当前流程，按批次汇总上报）

1. **翼差动滚转舵效塌缩且变号**：B_dA(f) = +0.041（1.55 Hz）→
   +0.015（2.0）→ −0.039（2.5）→ −0.118 N·m/rad（3.0）。旧值 19.0 量级的
   舵效塌缩约 300 倍，且在自动驾驶仪拍频域内**符号翻转**。f² 调度律在新被控对象
   上失效；调度取值已固定在配平邻域，差动通道在 f>2.2 Hz 视为不可信。
   滚转主通道在新被控对象上转移为尾翼差动（B_ail = 0.00483·v_eff²）。
   在环滚转权限的裁定事项列为遗留未决（步骤 14）。
2. **速度阻尼塌缩一个量级**：∂Fx/∂v 从 3.17 降到 0.18 N/(m/s)——该降低
   是 0.6 m 翼阻力面积缩小的直接后果；TECS 速度通道阻尼前馈已按新值
   重新标定，速度环增益的充分性待在环复验。
3. **附加质量力占比（处置保留第四项的验证）**：新配平点周期内瞬时力 RMS 占比
   18.6%（`reanchor_scheduling.json` added_mass 段）。该占比证实处置
   保留第四项的敏感性预警：附加质量力相对 215 g 机体惯量的等效作用
   上升，回归监测项目自本次起纳入监测范围。
4. 尾翼三通道 K_B_TAIL_*（∓0.0145/0.00483）复核结果：尾翼几何与 CN_SLOPE
   未随质量切换改变，动压平方律结构在 v_eff 口径下自洽，数值维持不变；
   唯一变化为 v_eff 中的滑流分量按第一节重新标定。
