# 有符号法向力系数推导与实现（处置改动第一项，2026-09-20 夜间开发）

## 一、问题重述

现行力律（`modules/aero_solver.py:365`）把法向力写成
`dF = q_dyn·|C_N(α_eff)|·c·dr` 并投影 `·cos(α_eff)·ẑ`，来流偏角计算使用
水平来流的绝对值（`aero_solver.py:358`：`atan2(v_z, |v_x|)`）。该绝对值
组合实现"翻转俯仰保证上下半拍都产生向上升力"的假设。在反向来流工况下
（在环实录 vx=−13 m/s 时 Fwx=−19 N 且与运动同向），该组合把机翼振荡
整流成同向伪推力，是自由飞倒飞发散的机制级主因（风险账本第三条）。

## 二、约束条件

1. 已辨识包线（悬停邻域＋正向来流＋小姿态）内的模型行为必须逐位不变，
   否则 2026-09-18/19 全部台架辨识与 2026-09-20 新被控对象配平结果作废。
2. 改动后倒飞至 10 m/s 范围内模型力方向必须正确（工作令验收标准）。
3. 纯"去掉绝对值"不可行：上行半拍 α_eff 为负（α 跟随 φ̇ 变号的翻转俯仰
   约定），C_N(−40°)=−3.38，去绝对值会把上半拍升力反向——悬停升力被
   消灭，违反约束 1。**绝对值承载的是翻转俯仰物理（半拍内自洽），不是
   错误本身；错误在于跨半拍参考系的方向信息丢失。**

## 三、推导：半拍参考系与镜像延拓

### 3.1 参考系分解

叶素求解的全部公式定义在"来流从机头方向到来"的参考系内：来流偏角
β=atan2(v_z, |v_x|)、有效攻角 α_eff=α+β、法向力投影 cos(α_eff)·ẑ。
记该参考系为 R⁺。翻转俯仰约定（α 的符号跟随 φ̇）在 R⁺ 内自洽：无论
下拍还是上拍，机翼相对自身运动方向的攻角为正，|C_N| 在 R⁺ 内是半拍内
的合法形式。

### 3.2 反向来流的镜像延拓

当净水平来流深度反向（机体水平空速分量 v_x < −1.2·2πf·amp·⟨r⟩，即
来流速超过拍动正弦特征速度 1.2 倍、净流反向成为主导）时，定义镜像参考
系 R⁻：x 轴反射（x→−x），y、z 不变。在 R⁻ 内求解（来流折算为正向）。
输出的 y、z 分量与力矩按反射张量映射回机体系：

- 力 y/z： (F_x, F_y, F_z) → (·, F_y, F_z)
- 力矩： (T_x, T_y, T_z) → (T_x, −T_y, −T_z)（由 r×F 在反射下的变换
  r'=(−x,y,z)、F'=(−Fx,Fy,Fz) 直接展开得到）

**x 分量不取镜像翻转**（实施修正）：R⁻ 内求解时 α=40° 使 C_T<0（推力
性，Robofly 拟合在 α>35° 的固有性质），净 F_x 是推力与阻力大量对消后的
小差值；镜像翻转该小差值在深反区仍可能给出微弱同向泵能（首轮实施实测
−0.47 N @ vx=−13）。x 分量改取**逐叶素切向阻力绝对值累积**
F_x = Σ q_dyn·|C_T(α_eff)|·c·dr：方向恒为阻动、量级为真实阻力尺度、
无对消脆弱性。推力在反区的阻动贡献未建模（保守近似，限制四）。

### 3.3 有符号性的数学表述

镜像延拓等价于把 C_N、C_T 延拓为关于来流方向的奇函数族：C_N 在 R⁻ 内
于镜像角 α̃_eff 求值，等于在 R⁺ 内对带符号来流取 C_N(π−α_eff) 型的符号
延拓。因此本实现就是"有符号法向力系数"的一种显式形式：符号信息由参考
系镜像携带，半拍内的 |C_N| 保持翻转俯仰物理。

### 3.4 等价性证明（约束 1）

v_x ≥ 0 或 |v_x| ≤ 1.2·⟨|v_flap_x|⟩ 时镜像不激活（R⁺ 恒等），全部代码
路径与旧版逐位一致。已辨识包线内 v_x ≥ 0 恒成立，故辨识结果与配平结论
不受影响。门限 1.2 的含义：拍动诱导水平振荡速度的 1.2 倍以上才算"净
来流反向主导"；门限以下的浅度倒漂区（从未被辨识）保持旧行为，作为
已声明限制记录。

### 3.5 方向正确性论证（约束 2）

反区水平力直接取逐叶素切向阻力绝对值累积，方向恒为 +x（对抗 −x
运动），伪推力从机制上消失；实测 vx∈{−2,−5,−10,−13} 给出
Fx=+0.1/+0.5/+1.9/+3.3 N（`docs/三组来流工况_215g.md` 组一），验收
"倒飞至 10 m/s 力方向正确"通过。升力竖直分量与侧向（y）通道不受
x 分量替换影响。

## 四、实现位置

`modules/aero_solver.py` `_wing_forces`：入口处按门限（1.2·2πf·amp·⟨r⟩，
拍周期常量）判定镜像并反射 `v_body_at_hinge` 的 x 分量；出口处 y/z 分量
与力矩按 3.2 的张量映射反射，x 分量取逐叶素 |q·C_T·c·dr| 累积。
`compute_forces` 不变（爬升守卫、WING_ROT_DAMP 均作用于映射后的量）。

## 五、验收与已知限制

1. 三组台架工况数据（反向、侧向、垂直来流）：`docs/三组来流工况_215g.md`
   （离线状态锁定求值口径，与台架试验使用同一套模型与求值方式）。
2. 反向来流在环复测：步骤 14。
3. 已知限制一：门限以下的浅度倒漂区（|v_x| < 1.2·拍动特征速度）保持
   旧外推行为，该区从未被辨识，定性不变。
4. 已知限制二：翻转俯仰运动学（α 跟随 φ̇）在深反向来流下不再物理
   （真机需反向羽化），力方向正确性不等于该区气动力数值可信。
5. 已知限制三：C_N/C_T 文献拟合本身的适用域外推问题（处置保留第一、
   二项）不因本改动消失。
6. 已知限制四：反区水平力为阻力保守近似（推力的阻动贡献未建模），
   量级下界；α 跟随 φ̇ 的翻转俯仰运动学在深反区不物理（真机需反向
   羽化），反区数值只保证方向正确性。
