## 一、判据口径裁决：Fz 列的 0.5 因子（本班第一发现）

用户指令的关键修正是"Fz/W 用含拍频反作用与守卫的动态周期平均
（第九跑实测口径），不用钉固开环"。执行中对第九跑数据流
（logs/ident_stream_flight_0925_174753.csv，飞行窗 1.0<t≤5.575 s，
n=412）直接对账，得到口径分解：

| 列 | 含义 | 中位 | 折 W |
|---|---|---|---|
| Frz | 钳位前原值 = K=8 同步周期平均总力（含爬升守卫、尾翼、拍频反作用） | 2.0505 N | 0.9722 |
| Fz | rate_scale 后每触发施加值（CSV 判据列） | 1.0254 N | 0.4862 |
| Fz/Frz | 逐样本比值 | min/med/max = 0.4999/0.5000/0.5001 | — |

机理：modules/aero_solver.py 的多触发补偿（第七班引入）把施加力除以
每主步触发数 fpms（实测 ≈2.0），CSV 的 Fz 列记录的是每触发施加值
（last_F_world=F_apply），故恒为周期平均原值的一半。第十五跑两流
复核同构：15a Frz/W=0.9478 对 Fz/W=0.4738；15b 0.9682 对 0.4842。

判读（记档，供主会话裁定"升力墙"定论的口径修订）：

1. "十六跑 Fz/W 中位 0.478~0.491 恒定"的墙值，一半是 0.5 簿记因子：
   同一批飞行的动态周期平均原值为 0.948~0.972。开环钉固承诺 0.99 对
   闭环实测 0.48 的"2 倍系统差"由此闭合到 ~3%~5%（0.972 对 0.987）。
2. 墙的另一半是真实物理：闭环俯仰未达配平（第九跑实际俯仰中位
   0.108 rad 对配平根 0.38 rad）与高度保持模态欠阻尼（第三十六班
   结构发现 1），属调节问题而非升力量级问题——本班控制器重整定后
   同一波形同一工作点四判据全过（见 §四）即为其证。
3. 逐拍 Frz/W 交替 0.83/1.14（拍奇偶交替），与第八跑谱中 0.525f
   次谐波线（0.62 Hz 对锁频 1.18 Hz）同源——拍频反作用的次谐波分量
   是逐拍升力交替的来源，本班闭环扰动谱保留该线。
4. 若把 0.5 施加簿记口径当判据，任何波形的 Fz/W 天花板为 0.5，
   "中位 ≥0.95"退化为恒假——该口径被证伪为判据口径而非波形能力。
   本班判据①采用 Frz 同源口径（动态周期平均原值）。

### 2.2 内层：逐波形标定（并行，真三维模型）

对象内核 = sane_dickinson_3d + 尾翼（modules/aero/ 与
modules/aero_solver.py，显式实例化、不读 AERO_MODEL 开关、不改
config；feasibility_map._true_model 同源）。每个候选（LHS 2400 组 +
5 个种子点，含甲组签核名义点）执行：

1. **俯仰根 θ\***：My(θ)=0（升降舵零位、ω=0 钉固状态整周期平均），
   粗扫 n=36 变号 + 二分精修 n=144；无根（|My|min>0.03 N·m）剪枝。
2. **逐波形斜率**（三探针结构的逐波形重提，全部 n=144 同相位网格）：
   ∂Fz/∂f（宽跨度 ±max(0.10, 0.08f)，限幅 ±0.20——Fz(f) 丘形细结构
   下窄跨度差分是网格噪声）、∂Fz/∂V（+0.5 单侧）、∂Fz/∂θ（+2° 单侧）、
   ∂Fz/∂vz（0/−0.5 单侧负向，避开爬升守卫污染），Fx 同套，∂My/∂θ
   刚度与 ∂My/∂vz。**教训记档**：aero 模式 α=|cos| 波形有折点，
   不同 n 的相位网格不对齐会引入 ~0.03 N 量级伪斜率（曾把 ∂Fz/∂θ
   的符号算反），参与差分的求值必须同 n 同网格。
3. **拍频扰动谱**：根态整周期 My 序列 DFT（1f~4f）只作逐波形相对
   缩放（限幅 [0.25,4]），锚定幅相用实测值——次谐波 0.525f=0.0193 N·m、
   84°（第八跑谱投影）；1f~4f=0.01196/0.00871/0.00367/0.00208 N·m、
   相位 2.097/1.270/1.019/0.993 rad（第九跑锁频 LS 拟合，
   optimize_gains 同源）。理由：在环施加力为 K=8 同步周期平均，拍内
   纹波（根态 DFT 实测 1f≈0.187 N·m）大部分被平均掉，扰动取实测
   残差而非纹波原值。
4. **动态标定（剪枝）**：锚定映射垂向释放 12 拍（俯仰钉固 θ*、速度
   钉固 V0、爬升守卫生效），末 6 拍逐拍周期平均 Fz/W 中位 <0.95 剪枝，
   并记录定常下沉率 vz*。俯仰钉固的依据：静态斜率口径下开环俯仰–垂向
   耦合环路增益 (∂My/∂vz/K_TH)·(∂Fz/∂θ/|∂Fz/∂vz|) 名义点 1.43（终选
   组 0.95~4.28）**普遍大于 1——本对象开环静态发散，俯仰刚度必须由
   闭环提供**（新结构发现，与十六跑"无控制器必坠"一致）。终选 20 组
   另做 event_series_6dof 式真模型纵向短积分复核（每步 K=8 同步周期
   平均真力，即第九跑 Frz 同源口径），动态 Fz/W<0.95 或触地者淘汰
   （20→16）。

锚定核对（名义点，本班复测 对 第三十七班探针 A/第三十一班斜率）：
θ*=22.02° 对 21.45°；FZ0=2.0828 N（0.9875W）对 2.0812（0.9867W）；
∂Fz/∂V=+1.2438 对 +1.244；∂Fz/∂vz=−0.2067 对 −0.2026；∂Fz/∂θ=−0.645
对 −0.487（单侧 +2° 局部斜率，n=288 曲线 19.45°→23.45° 段为 −0.49，
高角处曲线变陡，属局部化差异）；扰动线 1f/2f=0.01196/0.00871 逐位
复现。根部网格噪声：重复运行 θ* 抖动 ±0.25°、FZ0 ±0.003 N。**映射
对第九跑实测态的复核**：以飞行窗中位态（θ=0.108、f=1.1792、
vx=3.372、vz=−0.501）代入名义锚定映射，预测 Fz=2.204 N（1.045W）
对实测 Frz 2.0505 N（0.972W），线性外推偏差 +7.5%（远离根 0.27 rad
处），映射在根邻域可信。

### 2.3 外层：控制器整定与闭环考卷

闭环 60 s（dt=4 ms）= 内层锚定的 Fz/Fx/My 线性图（以该波形自身
θ*、f0、V0、FZ0、FX0 为中心）+ 扰动谱（相位跟随时拍频）+ 爬升守卫
（vz>0 时 Fz×1/(1+(vz/2.5)²)）+ 力矩直流 MY_DC=−0.0399 N·m（第八跑
实测，名义保留；真模型根态复核值 +0.014，两口径并存，见变体 V1）。
控制律 = flight_controller 单段巡航路径复刻（结构常数第九跑在环值；
vxd 下沿 V_CMD_MIN=3.0 保持真值，低 V0 候选如实受此约束；f0<1.0 时
FREQ_AP 下沿按第十五跑建议下探至 f0）。判据（先于数据）：① Fz/W
动态周期平均中位 ≥0.95（t>5 s 窗）；② z∈[2,4] 占比 ≥95% 且 z_min
≥1.5、60 s 存活；③ |θ−θ*|≤0.05 rad 占比 ≥80%；④ 舵 RMS ≤70% 满偏。

整定流程：每终选波形 LHS 384+τ 展开+三种子共约 1059 控制器组并行
评分（16944 组 74 s）→ 每 waveform 前二种子 Nelder-Mead 细化
（32 组）→ 前 6 控制器全量判据评估（96 组）。排序偏好带内居中与
θ RMS；最优组须在 MY_DC 两口径（−0.0399 与 0）下均可行。

即三十七班 wave_tol 口径（split −5% 等可吸收），波形轴不再有口袋
约束**——上环风险低于正式最优组，这是工程推荐组为首选的第二个理由。

## 六、判读

1. **寻优边界纠错的实义**：放开波形五参数后可行域确实变大（9 个
   工作点、46 组），但最靠带内居中、且不引入新口袋约束的解恰是
   **波形不动、只动控制器**。"波形五参数必须改"不成立；此前十六跑
   不过的根因按本班口径分解为：0.5 簿记因子（口径）+ 俯仰未达根 +
   高度交换模态欠阻尼（调节），而非工作点升力缺口。
2. **Fz/W 判据的分辨力**：动态周期平均口径下，处于力平衡邻域的闭环
   Fz/W 中位恒 ≈1.0（连第九跑坠机飞行窗的实测原值也有 0.972），故
   判据①几乎不单独筛人；考卷的实质压力在高度带、俯仰跟踪与舵预算
   （②③④）。若需 Fz/W 类判据保留分辨力，应改用"vz→0 外推的可持续
   升力"（即 |vz*| 派生量），本班以 |vz*| 进入内层排序实现了同一目的。
3. **开环俯仰–垂向静态发散**（环路增益 0.95~4.28>1，逐波形标定）：
   静态斜率口径下本机无条件闭环不可悬停——俯仰环不只是跟踪器，还是
   静稳定性的提供者。这解释了任何"姿态锁定开环承诺"与闭环表现的
   系统性落差,并把"先整定俯仰环、再谈能量环"的次序固定下来。
4. **∂Fz/∂θ 的口径并存**：静态图 −0.49~−0.65 N/rad（本班复测与探针
   A 同号）对在环回归 +0.773 W/rad（第十五跑弱证据）。本班闭环按
   任务指定用静态探针口径；推荐组已对反号口径复验（DFZ_DTH→+0.5
   变体：z 100%、θ 100%、判据仍全过），即其可行性不依赖该斜率符号。
5. **力矩直流双口径**（−0.0399 在环实测 对 +0.014 真模型根态）：
   推荐组与最优组在两档下均可行（V1 复核；推荐组另过 MY_DC=+0.014
   第三档：z 100%、θ 99.1%）；但攻角前馈 0.23~0.28 与 MY_DC=−0.0399
   耦合,上环若实测直流接近 0,前馈可相应回调（V1 下推荐组舵 RMS 反而
   降至 ~14%）。

## 七、局限

1. 闭环对象为根邻域线性图（对第九跑实测态外推偏差 +7.5%）；大幅值
   机动、失速区、横侧向耦合不在内。三十七班 M2 转弯、M4 起飞的空域
   结论未被本班推翻。
2. 名义点标定存在网格级抖动（θ* ±0.25°、FZ0 ±0.003 N、∂Fz/∂θ
   ±0.1 N/rad），来自 α=|cos| 折点波形的采样收敛慢；终值判读已按
   同网格差分规避,跨班复用斜率时须保持 n 与网格约定。
3. 最优组的真模型动态复核显示 +3.5 m/s 钉俯仰爬升（FZ0 富余 13.6%）,
   闭环靠降速/降频泄放——该工作点的"可行"依赖映射外推,上环前建议
   对该点补一次 scan_dfzdf 式开环扫点；推荐组（vz*=−0.13）无此顾虑。
4. 拍频 <1.0 Hz 候选的 FREQ_AP 下沿按第十五跑建议下探属契约层待追认
   项;推荐组 f=1.25 Hz 不触及。

## 八、处置建议（丙组自由空间内，非契约变更）

1. 上环首选：**波形与工作点零改动，仅换控制器七参数**（§4.2 推荐组），
   一次一跑验证；回退档=三十六班最优组（本班对照亦过）。
2. 正式最优组（α43/MEAN11.6/f2.24/V4.07）作为第二期候选，上环前先
   补该点开环扫点（∂Fz/∂f、∂Fz/∂V 在环有效性）与 α_set≥45° 边界。
3. "升力墙"定论建议按 §一修订口径后记档：墙值 0.478~0.491 的一半
   是 Fz 列 0.5 施加簿记因子；动态周期平均原值 0.948~0.972。CSV 列
   的修簿记（记录 F_apply×fpms 或直接记 Frz）属报告层修正,不动
   modules/。
4. Fz/W 类验收判据若保留,建议改用 |vz*|（可持续下沉率）或加 vz→0
   外推口径,避免动态口径下恒 ≈1 失去分辨力。
