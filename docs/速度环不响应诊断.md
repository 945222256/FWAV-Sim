# 速度环不响应诊断（收尾施工计划步骤一）

- 日期：2026-09-21
- 诊断脚本：`tools/diag_speed_channel.py`（离线重放，不启动仿真器）
- 数据文件：`logs/ident_stream_flight_0921_025539.csv`（六十五秒全程存活航班，速度在带率 47.4%，高度在带率 100.0%）
- 诊断问题：总比能误差 e_E 为正时，拍频指令为什么没有上升。

## 一、重放方法与对账结论

重放方法说明：本诊断把数据文件中的位置、姿态四元数、原始线速度、原始角速度逐帧读入；线速度先按时间常数 0.1 秒的指数滤波重建 `held_body_vel` 口径（与 `modules/aero_solver.py` 的控制器供数口径一致），角速度不经过该替换；随后逐帧调用 `FlightController.update`，重放全部指令链。重放起点取 t=2.0 秒（状态锁定与拍幅软启动均已结束），控制器状态按该帧数据初始化。

对账结论：重放拍频与数据文件拍频列的残差中位数为 +0.0137 Hz，峰值绝对残差为 0.058 Hz；重放期望俯仰角与数据文件期望俯仰角列的残差中位数为 +0.020 rad（峰值残差来自斜坡限幅在九十赫兹重放与一百二十赫兹实际环路之间的量化差异）。重放链路忠实，下列诊断结论成立。

## 二、三个怀疑点的核查结果（全部排除）

怀疑点一（积分抗饱和冻结条件误冻结）：冻结窗口（1.01 Hz 与 3.465 Hz 之外）外的帧占比为 0.00%；比能积分状态 ei 的全程范围为 -0.6 至 +7.3 J/kg·s，从未接近正负 60 的积分限幅，负值帧占比仅 4.7%。冻结与触顶均不存在。该怀疑点排除。

怀疑点二（动能误差项使用滤波后的陈旧速度）：滤波使动能误差相对势能误差的相位滞后为 +0.10 秒（振荡周期的百分之五）；滤波后总比能误差的标准差为 2.0 J/kg，滤波前为 1.1 J/kg，滤波方向是把误差信号放大而非压制。陈旧速度既没有显著相位损失，也没有压制拍频指令。该怀疑点排除。

怀疑点三（高度出带时角落地带分支冻结拍频）：目标速度 vxd 触底（等于 V_CMD_MIN=3.0 m/s）的帧占比为 0.00%；高度出带（高度偏差大于 0.8 m）的帧占比为 0.00%。角落地带分支全程未被触发。该怀疑点排除。

## 三、第十班现象的重新定性

核心反转证据：本航班中总比能误差 e_E 大于 +5 J/kg 的帧占比为 0.00%；势能误差与动能误差的相关系数为 -0.98（反相），两者全程近乎完全对消，总比能近似守恒。第十班记录的"能量误差达到正 20 J/kg 时拍频指令不上抬"的现象在本数据文件中不存在；该记录对应的失血场景属于世界边界墙时期的旧航班，与本轮缺口不是同一现象。

拍频通道的行为判定：总比能守恒时拍频指令保持中性是总能量控制的正确行为，不是缺陷。能量供给通道（e_E 到拍频）没有故障；本航班速度在带率缺口的成因不在拍频通道。

## 四、真实缺口的定量证据（能量分配通道增益不足）

现象定性：本航班残余的是速度与高度之间的能量交换振荡（浮沉型的长周期模态）。振荡周期测量值为 1.88 秒（z 序列上升沿过零间隔中位，二十八 个周期）；速度与高度严格反相（相关系数 -0.99，滞后 -0.03 秒）；巡航段速度标准差为 1.11 m/s，高度标准差为 0.42 m。

定量缺口一（分配通道供给远低于需求）：能量分配误差 e_B 的巡航段标准差为 8.1 J/kg；分配通道俯仰增量供给为 TECS_KP_E 乘以 e_B 标准差等于 0.032 rad；按俯仰到前向力导数 0.67 N/rad 与质量 0.215 kg 折算，阻尼该振荡所需的俯仰幅度约为 0.356 rad。供给与需求之比为 0.09，供给低了一个数量级。

定量缺口二（等效速度环带宽远低于振荡频率）：速度误差经动能误差（等效增益为巡航速度 4.5 每米每秒）、分配增益、俯仰到加速度导数（3.1 m/s²/rad）的链路合成，现状等效速度环增益约为 0.056 每秒（时间常数约十八秒）；振荡角频率为 3.34 每秒。速度环带宽比振荡频率低约六十倍，分配通道在振荡周期内无法建立有效响应。

定量缺口三（期望俯仰角的构成中分配项占比极小）：期望俯仰角巡航段标准差为 0.207 rad，其中垂速阻尼项（TECS_KD_V 乘以垂直速度）贡献标准差 0.196 rad，分配项（TECS_KP_E 乘以 e_B）贡献标准差 0.032 rad。期望俯仰角的大幅摆动几乎全部来自垂速阻尼项；垂速阻尼项在高度极值点（垂直速度为零、速度偏差最大处）恰好为零，无法在能量交换的极值点注入纠正量。

## 五、修复方向判定

按上述证据，本缺口的修复不需要动拍频通道；修复位置是能量分配通道（e_B 到俯仰角）的增益。分两步走：

第一步（最小修改，本计划步骤二）：把 TECS_KP_E 从 0.004 提高到 0.020（五倍）。取值依据：供给需求比从 0.09 提升到约 0.45，若允许三到四个振荡周期完成收敛，该供给水平足以把速度标准差压入验收带所需水平；历史 0.005 档的限环结论产生于俯仰阻尼系数 PITCH_DAMP 提升到 1.5 之前的旧配置，本次修改后试验架回归与在环验证重新裁决。垂速阻尼档位（TECS_KD_V）不动：该档位历史 0.3 至 0.4 曾使期望俯仰角顶满限幅成为继电器。

第二步（结构更换预案，仅当第一步在环验证不达标时上报后执行）：把能量分配误差的输出目标从俯仰角指令改为垂直速度指令（e_B 乘以增益得到期望垂直速度，期望垂直速度经比例积分产生俯仰角指令），与施工计划第三节的结构更换预案一致。

## 六、遗留说明

本诊断全部结论来自单一数据文件（六十五秒存活航班）的离线重放；重放口径与实际环路之间的已知差异为采样率（九十赫兹对一百二十赫兹），对账残差表明该差异不影响结论。
