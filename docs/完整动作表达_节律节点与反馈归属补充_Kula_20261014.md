## 一、节律节点及关系

在原方案 `modules/motion_action/types.py` 的配方和节律快照、`rhythm.py` 的 `RhythmService`、`runtime.py` 的装配处增加可执行描述，具体类型名由施工者沿现有约定选取。

| 对象 | 必需语义 |
| :--- | :--- |
| 节律节点 | 唯一名称、角色、坐标及单位、父节点、派生视图或独立状态、推进所有者、初始零点、段号和起停／复位策略。 |
| 父子关系 | 频率比例、偏移所在坐标、差动来源、关系生效时刻；父节点引用存在且父子派生关系不成环。 |
| 耦合关系 | 明确参与节点、误差坐标、目标关系、修正出口及采用策略；耦合网络允许闭环，与父子派生环区分。 |
| 提供者绑定 | 每个拍动、扭转、折翼或事件程序声明读取哪个节点、哪个坐标；尾舵保持和单次过渡允许非周期身份。 |

严格同步通道可以使用派生视图，不必每个关节复制一个 Hopf；需要独立推进或相位纠偏的节点保留自身状态。物理时间仍为统一步号乘步长。真实步统一提交一次，读取、预览和数值子步不增加提交；同一次耦合求值使用一致的状态与明示数值规则，不让节点遍历顺序暗中改变关系。

首配方复用已有关系，不重调参数。以累计拍数为坐标：

```text
dot(chi_c) = f_c
dot(epsilon) = dfreq
chi_L = chi_c + epsilon
chi_R = chi_c - epsilon + delta_0
```

已有折翼首配方继续绑定共模累计周期及原 2.2 rad 偏移；跟随各翼或形状相位是具名可选关系。持续差频与固定同坐标相差不得同时作为硬约束；锁相和允许相差演化分别声明。

## 二、反馈来源及注入位置

在 I-219 参数职责表、I-220 协调规则、I-221 基元耦合和 I-225 所有权接口中逐项登记：请求来源、原值／名义值、已有反馈是否包含、修正量、单位、最终采用者、限幅与生效时刻。

| 输入 | 首个合作版本的规则 |
| :--- | :--- |
| 现有 `freq` 及有效拍频选择结果 | 已有闭环输出作为采用后的速度预算接入；同一能量／姿态反馈不得在节律层再加一次。模式名义值与反馈分解有依据时记录，无法分解时保留“现有闭环采用值”的真实身份，不伪造分量。 |
| 现有 `dfreq` | 作为左右差动请求；协调规则产生实际采用的两翼速度并记录。禁止新旧路径同时注入同一差动。 |
| 相位关系误差 | 进入参与节点的相对推进或耦合修正，不只给主时钟共同加速；相位误差按已声明周期及坐标处理回绕。 |
| 中置、幅值、扭转和尾舵等修正 | 继续按原分配及明确控制权装配；本补充不新增姿态／能量控制增益或重做控制分配。 |
| 基元反馈、拍边或复位事件 | 明确内部状态修正与相位修正的出口；事件保持原段号、唯一消费、预览隔离及过渡规则。 |

共同相位速度同时作用左右时，相减后共同量抵消，不能据此宣称修复了相对相位误差。锁相纠偏与原差频请求发生冲突时，按配方采用规则处理并记录请求与结果，不隐藏抵消或限幅。

## 三、坐标及轨道表述

累计拍数 `chi` 的导数是 Hz 频率；其均匀角坐标的速率为 `2*pi*f`。形状相位受 split 或慢度剖面影响，其瞬时速率与周期预算频率分别记录，不重复时间变形。展开相位与重置段、解缠步长保护继续沿用原方案和 Fil A10。

固定配方及协调关系下可以定义周期参考 `q_ref = Gamma_a(theta; eta)`；独立相对相位、动态基元瞬态和时变参数保留为显式状态，不为得到单一相位表达而删除。周期基元仍保持内部状态，回绕不重置。

动作参考、生成器吸引结构、整机不变集合或相对周期运动分别表达。整机绝对位置可持续平移；动作周期不自动证明整机全状态周期。本批先接入完整参考及生成能力，在完整任务中观察，不新增整机周期轨道证明或性能胜出准入条件。
