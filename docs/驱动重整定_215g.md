# 翼面驱动重整定报告（步骤7，2026-09-20 夜间开发）

## 一、方法与口径

- 工具：`tools/sweep_drive_gains.py`（全状态锁定台架：基座位姿逐步锁定、速度
  清零、无气动力注入——气动力施加于基座被状态锁定吸收，与关节跟踪无关）。
- 波形：WingKinematics 恒频位置目标驱动 9 关节（与 `main_sim._drive_wing_joints`
  同映射、同软启动斜坡）。
- 指标：摆幅比 = std(实际)/std(目标)（判据 ≈1）；峰值 = max|实际|（判据
  远离 ±1.4 rad 机械限位）。
- 失真基准（甲项 A1 口径核对，`docs/甲项口径核对纪要.md`）：A1 全状态锁定
  2.5 Hz 摆幅比 1.83、峰 1.248；本扫描台基线 K=60/D=0.25 复现为 1.423/
  1.020（同性质欠阻尼放大，幅值差异来自 A1 全管线环境；扫描台自洽作
  为重整定基准）。

## 三、选值确定

**K=60，D=2.0**（刚度不变、阻尼 0.25→2.0）。

- 2.5 Hz：摆幅比 1.002，峰值 0.621 rad，限位裕度 0.779。
- 1.55 Hz（新被控对象巡航运行点）：摆幅比 1.011，峰值 0.615 rad，裕度 0.785。
- 选值依据：全场唯一同时满足"摆幅比≈1 且刚度与全部历史数据连续"的点；
  K=120/D=2（1.049）为次优备选。
- 机理注记：ωn·dt ≈ √(K/I)·dt ≈ 2.2 rad/步（I≈0.0009 kg·m²、dt=1/120 s），
  位置驱动的离散积分在刚度主导区数值失稳主导放大，重阻尼压制——与
  700g 时代"700g 翼惯量标定 ζ≈1"注释的连续时间分析口径不同，本注记
  以扫描矩阵为实证依据。
