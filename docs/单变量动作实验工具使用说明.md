# 单变量动作实验工具使用说明

本工具为 I-187 的首个全局拍频实验服务。当前新增的配方编译、确定性输入、实际条件观察、数据资格、离线计算与结果卡代码已完成接口回归。生产环境桥的最小接线尚待文件交接，真实四档八次采集尚未执行，不能据此宣称 I-187 完成。

长期维护三个入口：`config/experiments/global_frequency_v1.json` 声明实验；`tools/action_experiment.py` 编译、采集和分析；`tools/checks/action_experiment_acceptance.py` 从实际原档重算并执行验收。后续同类任务沿这些入口提交配方和证据，不为每轮交流另写运行或验收脚本。

## 当前配方

唯一变量是全局拍频。基准 1.9 Hz、正扰动 2.0 Hz、负扰动 1.8 Hz、减半扰动 1.95 Hz；声明输入范围为 1.7 至 2.3 Hz，范围只约束实验输入，不代表稳定飞行包线。拍动、扭转和折叠的相位及角速度、实际关节跟踪和作用量属于已明示的联动。

构型和气动模型沿当前生产来源，气动模型为 sane_dickinson_3d。初始位置采用加载器当前配置的世界坐标 [0,0,1.5] 米，预检核对该来源；机体在每个主循环求解后重置到同一位置，姿态为单位四元数，速度归零；六自由度不释放，静气，关闭自动驾驶仪、系留和定高反馈，尾舵指令为零。逐步重置属于软件台架，不能称为连续刚性约束。力模型实际输入状态另行检查，不能用配置值代替。

步长为 1/120 秒，预热 8 秒，测量窗为 (8,20] 秒。采集额外保留一个保护步，使 20 秒处的求解后关节读回和原生计步仍有观察；保护步原值保留，作用量不把它算入测量窗。最慢档覆盖超过十个周期。每档由既有统一入口实际执行 A/B，不能使用缓存替代。

频率采用值读回误差沿已登记规则为 1e-12 Hz。当前没有批准的关节跟踪误差阈值，因此只报告逐关节 RMS 和最大绝对误差，不宣称执行器带宽、悬停或控制能力通过。

## 固定用法

在项目根目录执行，命令环境的字符编码按预检提示配置。示例目录必须是新的空目录，不能覆盖旧计划或旧采集。

```powershell
python tools/action_experiment.py plan config/experiments/global_frequency_v1.json --output logs/experiments/本次唯一目录
python tools/action_experiment.py preflight logs/experiments/本次唯一目录
python tools/action_experiment.py run logs/experiments/本次唯一目录
python tools/action_experiment.py analyze logs/experiments/本次唯一目录
```

编译保存配方原文、四档输入、字段定义、当前源码版本及未提交源码原件、构型文件和内容摘要。运行前及每档运行后核对源码；变化后拒绝继续，重新编译新计划，不覆盖旧证据。失败运行不能悄悄续写为成功，不结束其他 Isaac 实例。

`run` 调用 `modules.sim_entry.launch_sim`，保持五项标准锁、人工输入隔离和完整 CSV 双跑比较。结果归档还保存各跑完整原值台账、实际驱动与气动事件、条件快照、CSV 身份旁档和运行日志。记录器文件名会截短标签，归档依据完整头部身份定位，不能只按文件名前缀选档。

`analyze` 先核每份记录的完整性，再做 A/B 比较。完整 CSV 的列、长度、时刻、阶段和非有限数单独检查；原值台账复用 I-184 的资格检查；事件核头尾、连续序号、身份、字节摘要和原值档绑定。两份同样缺失也不得通过。

实际关节顺序取消费者记录的完整关节名称。跟踪误差使用当前求解后位置减上一驱动步实际提交的 float32 目标，不能把本帧新目标与当前读回比较。完整实际配置及幅值、滞后和门控会与基准比较，不能只检查共同字段。

六分量冲量使用成功提交到 PhysX 调用接口的 float32 力与力矩，按下一次有明确原生计步对应的 World 步长积分。暂存力只在实际提交时计入，不能重复积分，也不能拿最近一次回调力或回调累计时间代替。单位为 N·s 和 N·m·s，世界坐标系；它是模型提交量的积分，不是测力计实测或机体动量闭合证明。缺少可靠的原生计步归属时，正式冲量为 null，数据判为不可用。

离线分析验证当前分析依赖与冻结源码一致，并连续重算两次。采集不复用，离线结果能按同一输入、源码、参数和判据重新得到。结果写入 `result.json` 和 `result_card.md`，逐条对应原六条判据，区分运行完成、数据有效和实验方法通过。

## 生产入口最小接线

现有 `modules/sim_env_bridge.py` 把自动试验与硬件手动输入放在同一开关内。统一入口设置 `FLAPPER_NO_MANUAL=1` 后，旧自动试验也被跳过；旧 `ExperimentController` 使用墙钟排程。因此本工具提供独立的确定性输入，只有明确选择实验配方时启用，沿用已有主循环和关节消费者。

所需修改现已收缩到一个文件，不需要修改 `modules/experiment.py`、气动公式、控制器或增益。取得该环境桥文件的交接后，在气动回调构造和配置导入之前加入：

```python
from modules.experiment_pipeline.action_recipe import prepare_runtime_input
_recipe_manual = prepare_runtime_input(world, mav_view, _G)
```

原手动输入选择处改为：

```python
if _recipe_manual is not None:
    manual = _recipe_manual
# 随后用 elif 接续原有 ExperimentController / ManualInput 分支
```

未提供 `FLAPPER_ACTION_EXPERIMENT_CASE` 时辅助入口直接返回 None，不更改配置。实际配方入口核对冻结输入，按真实 A/B 标签建立独立运行身份，并通过宿主仿真时钟读取排程时刻。实际条件与模型消费者仍须经真实运行核验，接线片段本身不构成验收证据。

## 检查与正式提交

```powershell
python tools/checks/test_action_experiment.py
python tools/checks/action_experiment_acceptance.py
```

第一条是工具正反例回归，测试数据只用于检查接口。第二条读取固定交付清单 `outputs/i187_action_experiment_manifest.json` 指向的实际计划，重算全部证据并要求六条判据通过；无实际采集时必须失败。它才是事项登记的实验验收入口，不把单元检查绿灯当作实验完成。

完成生产接线后须重新编译真实实验计划，先登记计划内容摘要，再执行真实采集；当前接口预检计划不能冒充正式采集。登记与结载使用既有事项服务，保留机主授权与本项自行审理边界，不把作者自检称为第三方独立验收。
