## 五、归因判读

1. 设定值修正的独立效果为量级改善、非质变：坠地时刻 3.758→3.983 秒
   （+0.225 秒，+6.0%）；高度峰值 7.101→6.312 m（-0.79 m，-11.1%）；
   失控速度峰值 29.63→24.34 m/s（-17.8%）。改善方向与清单预期一致
   （发射能量、初始俯仰、配平频点更贴近三维模型配平域），但距离 60 秒
   通过线仍差一个数量级以上。
2. 失败模式与第 3 步逐位同型：发射后推力剩余把 vx 从 4.0 推到 24+ m/s、
   机体上冲爬到 6.3 m、pitch_des 顶死 +0.35 rad 限幅、拍频落到 1.1792 Hz
   下限、失速俯冲坠地。拍频与俯仰指令的行为指纹（下限值、限幅值、
   锁定期 3.5 顶满）与基线完全一致，说明频率/能量通道的行为不是
   差异来源，也未被设定值修正改变。
3. 剩余归因指向俯仰力矩配不平（主）：pitch_des 全程试图拉杆（正值爬到
   限幅）而机体俯仰实际在 ±0.9 rad 级震荡，俯仰通道在三维模型上没有
   配平能力——俯仰力矩配平点漂移导致控制器权限耗尽。这与 git 提交
   e2d2209 附带预警一致（sane_dickinson_3d.py:51 镜像变换缺行列式因子，
   当前为死参数无害，恢复 ω×r 前必修正），也与第 3 步失败归因清单的
   第二候选（俯仰力矩错配）一致。
4. 结论：设定值修正解决第 3 步失败的可归因份额约 6%（存活时长口径），
   失败主因不在设定值域，下一步应走模型侧（俯仰力矩配平/三维后端
   力矩修正），而非继续调设定值。
