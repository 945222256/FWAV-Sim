# FW-IID 预登记卡：阶段二引擎侧单因素矩阵

```
试验标签：fw-iid-ph2-f1 … fw-iid-ph2-f8（八因素同卡预登记）
试验目的（对应假设编号：乙）：在阶段一封锁基线上逐一切换单一引擎因
    素，判定分歧是否由引擎配置项消除，以及首差通道是否随因素迁移。
基线：阶段一封锁组配置（无头、台账、三十五秒、随机源固定）。基线事
    件率以阶段一封锁组八对的读出为对照列。
单因素纪律：每次试验只允许一个因素偏离基线；任何组合试验不进入判定
    矩阵；每个因素水平的成对运行重复三次（三对六跑）。
因素表与实施开关：
    因素一 GPU 刚体管线：FLAPPER_PHYS_GPU=1（基线为 CPU 物理，偏离臂
    为开 GPU 动力学）。若基线实读打印显示默认已开 GPU，则两水平对调
    （基线开、偏离关），以实读为准并在结果表登记。
    因素二 中央处理器线程数：FLAPPER_PHYS_1THREAD=1（单线程臂）。基
    线线程数以 carb 实读打印为准。
    因素三 增强确定性标志：FLAPPER_DET_OFF=1（关臂）与
    FLAPPER_DET_ON=1（开臂）。标志现值以 USD 层
    physxScene:enableEnhancedDeterminism 与 carb 层双打印为准；若基线
    已置位则偏离臂为关，反之亦然。
    因素四 求解器类型：FLAPPER_SOLVER=PGS（基线 TGS，偏离臂 PGS）。
    因素五 求解迭代次数：FLAPPER_ITERS="位置,速度"。基线值以启动打印
    的刚体层 physxRigidBody:solverIterationCounts 基线值集合为准；偏
    离臂取基线加倍值。
    因素六 宽相碰撞检测类型：FLAPPER_BROADPHASE=SAP（基线 MBP，偏离
    臂 SAP）。
    因素七 连续碰撞检测：FLAPPER_CCD=1（基线关，偏离臂开；实施为场
    景级 physxScene:enableCCD）。
    因素八 关节组求解位置（中央处理器对图形处理器）：本版本该档位
    与 GPU 动力学管线绑定（无独立开关，USD 场景属性行单一路径），
    其图形处理器臂由因素一的偏离臂覆盖，不设独立试验；此耦合在判
    定报告中显式声明。
预测（含数值或逐位结论）：
    预测一（延续 0928 四臂与阶段一读出）：全部因素的偏离臂均不消除
    分歧（各因素三对内至少一对分歧）；各臂首差步随机分布、首差幅度
    为末位量级、首差通道属机体状态族（bp 或 bv 或关节族）。
    预测二（若某因素三对全部逐位相同且偏离方向与基线档位差异明确）：
    该因素为分歧的配置根因，按判定矩阵对应行处置。
证伪条件：
    其一，任何因素的偏离臂与基线的事件率差异不可分辨且全部逐位相
    同：预测一方向被支持，假设乙（引擎内注入）证据闭合的前提是其
    全部因素都不可消除分歧。
    其二，同因素三对读出自相矛盾（既有全同又有分歧且首差形态不
    同）：该因素读出标未判定，不进入判定矩阵，加倍重复。
读出量：逐位是否相同、s*、c*、首差幅度；组级汇总进
    logs/fw_ph2_summary.json。
配置基线：Isaac Sim 5.1.0；物理步长 1/120 秒；每次运行全新进程；驱
    动版本与阶段一相同（同一台机器当日连续执行）。

登记时间：2026-09-29
```
