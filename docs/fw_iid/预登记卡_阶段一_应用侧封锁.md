```

试验目的（对应假设编号：甲）：检验假设甲（应用侧注入：两次运行向引
    擎提交的输入序列不同）。封锁项逐项核对与执行后，若封锁组分歧消
    失而对照组分歧复现，则假设甲成立。
封锁项核对（方案第六节阶段一清单，逐项声明现状）：
    项一（控制器仅以物理步计数器决策）：代码现状已满足；飞控 dt 取
    权威物理时钟差分，墙钟仅用于帧率统计，渲染帧号不参与控制。
    项二（步长固定、每渲染帧物理步数固定、无渲染基线）：现状满足；
    物理步长 1/120 秒，渲染间隔固定四步，基线跑全部无头模式。
    项三（异步回传关闭、日志同步写）：无头模式下渲染不执行；台账在
    主循环内同步写盘；遥测外发不回馈物理。
    项四（随机源固定种子、关闭噪声注入）：本次新增封锁开关
    FLAPPER_IID_LOCK=1，固定 random 与 numpy 两个随机源为零号种子；
    静态障碍默认二十个由随机数放置，是本项封锁的首要对象。
    项五（全新进程、场景从零构建、创建顺序固定）：现状满足；每次运
    行经 python.bat 全新进程启动。
    项六（对照组）：对照组不设 IID_LOCK，其余与封锁组相同。
配置（两组共用）：Isaac Sim 5.1.0；FLAPPER_HEADLESS=1；FLAPPER_LEDGER=1；
    FLAPPER_MAX_S=35；时长选择依据：历史分岔实录聚于七至九点四秒，
    三十五秒窗口覆盖事件聚集区与巡航时界，与 0928 四臂口径一致。
    每组八对（一十六跑）。样本量依据：历史成对分岔率约九分之一，
    八对在真实率不低于九分之一时零事件概率低于百分之四十，足以避
    免单对碰巧一致被误判；按方案第九节，事件率差异以威尔逊区间报
    告，不单靠点估计。
预测（含数值或逐位结论）：
    预测一（假设乙方向，与 0928 四臂结论延续）：封锁组仍出现分歧
    对；首差步随机分布；首差通道属关节求解响应族（je、jv、bv）；
    首差幅度为离散事件量级（远超末位单位），即 0928 已实录的单步
    跳入形态。
    预测二（假设甲方向，仅当封锁组八对全部逐位相同且对照组分歧率
    不低于历史量级时）：障碍随机放置经碰撞池排布进入引擎处理顺序，
    构成应用侧注入；此时假设甲成立，流程转阶段四。
证伪条件：

    效，假设甲的应用侧随机注入路径证伪（支持假设乙）。
    其二，封锁组全同而对照组全同：分歧在两组都不可复现，本批读出
    失效，须回查试验登记档案并加跑，禁止下结论。
读出量（s*、c*、首差幅度、逐位是否相同）：
```
