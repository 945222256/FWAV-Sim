# FW-IID 阶段零定案：位级基线管道验收通过

日期：2026-09-29。依据：《扑翼冲量积分差分测量方案规划》第六节阶段零。

## 一、交付物

其一，冲量台账记录器：modules/fw_iid_ledger.py 的 LedgerRecorder；主循
环每物理步求解后记录八通道（bp 位姿七元、bv 速度六元、jp 九关节位置、
jv 九关节速度、je 九关节实测力矩、tgt 九关节目标、Fa 气动施加力、Ta
气动施加力矩）共五十五个双精度浮点位型；文件布局为魔数加头 JSON 加
逐步记录体加尾部统计；FLAPPER_LEDGER=1 开启，默认零触碰。

其二，逐位比较器：同文件 compare 命令行；输出首差步 s 星号、首差通
道 c 星号、三十二位与六十四位双口径位差、每通道差步统计、十秒桶分
布、可选扑翼周期积分差分；退出码零为逐位相同、一为存在差异、二为档
案错误。

其三，仪器校验注入口：FLAPPER_LEDGER_ULP 等于「步:关节名」时在该驱
动拍对该关节目标的三十二位位型翻转最低有效位一次。

其四，封锁开关：FLAPPER_IID_LOCK=1 固定 random 与 numpy 两随机源为
零号种子（阶段一封锁项四执行机制）。

其五，仪器自测：tools/_fw_iid_selftest.py 三案（末位注入定位、逐位相
同判定、损坏档案拒判）全部通过。

## 二、验收运行判读

跑甲（无注入）与跑乙（步六百 flap_L 注入）各十二秒、各一千四百四十
步。验收判据逐条核对：

其一，比较器报告差异：成立，差步八百四十。
其二，首差步等于六百零一：成立（注入于驱动指令步六百写入，物理步六
百零一生效；预登记卡预测值即六百零一）。
其三，步六百零一 tgt 通道 flap_L 元素位差恰一个三十二位末位单位：
成立（三十二位位差为一）。
其四，通道归属正确：成立（同拍差通道为 jp.flap_L、jv.flap_L、
je.tail_yaw、je.fold_L、bp、bv、Fa、Ta，全部位于注入响应路径上）。

附加实录：单末位注入经七秒放大后差异持续存在且不回收（末段每通道差
步占比为差步总数除以剩余步数等于一），与李雅普诺夫放大预期一致。

## 三、过程缺陷与修正（留痕）

其一，比较器首版把数组行号当步号报告（台账首行步号为一，行号与步
号相差一），验收卡点四当场抓住，已修正为步号列取值并全字段统一口径。
其二，tgt 通道首步（步一）缺失一次（首帧记录先于首次驱动写入），两
次运行行为一致，不影响逐位比较；已在预登记卡口径声明。

## 四、判读纪律延续

比较器通过校验前的一切后续阶段禁令解除；阶段一起跑。
