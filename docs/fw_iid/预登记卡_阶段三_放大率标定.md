# FW-IID 预登记卡：阶段三放大率标定与注入分辨

```
试验标签：fw-iid-ph3-lyap 与 fw-iid-ph3-ulp 与 fw-iid-ph3-stats
试验目的（对应假设编号：丙）：其一，测横向李雅普诺夫指数 λ 的实测区
    间（三量级一致性检验）；其二，人为末位注入试验（关节目标位型翻
    转末位一次，验证舍入量级注入足以解释宏观分歧）；其三，汇总全部
    首差样本判注入形态属随机末位族还是事件绑定族。
子试验一（λ 标定）：
    注入口：FLAPPER_PERTURB_ROLL（释放序列末位施加，绕机体 x 轴）。
    三个量级：0.01、0.001、0.0001 弧度；每量级十六次注入运行，与同
    配置同种子的一个基线运行配对差分。
    拟合口径：从台账 bp 通道取两运行的滚转角差序列 δ(t)，对
    ln|δ(t)| 做对数线性回归，回归窗取注入后一秒至滚转差首次饱和或
    回收之前；十六次拟合的中位数与四分位区间为该量级读出。
    预测：三量级的 λ 区间相互重叠（非线性饱和可忽略段）；巡航段量
    级与 0928 实测（约每秒一点二）一致；释放瞬态段（首拍）放大率远
    高于巡航段（0928 实测约五千倍首拍跳变），两段分开报告。
    证伪条件：三量级 λ 区间互不重叠时 λ 标记未判定，判定矩阵中依
    赖 λ 的行降级为参考证据（方案第十一节风险三对策）。
子试验二（人为末位注入）：
    注入口：阶段零已校验的 FLAPPER_LEDGER_ULP（关节目标末位翻转一
    次）。注入时刻取释放后巡航段（步六百即五秒）与早段（步一百二
    即一秒）两个拍位；各重复四次（成对运行）。
    预测：末位注入后两次运行的宏观结果分岔（差异持续增长不回收），
    且增长速率与子试验一的 λ 实测值吻合；该证据支持假设丙的放大机
    制（注入为末位量级即可致宏观分歧）。
    证伪条件：注入被动力学回收（差异衰减至零并保持）则末位注入不
    足以解释宏观分歧，假设丙的放大机制在这条路径上削弱。
子试验三（首差样本统计）：
    样本：阶段一与阶段二全部成对运行的首差读出（s*、c*、幅度、增
    长率）。
    判据：若 s* 时间上随机分布、首差幅度恒为一个至数个末位单位、
    且首差后的增长速率与 λ 实测吻合，则证据支持假设丙（固有放
    大）；若 s* 绑定同类仿真事件（首次接触、限位触发、命令切换），
    则证据支持事件触发差异，按事件归属分别归入假设甲或乙。
读出量：λ 区间（三量级各自中位数与四分位）、末位注入的分岔判定与
    增长率、首差样本全表。
配置基线：与阶段一封锁组一致（随机源固定、无头、台账开启）；λ 子
    试验时长二十秒，末位注入子试验时长三十五秒。
登记人：ZCode 执行席（B 队会话）
登记时间：2026-09-29
```
