# 仿真器确定性与李雅普诺夫伴随实验记录（2026-09-28，用户令双线）

## 一、仿真器判决（第一线）

工具与实装：[PHYS] 启动配置打印、FLAPPER_PHYS_CPU=1（carb 关闭 GPU
动力学，已验生效；单线程接口此版本无）、FLAPPER_DETCHECK=1 高精度
侧档（float64 十六进制逐行）、FLAPPER_PERTURB_QW 扰动注入口。

首批：GPU 对与 CPU 对各两跑，八秒全精度**均逐位一致**；但前一日
同命令对照对在七点六秒分岔（末态差零点八米）。十连跑战役定律：
**九分之一分岔**，分岔为**单步跳入**（前一拍全精度为零、当拍
δ=八点三乘十的负五次方），事件时刻聚于七至九点四秒，随后一秒内
长到百分之一量级。判决：非确定性为**间歇性离散事件注入**，不是
浮点加法序的连续灰尘放大（全精度数据排除连续放大说）。事件源
未定位（求解器内部突发，GPU/CPU 是否同频率样本不足，登记待办：
CPU 十连跑对照）。

## 二、李雅普诺夫伴随（第二线）

过程事件两起如实记：首版注入口置于俯仰同步块之前被干净四元数
覆盖（巡航对逐位一致的教训），搬移至释放序列末位后修正；注入
一比百万经归一化与 float32 后实际生效约一个最小位（六点七乘十
的负八次方）。

两段发散律（全精度 δ(t) 与滚窗 λ）：
- 释放瞬态极烈：注入后首拍差即达三点五乘十的负四次方（十毫秒内
  放大五千倍）。
- 巡航段 λ ≈ 每秒一点二（翻倍周期约零点八秒）。
- 坡度切入与建立段 λ ≈ 每秒四至五（翻倍周期约零点二秒）。
- 由一个最小位的初差长大到宏观失相关：巡航约十四秒内、坡度段
  约三到四秒内（实测一点五乘十的负七次方 → 百分之一用了二点七
  秒）。

## 三、合并判读：可预测时界

t* ≈ ln(ε/δ₀)/λ。取注入下限一个最小位：巡航 t*≈十三秒，坡度段
t*≈三到四秒；若间歇事件（万分之一级）砸中：巡航 t*≈七秒，坡度
段 t*≈二秒。**六十秒巡航远超时界=掷硬币的数学根源；坡度切入后
一切单次结论的时窗只有三到四秒**。此前所有单次"到不了/翻不掉"
的断言都在时界之外，判读效力作废重审。

## 四、方法论定则（替代"跑三遍"）

其一，任何存活类判据在时界外的检验必须以重复实验的统计量
（存活率、发散时刻分布）为结论，单次不作数；样本量按二项置信
区间宽度需求定，不得拍数。其二，短时窗（三秒内）的单次机理
试验（如释放瞬态、切入掉高）仍有效。其三，事件源定位与
CPU 模式频率对照为下一步（各一组十连跑）。
