### 3.1 完整动作对象的必填内容

`ActionRecipe` 必须包含九坐标目录、配方版本、提供者、基准参数、节律后端与坐标、相位关系、事件、约束、控制权、几何与气动适配器标识。

`ActionFrame` 必须包含：

~~~python
frame_id, recipe_version, step_id, t_eval, t_effective
requested_parameters, effective_parameters, rhythm
q_d, q_dot_d, q_ddot_d
channel_roles, derivative_status, active_events
aero_view, adapter_id, parameter_sources
~~~

所有关节都有明确角色：生成、控制器提供、保持、被动或未支持。未支持不能以零伪装；请求值、目标值、实测值分别保存。

关节目标与气动视图可以表达当前已有的不同取值，但必须列明映射和来源。当前关节与气动俯仰参数不同，当前中置作动与平面气动几何不同，均不得在装配时静默抹平。

### 3.2 参数的可解释性约定

保留 `q=μ+a*z+δq`。旧中置仍按行程中心解释；参考形状的中心、尺度和相位零点写入配方，避免形状权重重复吸收中置、幅值和相差。归一化针对参考形状进行，不对每步输出再做隐含缩放或截断。

配置快照读取当前已生效的值，包括环境覆盖及原生对象实际构造值。保留中置／偏置 `μ`、幅值 `A`、分段周期比 `s` 和俯仰滞后 `lag` 的原含义，角度在适配边界明确转换一次。对应源码常量及公式见原资产文档第 2、3 节和本方案的配置行段。

原关节角偏置差动和幅值差动分别命名；原控制器的 `dA` 按配方中的明确旧语义绑定。不能统一字段时顺带把角偏置改为幅值差。差频约束沿用该通道已定义的作用范围，不把差频通道专用上界新增为所有集体拍频的第二层限制。

### 4.5 动态运动基元：实现完整形状能力

**新增位置：**`motion_action/primitives.py` 与 `trajectories.py`。

周期基元按设计中的规范相位推进：

$$
G=-kz-dv+F(\theta;w)+c,\qquad
\dot z=\dot\nu v,\quad \dot v=\dot\nu G,\quad
\ddot z=\ddot\nu v+\dot\nu^2G.
$$

实现周期基函数、权重、状态初始化、参考轨迹导入与变换系统。单次基元另有起点、终点、规范进度与形状驱动；规范进度由共同服务中的已声明事件时间或拍数预算派生，不能在基元里另起一个无关时钟。

拟接口为：

~~~python
fit_reference(samples, normalization, phase_coordinate)
reset(initial_state)
advance(clock_sample, parameters, coupling, dt)
sample()
clone_for_preview()
~~~

提供者生成归一化形状及其导数，装配层计算中心、幅值、控制修正与镜像。时变中心和幅值的链式导数按原设计补齐。耦合入口声明单位和控制权，不能与旧控制器同时写同一修正量。

参考轨迹可以从当前解析程序或采样导入；它服务于初始化和新动作构造，不以拟合出旧轨迹的逐位等价性作为动态基元能否并入的前提。`legacy_current` 的精确保留由原提供者负责。

## 5. 新路径的一步调用顺序

设已经完成物理步 `n`，其步后控制需求为 `commands_n`：

~~~text
步前：
  queue(commands_n) -> ParameterAssembler
  advance_once(step=n+1) -> RhythmSnapshot
  update primitives/transitions once -> ActionFrame(n+1)
  validate consumers -> write nine joint targets and tail
步内：
  world.step -> aero callback reads ActionFrame(n+1)
  clone runtime/model cache -> preview window -> apply force
步后：
  join target/aero/actual receipts for n+1
  observe body -> existing controller -> commands_(n+1)
~~~

共同服务是唯一真实推进者；预览只改副本。控制器、气动回调和记录器不再分别推进新动作时钟。真实读者多次读取同一帧只得到同一版本。

当前 `main_sim.py` 第 758—760 行有可选主循环气动调用且连续调用两次，回调注册又有前／后步选择。新路径初始化须检查回调路由，并按物理步验证消费次数；不允许通过重复回调多推进节律。首次支持标准物理回调，新路径对未支持的回调路由明确报错。旧配方的路由不在本次改写。
