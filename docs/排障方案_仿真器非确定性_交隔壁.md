# 排障方案：仿真器间歇性非确定性事件（2026-09-28 交隔壁团队）

> 用途：定位本项目仿真器的偶发单步状态跳变（下称"事件"）的机制
> 类别并围栏或共存。本方案自足；判据全部先于数据写定，运行后不改。
> 全部表述只用函数、标度律、符号与排序；离散读数只存在于档案
> （logs/detcheck_*.csv、logs/lyapunov_*.json 与
> docs/仿真器确定性与李雅普诺夫伴随_20260928.md），正文不引用其数值。

## 零、已确立的定律（排查的地基，不必复证）

其一，偏差增长律 δ(t)=δ₀·e^{λt}，增长率排序 λ(释放瞬态)≫λ(坡度段)
> λ(巡航段)，全部为正。其二，事件形态：前一拍全精度严格为零、当拍
单步跳入，跳变量级远超浮点舍入尺度——**连续微差放大说已被排除**
（浮点求和顺序类机制指纹不相容，勿再走该路）。其三，事件为间歇性，
发生过程近似泊松（率 R），由此两跑到时刻 t 已失相关的概率
P(t)=1−exp(−R·t)。其四，GPU/CPU 动力学两档与负载的依赖关系**未知**
——这正是本方案要裁的。

## 一、机制候选与函数指纹（判据的理论依据）

| 机制类 | 事件率对负载的响应 | 事件率对线程争用的响应 | 跳变量级分布 | 事件时刻特征 |
|---|---|---|---|---|
| 甲·竞态（跨线程读写颠倒） | 随争用上升，近似正比 | 争用归零则率归零 | 台阶化（量子=被竞争变量两取值之差） | 随机 |
| 乙·求解器分支（warm-start/接触排序换路） | 平坦（与负载无关） | 单线程不消失 | 连续分布，尺度与求解器容差同阶 | 随机 |
| 丙·时基混用（渲染/墙钟节拍量进入物理路径） | 随渲染负载上升 | 单线程不归零 | 台阶化或连续 | 与节拍边界相位相关 |

## 二、工具与运行纪律（全部在库）

- 高精度侧档：FLAPPER_DETCHECK=1（float64 十六进制位姿逐行，判分岔
  的唯一权威口径）。
- 物理器档位：FLAPPER_PHYS_CPU=1（关 GPU 动力学；本版本无单线程
  接口，单线程化另见 E-B）。
- 扰动注入口：FLAPPER_PERTURB_QW（本方案不用，属发散律线）。
- 分析：python tools/lyapunov_companion.py <档A> <档B> --png out.png。
- 标注必填：每次运行带 FLAPPER_TAG 与 FLAPPER_DESC，缺一会被
  [TAG-FAIL] 拒绝；跑完在回放台核对记录。
- 样本量一律按置信区间定：事件率估计的区间半宽目标 w 取策略值，
  二项样本量 n ≥ ẑ²·p̂(1−p̂)/w²，逐档补跑至达标；不得拍数。
- 仿真时长取覆盖已归档事件时刻分布支撑集的整段（见地基档案），
  各档一致。

## 三、实验清单（每项含判据与解读分支，先于数据）

### E-A 负载扫描（裁"率是否随争用变化"）

配置：同命令对照对，后台压力从空载到饱和分档（压力用并行压测
进程实现，档位以实测占用率标定），每档按第二节样本量公式跑足。
判据：拟合 r(负载) 的斜率及其置信区间。
解读：区间不含零且斜率为正 → 甲或丙（争用依赖）；区间含零 → 乙。

### E-B 线程争用扫描（裁甲）

配置：进程亲和性钉核与优先级两维扫档（Windows start /affinity、
/realtime 族），外加一切可得途径压缩物理并发；同命令对照对按
样本量公式逐档跑足。
判据：r(争用) 的函数形态。
解读：随争用趋零而率趋于零 → 甲成立；率不随争动 → 排除甲，剩乙丙。

### E-C 跳变量级分布（裁甲的量子指纹）

配置：汇总各战役全部事件的 δ_jump，做分布检验：离散台阶检验
（值聚类于少数量子之比）对连续分布检验；并与候选被竞争变量的
取值差尺度、求解器残差尺度分别比对（尺度比取自档案）。
解读：台阶化且量子匹配某共享变量 → 甲坐实并指认变量；连续且与
容差同阶 → 乙坐实。

### E-D 事件时刻相关性（裁丙）

配置：把事件时刻对运行内周期过程（数据流落盘节拍、渲染帧节拍、
内存增长曲线、接触对数增长曲线）做风险函数相关性检验。
解读：与某协变量显著相关 → 丙坐实并指认混入点；全不相关 → 排除丙。

### E-E 围栏与复验（定位后执行）

按定位结果上围栏，全部仪器侧、开关形态、默认关：
甲 → 动力学路径共享变量改每步冻结快照（双缓冲）；乙 → 若闭源
不可修则转共存（第五节）；丙 → 混入量统一到物理时钟。
每道围栏后同战役复测，关账标准为函数形式：事件率置信上界随
样本量按平方根分之一收窄至策略阈值之下。

## 四、禁改清单

## 五、共存条款（若乙且不可修）

一切时界外结论以报告律发布：P(t)=1−exp(−R·t) 复合各段增长律
δ(t)=δ₀e^{λt}；参数 R 与各段 λ 以拟合值加置信区间形式维护成
活表（lyapunov_companion 持续更新），原始读数只入档案。
