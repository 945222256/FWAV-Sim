# 在环复跑前置·控制器设定值修正清单（第十九班 3a，只备不执行）

依据：第十七班在环确认（docs/三维模型在环确认.md）的归因二——控制器
设定值按冻结几何版配平标定（速度 4.5 m/s、拍频 1.55 Hz、俯仰
−0.05 rad、攻角设定 40°），与三维模型自洽配平域（速度 3.5~4.0 m/s、
拍频 1.00~1.75 Hz、俯仰约 +7°、攻角设定 35°，出处
docs/单拍量子_包线网格.md 巡航格与 docs/三维盘旋扫描_高分辨率复跑.md
配平复核）错配。本清单列出全部改动点；执行须待用户批准，且按计划
先于阻尼更换单独复跑一次（归因分离基线）。

## 不改项（核对过）

- FREQ_AP_MIN=1.0（665 行）：新拍频 1.75 的频带 0.9×=1.575 Hz 高于
  下限，不需要改。
- 速度验收带 4.5±1.0（643 行注释）：下沿 3.5 m/s 覆盖新设定 4.0，
  3a 不动；若追求口径干净可另批改中心为 4.0±1.0。
- MANUAL_FREQ_MIN=1.2（409 行）：手动油门下限，自动驾驶域不受影响。

## 口径警示

- PITCH_TRIM（707 行）=0.000 属力矩配平口径，注释明示不得与气动
  配平口径混用；三维模型存在未配平俯仰力矩 +0.374 N·m（第十七班
  第二步），该键怎么动取决于配平方向裁决（改扑动运动学或鲁棒
  接受），不属 3a 范围。
- 波形攻角设定从 40° 切到 35° 会改变全部在环行为基准；此改动与
  AERO_MODEL 切换（在环确认用）属同一口径族，复跑时两者必须同时
  生效，否则波形与模型不配套。
- 执行顺序纪律：3a 单独复跑（只改上表七项 + AERO_MODEL=三维，不动
  阻尼）→ 读归因 → 3b 换阻尼 → 3c 增益重整定与复验。

## 执行方式（获批后）

由子代理执行：逐项修改并核对行号 → FLAPPER_HEADLESS=1 跑 60 秒 →
读日志（存活、高度带、行为指纹）→ 还原或保持（按用户指令）→
报告写 docs/三维模型在环确认_3a复跑.md。
