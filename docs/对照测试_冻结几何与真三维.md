# 结论（第十二班判读）

## 一、检查项二翻案：翼差动"塌缩且变号"主要是冻结几何简化的模型失真分量

冻结版 B_roll 随频率 +0.022→−0.151（塌缩＋变号，第九班定案的形态）；
真三维版 B_roll 随频率 −0.001→**+0.351 单调增长**，3 Hz 处达到尾翼差动
权限（约 0.10）的 3.5 倍。**在自洽扫掠几何下，翼差动滚转通道是活的、
随拍频增强的、不变号的。**"翼差动塌缩三百倍"的结论必须降级为"冻结
模型的实测"——滚转主通道迁移到尾翼的裁决、RL 两通道动作空间的依据
（B_dA 无用论）都需要在新模型上重估。

偏航方向相反：三维版 B_yaw 比冻结版小约 2.5 倍——冻结版高估了差动
出偏航、低估了差动出滚转，两者的物理图像在三维下互换。

## 二、检查项一通过回归门，但暴露悬停推力差

竖直力两版同阶同号（−0.14 对 −0.28，本波形悬停不可达的定案两版一致）。
但悬停前向力：冻结版 +0.30 N（"推力富余"），三维版 **0.000**——冻结版
的悬停推力富余疑为无符号 x 速度分量的模型失真分量，与"爬升守卫前的气球现象"
的机理链需要重新对账。

## 三、检查项三的诚实边界

三维版侧力在 vy=±1/±2 两向同为正（+0.25~0.29），偏航力矩亦两向同号
（约 +0.05）——存在一个与侧滑方向无关的侧向分量（疑为不对称分裂比
经扫掠几何的整流，或 α_eff 角域分支的模型失真分量），**该钩子在定性上未通过
镜像对称性自检，三维模型的侧向力符号约定需要下一班复核后方可引用**。

# 几何修复记（第十二班，三次迭代）

1. 首版右翼扫掠 x 分量用了带符号半径（右翼前后扫反）——侧向力出现
   与侧滑方向无关的 +0.24 N 常值分量，巡航点竖直力为负。
2. 二版修正 x 分量后攻角参考矢用错（固定参考法向而非俯仰后弦面
   法向）且法向力叉积顺序反置——左右翼竖直力成对抵消，全场升力
   为负、任何波形参数下不可配平。
3. 终版采用镜像变换包装：右翼永远在左翼标准系计算，力与力矩经
   镜像矩阵变换回机体系——从构造上保证严格镜像对称。修复后升力
   恢复（最高 +6.48 N = 3 倍体重），侧向力奇对称逐点成立。

# 修复后的三个考核工况结论

- 检查项一（悬停）：两版同阶同号（−0.14 对 −0.31），"巡航波形悬停
  不可达"定案两版一致。
- 巡航考核工况：三维版在冻结配平点 Fz=+3.14（冻结版 +2.80，量级
  一致偏高 12%）、Fx=+0.05（一致）；**新增 +0.54 N·m 扫掠俯仰耦合力矩
  （冻结版恒零）**——这是扫掠几何打开的新物理通道，配平需重扫。
- 反向来流考核工况：三维版 Fx=+1.55 阻动（方向正确由几何保证），
  Fz=−29（真实下压，冻结版 +24 为假升力）；反区数值待真机标定。

# 检查项二权威结论（翻案维持并加强）

三维版 B_roll 全频段为正、单调增长（+0.123→+0.472），1.55 Hz 运行点
即为冻结版的 5.7 倍；B_yaw 同步为正增长（+0.080→+0.343）。冻结版的
"塌缩＋变号"确认为几何简化的模型失真分量；差动翼面通道的滚转与偏航
操纵效能均随拍频增强、无变号。
