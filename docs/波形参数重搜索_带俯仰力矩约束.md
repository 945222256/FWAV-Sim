## 判读补充：无解的结构性观察与代价（对 JSON 的二次分析）

1. **压缩量**：最近能力 0.1800 N·m 对基线 0.3741 N·m 压掉 51.9%，但未达 0.10 达标线，也未达 0.15 降级线。
2. **约束前沿**：把竖直残差放宽到 5.8%，|My| 可以到 0.1604（α35/MEAN+0/f1.75/V4.0/SP0.50/LAG−0.04/AMP30，残差 5.36%）——竖直平衡小岛（第十六班包线网格结论的再现）是绑定约束，力矩旋钮与配平域在 0.10~0.16 区间互卡。
3. **三轴同时顶格**：最近能力点同时压在搜索域三面边界上（MEAN+10° 为网格上限、V3.5 为网格下限、SPLIT0.50 为网格上限），提示极小值很可能在声明域之外；域外走向未验证，扩域属新的工作令（建议轴：MEAN +12.5/+15/+20°、V 3.0 m/s、SPLIT 0.625/0.75，同工具改轴重跑约半小时）。
4. **姿态代价**：前沿点的配平俯仰 +15.6° 至 +24.5°，全部高于现行 +7.14°；高姿态点更靠近叶素攻角 45° 饱和区（第十九班扩段已证该区斜率弱化 42.8%），若被选为工作点，其阻尼矩阵须按 12.7 节挂账复测。
5. **旋钮方向**：残差过线的前八名全部落在 SPLIT≥0.375（前五名中四名 SP0.50）——分裂比增大是压 My 的最强变体轴；LAG−0.04 与 −0.02 次之；MEAN 方向与速度强交互（+10 与 −5 都出现在前沿）。
6. **舵面消化预算不可行**：最近能力点残余 0.1800 N·m 折算升降舵偏度 0.710 rad，占 ±0.30 rad 限幅的 237%；升降舵满偏最多配 0.076 N·m（0.2535×0.30）——路线图"残余力矩的舵面消化预算"分支在该点同样不成立，接受该点即接受常值俯仰力矩残余，其闭环影响须在环评估。
