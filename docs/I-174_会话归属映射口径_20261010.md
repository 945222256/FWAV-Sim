# 会话归属映射口径（I-174 冻结，2026-10-10）

> 判据要求映射口径文档同步更新。本文件为控制台会话归属的唯一口径。

## 一、三组定义

施工会话组（group 为 worker）：归属依据为两处在册记录之一——认领
记录（认领事件详情携带自报会话号，I-174 起）或派发登记册（I-143
三元组，宿主服务派发时写入）。两条记录互为补充：派发登记覆盖宿主
服务派发的会话，认领自报覆盖客户端内施工会话，认领自报为权威来源。

机主会话组（group 为 owner）：两处在册都查不到的会话。客户端随手
打开的对话属于本组，不再标注未挂事项。

归档组：已交接归档的施工会话，保留原归属，含回填依据指针（I-170）。

## 二、认领自报机制

施工队认领事项时携带会话号（claim 的 session_id 参数），云端写入
认领事件详情，形态为"认领，租约四小时，会话 sess_xxx"。宿主服务
派发时在简报末尾自动附自报指令（含派发回执的会话号），施工队照抄
即可，无需自行查询。

## 三、回填与测试的边界

历史回填依据三源取证（I-170），无依据不猜不挂。测试与自检派发不
登记索引、不进登记册（I-157），其临时会话不进入任何分组展示。

## 四、与既有机制的关系

I-157 驻留注册表（一队一驻）是派发侧的会话换绑机制；本口径的映射
读取以认领记录为权威、派发登记为补充，驻留表作为派发侧状态保留。
三者来源不同、职责不重叠：驻留表管派发路由，认领记录管归属展示，
登记册管派发历史。
