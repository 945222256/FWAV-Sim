# 权限包线与因子隔离定案（2026-09-28 晨）

依据：《量子异步抽验_口径调和.md》第四节第一步（量子表加侧滑与坡度
两维）。工具两件：tools/quantum_envelope_scan.py（包线）、
tools/quantum_state_factor_isolation.py（因子隔离）。数据两件：
logs/quantum_envelope_scan.json、logs/quantum_state_factor_isolation.json。
判定标准先于数据写定于工具文件头，运行后未改。

## 一、过程事件登记（先查代码纪律）

包线工具首版的判定代码把权限符号写反（测量值取"全拍减停拍"，
判定却按"停拍减全拍"解释），首版输出的 E1 不通过与反号边界
全部作废；修正符号后重跑，本文件数据为修正版。另修正变号搜索
只捕捉单方向过零的缺陷（φ=+10 行左端负值曾被漏检）。

## 二、包线结果（密度通道，停右翼的滚转权限，牛米）

在钉配平俯仰 −13.03°、零竖直速度、零角速度、拍频 1.80 赫兹的
干净条件下，密度通道权限在整个扫描网格（坡度正负 20 度、侧滑角
负 60 至正 15 度）上几乎全部为正且量级充足（正 0.04 至正 0.12）。
E1 通过：协调转弯走廊（坡度 0 至正 10 度、侧滑负 10 至 0 度）内
权限恒正。E2 反号区只在极端左大侧滑叠加正坡度的角落出现：
坡度 +10 度时侧滑角小于负 54.4 度反号，坡度 +20 度时小于负 31.7
度反号；负坡度全域不反号。

幅值差动通道（E3 对照）：全网格量级 0.004 至 0.018，为密度通道
的十分之一量级，符号大体正确，可作细调副通道，不能作主力。

## 三、因子隔离结果（科目一日志 t=8 秒状态，权限基线 +0.0039）

| 处置 | 停右翼权限（牛米） |
|---|---|
| 原始状态（回放基线） | +0.0039 |
| 角速度清零 | +0.0026 |
| 竖直速度清零 | +0.0414 |
| 俯仰换回配平 −13.03° | +0.0544 |
| 拍频换回 1.80 | +0.0023 |
| 全部清理（包线口径） | +0.0695 |

定案：权限塌缩的主因是俯仰偏离配平（实测负 6.6 度对配平负 13.03
度）与爬升竖直速度（正 0.42 米每秒），两者各自单独解释大部分
塌缩；角速度与拍频不是原因；侧滑本身在包线内不杀权限（全部清理
组保留每秒负 3.23 米的侧滑，权限仍有 0.0695）。

## 四、对既有结论的修正与科目一失败链改写

《量子异步抽验_口径调和.md》第二层"侧滑是权限杀手"的归因作废：
真凶是俯仰与竖直速度偏离配平点，侧滑只是伴随现象。科目一失败
因果链改写为：坡度切入后高度环把拍频推上 2.2 赫兹，升力过剩
引起爬升与俯仰上抬，密度通道权限因俯仰与爬升偏离配平而塌缩，
滚转失控后侧滑发散，倾覆。t=10 秒回放中的权限反号（−0.052）
发生在俯仰已大幅正偏的状态，与俯仰归因一致。

## 五、下一步（按序）

其一，科目一重跑的配置修正：坡度段须把俯仰与竖直速度约束在
配平邻域（拍频上限 2.2 赫兹开关 BANK_FREQ_CAP 在案，加俯仰
通道保持配平前馈），判据五条不改。其二，密度通道的前馈量子
在俯仰与竖直速度两维上的调度函数须补测（包线表加俯仰维），
这决定调制器在大扰动下是否需要降权限防反号。其三，频率差动
偏航通道在环标定（判据乙三）随重跑一并执行。
