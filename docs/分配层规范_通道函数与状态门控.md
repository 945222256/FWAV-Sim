# 分配层规范：通道响应函数与状态门控登记表（2026-09-28）

本表是分配层的唯一事实来源。所有函数均为实测拟合，系数与残差在
logs/authority_fits.json 与 logs/combined_authority_map.json；
力律因子三不确定带适用于全部气动项。角度单位为度，力矩单位为牛米。

## 一、通道响应函数登记

### 通道 1：密度差动（rho，编号 46/47）

- 输入：每翼拍动密度 ρ∈[0,1]；差动量 δρ=ρ_L−ρ_R 的满额对应一翼停拍。
- 响应函数：A_ρ(θ,β,φ) = c0 + cθ·θ + cβ·β + cθβ·θ·β（牛米，满额
  停翼口径），系数分坡度 0° 与 10° 两档，见 authority_fits.json
  的 density_bilinear_phi0/phi10 条目；残差 RMS 为满额量级的
  百分之六以内。
- 标度律：对俯仰的敏感度是对侧滑的六至十八倍；零穿越线
  θ*(β,φ) = −(c0+cβ·β)/(cθ+cθβ·β)，零侧滑处约 −1.4°。
- 时标：逐拍生效，是最快通道。

### 通道 2：幅值差动（dA，编号 6）

- 响应函数：A_dA(θ) ≈ 常数加弱斜率（随俯仰略升），全程正号；
  效能口径 B_DA_3D = 0.046 N·m/rad（dA 语义，三维实测）。
- 域：±0.175 rad（建议域；±0.10 内为已验证域，超出为外推）。
- 副作用：附带偏航注入（旧口径 +0.209 N·m/rad 量级），须由滞后
  差动组合抵消（WING_MIX 在案，高频档抵消比退化在案）。

### 通道 3：滞后差动（dlag，编号 7）

- 响应函数：A_lag(θ,β,φ) 网格实测（authority_lagdiff_grid 两份
  数据）；线性安全域 ±0.02 秒内全程正号；±0.04 秒档反号禁用。
- 定性：巡航点权限与幅值通道同量级，俯仰敏感度低。

### 通道 4：尾翼差动（aileron）

- 响应函数：A_ail = b_ail(v_eff)·δ_ail，b_ail = 0.111 N·m/rad
  实测（侧滑工况横侧通道效能），域 ±0.30 rad 软件限幅。

### 通道 5：频率差动（偏航通道，不进滚转分配）

- 响应函数：ΔJ_Tz 随两翼频率差近似线性（阶段一实测），定位是
  偏航/推进通道；滚转权限不足（判据甲三不通过在案）。

### 需求函数

D(φ,β) = 4.4e-4·|φ| + 4.2e-4·|β|（牛米；第七十一班实测系数：
坡度伴生侧滑驱动矩加侧滑整流梯度）。

## 二、状态门控登记

| 门控 | 函数 | 依据 |
|---|---|---|
| G1 密度俯仰门控 | g(θ)=clip((θ_zero−θ)/(θ_zero−θ_full), 0, 1)，θ_zero=−4°、θ_full=−6°（保守缓冲，拟合零穿越 −1.4° 加不确定带） | 零穿越实测 |
| G2 频率差动包络门 | 每翼频率裁剪进 [1.0, 2.2] Hz，区间倒置时指令归零（纯函数 _freq_diff_clamp） | 失效区边界 |
| G3 尾翼速度门 | v_eff < 1.0 m/s 时尾翼通道关闭 | 物理（低速无舵效） |
| G4 试验拍频帽 | 定坡度试验内拍频 ≤ 2.2 Hz | 归因测量 |
| G5 密度死区 | δρ 绝对值小于 0.05 时双翼全拍 | 防小扰动抖动（自定） |
| G6 域界门 | dA、dlag 限幅即已验证域界，不外推 | 测量纪律 |

## 三、分配规则（待整定的只有权重）

力矩需求 mx 到通道的分配为加权逆映射：u_i = w_i · mx / eff_i(state)，
各通道按域界裁剪。eff_i(state) 取第一节的响应函数在当前状态下的
取值；响应函数值为负的通道在该状态下权重强制为零（不用反号通道）。
待整定量：四条滚转通道的权重 w_ail、w_dA、w_lag、w_rho，整定方法
见《标准整定方法_TPE分配权重.md》。
