# I-021 v1 标定器尾翼除数口径裁决（2026-09-30）

> 事项 I-021 标题为 v1 标定器尾翼贡献被采样数二百八十八除的口径缺陷
> 待裁。销项判据为按冻结约定书面关闭或登记修复方案。本文件选择前一
> 分支，为书面关闭记录。

## 一、缺陷定义与现状核验

v1 标定器指 tools/unified_search_framework.py，其周期平均函数
stroke_avg 在第 253 行的返回式把翼力与尾翼力之和除以相位采样数，把
翼力矩与尾翼力矩之和同除相位采样数。翼力与翼力矩本为逐相位点求和
再平均，除以采样数正确；尾翼力与尾翼力矩为无拍动的稳态量，单次求
值后不应再除，同除使其贡献被缩小二百八十八倍。本次销项施工当日核
验该行原文仍在，代码按原版不动约定未被修改。

缺陷影响已由配平工具对照施工完整定界，档案为
docs/配平工具对照_20260930.md。要点三条。其一，标定层静态账缺失尾
翼俯仰矩零点零三九二牛米，为升降舵权限当量零点零二九一牛米的一点
三五倍。其二，缺陷使工具甲口径的俯仰力矩曲线在两对照工况全程为
正、无力矩根，该结果由辅助根丁的空变号独立证明。其三，历史三轮
全参数搜索考卷的静态可行域结论全部经由该函数求值，含此口径缺陷；
闭环仿真核 forces_total 不经此式，六十秒巡航达成结论不受影响。

## 二、裁决

裁决为维持 v1 原版不动，缺陷按登记口径差书面关闭，不修 v1 本体，
不重算历史静态结论。裁决依据四条。

第一条，冻结约定在先。审查记档明载 v1 按原版不动约定不修改，缺陷
由主会话决定修复时机。机主把本事项按关闭判据派给本路，判据的前一
分支即按冻结约定书面关闭，本裁决执行该分支，与既有约定一致。

第二条，考卷可比性。v1 为历史考卷，其求值口径随脚本冻结。修改除
数会使全部历史静态结论失去同口径可比性，违背判据先于数据的纪律。

第三条，正确口径已有实现。闭环核无此问题；邻域重扫工具内置全量尾
翼修正；侧滑测量工具按正确写法单独实现；部署配平采用净矩根口径。

第四条，边界声明已立。配平工具对照文档第七节第三条已声明工具甲的
配平俯仰角为静态预筛内部量，不得对外引用，不得与其他口径数值直接
比较。

## 三、引用纪律

引用历史全参数搜索考卷基于 stroke_avg 的静态可行域结论时，
必须附带尾翼贡献被除二百八十八的口径缺陷标注。对外引用配平俯仰角
的唯一现行口径为部署净矩根口径，引用时给数值与口径名。此项纪律随
本裁决生效，登记入本文件与总账。
