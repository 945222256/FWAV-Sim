# I-144 控制台指挥部页面（2026-10-09）

> 事项 I-144：目标到需求到事项三级拆解树视图。依据编排控制台方案
> 第四节草图与第十四节评审并入记录。施工：L5 队。判据三条冻结于
> 事项登记。

## 一、实现

board_ui 新增 console 目录：ConsolePage 外壳（三页导航、页脚并行
额度与采样时刻、十秒轮询、断连与滞后两态）、HqView 指挥部树、
SourceMark 出处角标（十二像素回形针，悬停摘要浮层，点击开抽屉）、
SourceDrawer 出处抽屉（右滑三百六十像素，发丝线零投影，摘录十行
折叠，账本编号链接跳事项详情，复制四字段按钮）、tokens.css 全站
共享设计令牌（参数实验室三稿钉固值提炼为单一来源，控制台与实验室
同站同源）。路由 #/console，看板顶栏增"编排控制台"入口，深度链接
契约扩为七路由。层级执行评审并入记录三处：目标卡出处降为合并次要
行、需求行进度条占行宽三分之一事项数次要、明细卡点击才展开不自动
弹出。只渲染接口返回字段；目标授权记录接口未提供，明细卡如实标注
"接口未提供该字段"。

## 二、判据核验（云端实测，logs/i130_check/i144_check.js）

判据一（页面渲染与接口数据逐格一致）：同刻拉取接口与文档对象模型
比对，两张目标卡、六条需求行全部字段逐字一致，进度条宽度与接口
判据闭包比逐格一致，页脚并行额度与采样时刻与接口一致，核验输出
PASS 无差异项。

判据二（每格可开出处抽屉）：页面渲染出处角标八枚，点击开出三百
六十像素抽屉，投影计算值为 none，摘录与采样时刻齐备，账本编号
链接与复制按钮在位。

判据三（层级调整按方案第十四节落实）：明细卡默认零张、点击后一张
（不自动弹出）；进度条占行宽三分之一；目标卡授权与出处合并次要行。
