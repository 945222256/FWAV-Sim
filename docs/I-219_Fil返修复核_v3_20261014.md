## 唯一保留的阻断：求力需求表遗漏扭转角速度

编号 F08，原判据五，优先级 P2，重要程度 7/10。定位：[需求表](G:/Playground/isaac_flapper_sim/modules/motion_action/types.py:368)、[真实旋转力消费](G:/Playground/isaac_flapper_sim/modules/aero/sane_dickinson_3d.py:133)、[当前默认开关](G:/Playground/isaac_flapper_sim/config/sim_config.py:342)。

v3 的气动力需求表只登记左右拍动通道的拍动角速度，以及附加质量开启时的拍动角加速度，没有任何一行登记左右扭转通道所需的扭转角速度。实际三维力核读取 `alpha_dot`，在旋转力开启时将它用于旋转力计算；现行旋转力开关为开启。

真实函数反例固定拍动角 0.1 rad、扭转角 0.2 rad、拍动角速度 2 rad/s、拍动角加速度 0 rad/s²，机体平移和转动速度都为零。只把扭转角速度从 0 改为 2 rad/s：

- 机体系力变化为 `[0, 0, 0.06223808]` N。
- 机体系力矩变化为 `[-0.0127826163, 0.0030741260, 0]` N·m。
- 保持默认旋转力开关、将扭转角速度设为不可用，真实求力函数抛出类型异常。
- 关闭旋转力后，同一函数接受不可用扭转角速度，输出与零角速度一致。

这证明该量有真实的条件消费：旋转力开启时需要扭转角速度，关闭时不强制。它与附加质量开关控制的拍动角加速度是两个条件，不能只按附加质量开关登记全部需求。

直接影响是需求契约允许缺少一个实际必需量。后续消费者若按当前表判断动作可用，会把缺失扭转角速度的动作认作可求力，而默认真实力核无法消费。当前交付仍处于对象和接口层；本次确认的是契约与真实求力函数不一致，没有测量它对整机飞行的影响。

[交付检查器](G:/Playground/isaac_flapper_sim/tools/verify_i219_motion_action.py:117)仅检查拍动导数和附加质量开关，并在真实力核调用时固定提供有效 `alpha_dot`。因此 96 项全过未覆盖这个缺口。检查器关于扭转不进入拍动加速度行的判断可以保留，但还须另查扭转角速度需求。

## 原事项续修及通过条件

1. 在需求表中登记左右扭转通道的扭转角速度，单位 rad/s，明确当前默认三维模型及旋转力开关条件；旋转力开启且该量不可用时记为消费无效，不填假零。旋转力关闭时不强制提供。扭转角加速度和尾舵导数不因此一并强制。

3. 补真实力核反例：有效扭转角速度改变输出；旋转力开启时该量缺失使实际求力失败且契约拒绝；关闭时该量可缺失。核对附加质量开关切换不会消除旋转力开启时的需求。检查须覆盖表的完整性，不能只断言当前已登记行正确。
4. 保留 v3 已通过的修复及原冻结判据，在原二队领地提交下一版交付。没有新增事项，没有改动控制参数或气动力律。
