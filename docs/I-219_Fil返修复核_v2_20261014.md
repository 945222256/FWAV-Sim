## 第一项 逐通道策略仍被忽略或在混合前错误采用

**优先级 P1，属于原 F05 和原判据三。** 位置：[策略输入语义](G:/Playground/isaac_flapper_sim/modules/motion_action/parameters.py:206)、[翼面装配](G:/Playground/isaac_flapper_sim/modules/motion_action/parameters.py:311)、[左右尾装配](G:/Playground/isaac_flapper_sim/modules/motion_action/parameters.py:374)。

输入声明逐关节指定策略和上一采用值，但左右尾只对 `tail_L` 调用一次策略函数，随后把同一个采用值加减副翼分配给两侧。右尾策略因此完全未读；左尾“保持上一关节值”也会被再次加入副翼量，改变已经采用的关节目标。六个翼面通道的装配没有调用通道策略函数，传入这些通道的策略会被静默忽略。

真实装配反例如下，全部数值单位为弧度：

| 请求 | 依据逐关节策略应得左尾／右尾 | 实际左尾／右尾 |
| :--- | :--- | :--- |
| 升降 0.11、副翼 0.03，仅右尾归零 | 0.14／0 | 0.14／0.08 |
| 同一需求，仅左尾归零 | 0／0.08 | 0.03／−0.03 |
| 两尾保持，上一左尾 0.2、右尾 −0.1 | 0.2／−0.1 | 0.2／0.2 |
| 升降 0.11、副翼 0.03，左尾保持上一值 0.2 | 0.2／0.08 | 0.23／0.17 |

另有诊断反例：未知策略放在方向舵上会报错，放在右尾或左拍动通道却被接受。当前 77 项检查只用方向舵验证策略，漏掉这些路径。复现结果为 `right_tail_zero`、`left_tail_zero_with_aileron`、`different_left_right_hold`、`hold_left_with_nonzero_aileron` 及三条未知策略输入。

**最小修订：**先形成左右各自的原始尾舵候选目标，再对每个关节分别采用策略。上一采用值和模式退出基准须对应同一个最终关节目标，不能当作升降分量再混合。逐项校验传入的策略及其适用量；对已声明支持的通道真正执行，对未支持组合给定位结果，不能静默忽略。保留本轮已经修好的默认配平和绝对命令规则。

## 第二项 求力导数表遗漏实际必需的拍动角加速度

**优先级 P1，属于原 F08 和原判据五。** 位置：[需求表仅列速度](G:/Playground/isaac_flapper_sim/modules/motion_action/types.py:334)、[真实三维力核读取加速度](G:/Playground/isaac_flapper_sim/modules/aero/sane_dickinson_3d.py:73)、[加速度进入附加质量力](G:/Playground/isaac_flapper_sim/modules/aero/sane_dickinson_3d.py:138)、[当前附加质量开关](G:/Playground/isaac_flapper_sim/config/sim_config.py:343)。

当前求力适配器需求只登记速度，接口文字还将其描述为世界系速度。但是通道动作表示关节角，所需通道导数是对应角速度和角加速度；机身世界系速度属于另一组状态输入。

默认三维模型启用附加质量力，实际函数读取拍动角加速度并用于求力。调用这个真实函数时，速度有效但加速度为 `None` 会抛 `TypeError`。同样姿态和速度下，仅将拍动角加速度从 0 改为 10 弧度每秒平方，左翼力差约为 `(-0.069918, -0.007015, 0)` 牛，力矩差约为 `(0, 0, -0.014013)` 牛米。这是局部力核对导数的消费证据，不是飞行收益或整机响应测量。

**最小修订：**需求表按实际模型、通道和开关登记必需导数，至少覆盖当前拍动加速度消费，并区分角运动学与机身世界状态。未消费的折翼或不需加速度的通道不强制增加必需量。保留已声明近似身份，但不能把缺失量伪装为有效量；当前实现具体导数算法仍属于后续事项，本项只需把消费契约定义正确。

现检查器第 119—120 行直接要求需求表等于“只含速度”，会保护这项错误定义；应改成对照真实消费者需求。[对应检查](G:/Playground/isaac_flapper_sim/tools/verify_i219_motion_action.py:117)
