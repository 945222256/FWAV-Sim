## 第二节 记号与总架构

记号：theta 为拍动相位，周长 2*pi；u = theta/(2*pi) 为周期分数，u 属于
[0,1)；t 为时间秒；T = 1/f 为拍周期。下标 k 恒指第 k 拍频谐波（频率
k*f）。H(u) 为慢度剖面（相位每前进单位分数所需的时间份额），g = 1/H 为
快度。五个自由度记 p = (mu, A, f, s, psi)。

总架构：发生器 = 相位核 复合 输出映射。相位核负责时间与相位的关系（恒
周期调频），输出映射负责波形形状（相位的光滑函数）。两层解耦的意义：
周期语义、可微性、乘子接口全部由相位核决定；升力与力矩的形状语义全部由
输出映射决定；两层可以独立验证、独立冻结。

## 第三节 五自由度定义与现行键映射

| 自由度 | 符号 | 语义 | 现行键 | 换算 |
|--------|------|------|--------|------|
| 中置偏置 | mu | 拍动行程中心相对机体的偏角，弧度 | MEAN 与 BIAS 之和 | mu = radians(MEAN) + radians(BIAS) |
| 振幅 | A | 拍动角单侧峰值，弧度 | AMPLITUDE | A = radians(AMPLITUDE) |
| 频率 | f | 拍频，赫兹 | FREQUENCY | 相等；双翼共用（第十节约束四） |
| 上下行程不对称 | s | 正半行程占周期时间比，无量纲 | SPLIT | 相等；s 小于二分之一表示正半行程快，与现行注释同义 |
| 相位漂移 | psi | 俯仰相对拍动的相位偏移，弧度 | PITCH_LAG_S | psi = 2*pi*f*PITCH_LAG_S（定频标定点换算） |

判据文中"中置漂移"与本表第五行"相位漂移"同指（机主令原文用词为相位
漂移；两词均指俯仰通道相对拍动相位轴的中途偏移）。俯仰通道自身的幅值
a_amp 与偏置 a_bias 是通道常数（现行 FEATHER_AMPLITUDE、ALPHA_SET 族与
FEATHER_BIAS、俯仰偏置族），不属于五自由度；这样处理使五自由度恰好覆盖
判据清单，同时保留俯仰形状的通道级配置。

正半行程与负半行程的划分沿用现行相位约定：theta 属于 [0, pi) 为正半
（现行代码注释称下扑），theta 属于 [pi, 2*pi) 为负半（上扑）。相位零点
theta = 0 对应行程中点（拍动角等于 mu、指令速度最大的时刻），此零点同时
是第八节乘子接口的时间基准。

## 第四节 相位核：恒周期调频

### 4.1 定义

相位核为周期分数上的常微分方程：

    du/dt = f / H(u)
    H(u) = 1 + b1*sin(2*pi*u) + b3*sin(6*pi*u)

H 只含奇数阶正弦项，因此 H(u) + H(u+1/2) = 2 对一切 u 成立（与旧分裂
周期模板相同的半周配对不变量）。标准模板冻结为 {1,3} 两阶；更高阶不禁止，
但接口与验收按两阶声明。

### 4.2 周期精确性（定理一）

若 H 在 [0,1) 上严格正值且均值为一，则相位核的周期恒等于 1/f，与系数
取值无关。

证明：一个周期的时间 = ∫_0^1 H(u)/f du = (1/f)*mean(H)*1 = 1/f。最后一个
等号用均值一。系数空间中 mean(H) = 1 对任意 (b1, b3) 成立（正弦项整周
积分零）。证毕。

推论：判读工具的单周期状态转移矩阵假设（周期 = 1/f_stroke）由构造保证，
这是第八节乘子接口成立的前提。

### 4.3 占空比映射（定理二）

正半行程占周期时间比 s = ∫_0^{1/2} H(u) du = 1/2 + (b1 + b3/3)/pi。

证明：∫_0^{1/2} sin(2*pi*k*u) du 对奇数 k 等于 1/(pi*k)，对偶数 k 等于零；
余弦项整半周积分为零。代入即得。证毕。

记 c = b1 + b3/3 = pi*(s - 1/2)。系数冻结规则（在 4.4 可达域内）：

- 纯一阶区 |c| <= 0.9：b3 = 0，b1 = c；
- 扩展区 0.9 < |c| <= 1.1017：固定比值方向 b3/b1 = 0.19324（即可达域
  顶点方向 1.035 比 0.2），b1 = c/(1 + 0.19324/3)。

### 4.4 可达域（正值性边界）

可达域边界为 min_u H(u) = 0（硬边界，相位停摆）。运行安全线取
min_u H(u) >= 0.1（冻结值）。两阶模板在安全线内的占空比可达域为

    s 属于 [0.1493, 0.8507]（margin = 0.1 时的网格扫描值，步长 0.005）

现行工作点 s = 0.176 落在可达域内（纯一阶区之外的扩展区，系数为
b1 = -0.9562、b3 = -0.1846，此时 min H = 0.169）。旧分段模板的任意占空比
在 (0,1) 内可达，光滑族的可达域比它窄；窄化的代价声明：占空比超出
[0.149, 0.851] 的意图不属于本族，需要时可提高阶数重新预登记。

### 4.5 与旧分裂周期模板的关系

旧模板（modules/aero/kinematics.py 的 _phase_sc）是本族在以下意义下的
极限形式：H 取分段常数 H = 2s 于 [0,1/2)、2(1-s) 于 [1/2,1)，其均值为一、
占空比精确为 s，恰是本族公式在阶数趋于无穷时的阶梯极限。旧模板的速度
指令在相位零点与 pi 两处跳变（见第七节对照），本族以两阶光滑剖面替代，
占空比语义保持连续衔接。

## 第五节 Hopf 基底

### 5.1 定义

相位核与振幅自稳合成一个二维状态方程（Hopf 结构）：

    dx/dt = kappa*(A^2 - r^2)*x - (2*pi*f/H(theta/(2*pi)))*y
    dy/dt = kappa*(A^2 - r^2)*y + (2*pi*f/H(theta/(2*pi)))*x
    r = sqrt(x^2 + y^2)，theta = atan2(y, x)

输出映射取 phi = mu + y、alpha = a_amp*cos(theta - psi) + a_bias。在环
r = A 上 y = A*sin(theta)，与第四节的相位核复合输出映射完全一致。

### 5.2 径向收敛（定理三）

从任意初值 r0 > 0 出发，r 单调收敛到 A，无过冲；在 r = A 邻域径向误差
指数收缩，收缩率为 2*kappa*A^2。

证明：极坐标下 dr/dt = kappa*(A^2 - r^2)*r，右端在 (0,A) 为正、在
(A,无穷) 为负，且在 r = A 处导数 -2*kappa*A^2。单调性与收缩率直接可得。
证毕。

### 5.3 相位与半径解耦（定理四）

Hopf 基底的相位变化率 dtheta/dt = 2*pi*f/H(theta/(2*pi)) 与 r 无关；因此
幅值瞬态期间周期精确性与相位轨迹完全不受影响。

证明：dtheta/dt = (x*dy/dt - y*dx/dt)/r^2，径向项因反对称消去，剩余
(2*pi*f/H)*(x^2+y^2)/r^2。证毕。

推论：乘子接口的相位零点基准在幅值瞬态期间依然精确成立；振幅自由度的
变更不污染周期判读。

### 5.4 奇点与初值规则

向量场在原点无定义（相位角无定义，原点为排斥平衡）。初值规则：运行
初值取 (x, y) = (r0, 0) 且 r0 > 0；缺省 r0 = A（在环启动，无瞬态）。原点
属于状态空间删除集，运行不可达（定理三保证 r 一旦为正即远离零）。

### 5.5 kappa 选取公式

径向误差 e 折叠时间 tau_amp = 1/(2*kappa*A^2)。要求幅度瞬态在 N0 拍内
折叠，取 kappa = N0*f/(2*A^2)。N0 缺省三（幅度误差三拍内折叠到 e 分之
一），N0 属于整定参数，其授权域归 I-138 的指令契约。

### 5.6 约化实现

部署最小形式为纯相位积分器（相位核直接积分，r 恒等于 A），即现行
_phase_sc 的推广：把分段常数 H 换成本族光滑 H，相位作为积分状态的既有
纪律（2026-09-20 改频不跳相）原样保留。在环上两种实现的输出逐位一致；
Hopf 形式用于需要振幅自稳的场景，约化形式用于最小改动部署。

## 第六节 输出映射与导数

在环输出及其对时间的导数（闭式）：

    phi   = mu + A*sin(theta)
    dphi/dt   = A*thdot*cos(theta)
    d2phi/dt2 = A*(thddot*cos(theta) - thdot^2*sin(theta))
    alpha     = a_amp*cos(theta - psi) + a_bias
    dalpha/dt = -a_amp*thdot*sin(theta - psi)

其中 thdot = 2*pi*f/H(u)，
thddot = -(2*pi*f) * (dH/dtheta) * thdot / H^2，
dH/dtheta = b1*cos(theta) + 3*b3*cos(3*theta)。

全部量为 theta 的光滑函数与正值的 H 的商复合，闭式可积可导，伺服指令链
（位置、速度、加速度）不需要数值差分。旧实现的俯仰角速度数值差分（时间
步 1e-4 的前向差分）在本族中由闭式替代。

## 第七节 硬约束一：可微性声明

### 7.1 光滑族声明

本族（第四、五、六节）在参数 p 固定时，一切输出（phi、alpha 及其各阶
导数）关于时间是无穷阶连续可微的。依据：H 是三角多项式且在可达域内严格
正值，故 thdot = 2*pi*f/H 光滑；输出映射是 theta 的三角函数与常数仿射，
复合保持光滑。

### 7.2 参数轨迹继承声明

参数随时间变化时（控制器逐拍改写自由度），输出继承参数轨迹的正则性：
p(t) 属于 C^m 则输出属于 C^m（与相位核的 C 无穷取小）。对参数轨迹的
强制要求：连续且分拍更新（每拍边界改写一次、拍内保持常数是合法的最低
形式，此时输出属于 C 零拼接光滑段）；斜率上限（每拍允许的自由度改变量）
的数值归 I-138 契约，本文件只声明要求的形式。

### 7.3 旧模板对照（分段光滑声明）

旧分裂周期模板属于分段光滑类：phi 连续、phi 的速度在相位零点与 pi 两处
跳变，跳变量幅值为

    |delta(dphi/dt)| = A*pi*f*|2s-1| / (s*(1-s))

（现行工作点数值见验收结果文件）。该跳变在每个周期出现两次，以宽带成分
激励驱动链共振。本族在同占空比下速度指令连续，宽带激励源在指令侧消失；
同占空比两版本的谐波谱对照数值归验收结果文件。

### 7.4 停拍禁区（结构性声明）

本族输出映射不含闸门、不含钉位分支、不含任何逐拍二值调制；不对称与冲量
调制只经五个连续自由度表达。这是 I-125 教训的结构化落实：停拍亏升力的
路线在数学结构层被排除，而非被参数禁用。

## 第八节 硬约束二：与周期判读工具的乘子接口

对象工具：ltv/hss_floquet.py 与 ltv/hss_i079_adapter.py（读
logs/ident_matrix/*/matrix.json）。接口四条：

### 8.1 周期等式

matrix.json 的 f_stroke_hz 字段 = 发生器自由度 f。定理一保证单周期状态
转移矩阵的周期假设精确成立。发生器频率逐拍变更时，判读按段进行（每段
内 f 常数），复合规则见 8.4。

### 8.2 相位零点基准

判读展开式 A(t) = A0 + Σ_k [Ac_k*cos(k*w*t) + As_k*sin(k*w*t)]（w = 2*pi*f）
的 t = 0 对应发生器相位 theta = 0（第三节定义的行程中点）。发生器的 H
剖面、输出映射、事件相位全部以同一零点声明。数据侧对照：现行估计器的
相位分箱与逐拍编号同用此零点（相位作为积分状态、段起点归零的既有口径）。

### 8.3 谐波投影算子

相位周期量 Q(theta)（周期 2*pi）到判读展开式系数的换算：

    c_k = 2 * ∫_0^1 Q(2*pi*u) * cos(2*pi*k*F(u)) * H(u) du
    s_k = 2 * ∫_0^1 Q(2*pi*u) * sin(2*pi*k*F(u)) * H(u) du
    F(u) = ∫_0^u H(u') du'

推导：t = F(u)/f 与 dt = H(u)/f du 代入傅里叶系数定义。数值上以 n = 288
均匀网格矩形和实现（项目测量纪律：粗扫 72 终值 288）。发生器经此算子向
判读工具提供受波形调制的植物矩阵元素（进入 Ac_k、As_k）与输入调制深度；
判读工具本身零改动。

### 8.4 分段复合与事件相位

混合飞行分段（ltv/hybrid_flight_spec.json）的复合乘子规则维持该规范
原文：段边界携带事件发生时的相位值，各段转移矩阵按段首相位对表，复合为
后段乘衔接映射乘前段。本发生器为该规范补充的语义：事件参数中的拍相位
以第三节相位零点为基准表达。停拍类事件在本族驱动下不发生（7.4），规范
中该词汇的其他用途不受影响。

### 8.5 冲量泛函（供 I-137 的挂钩形式）

单拍单侧力矩通道 m 的冲量泛函：

    J_m(p) = ∫_0^T M_m(theta(t); p) dt = (1/f) * ∫_0^1 Mtilde_m(u; p) * H(u) du

其中 Mtilde_m 为力矩的相位函数形（由既有叶素表给出）。双翼对称对加差动
自由度（每翼独立的 mu、A、s、psi 微差）后的滚转冲量差 = 左右 J 之差。M
在可达域内关于 p 光滑（叶素表对相位与参数的依赖光滑、H 光滑正值），故小
差动下 J 差线性化有效，梯度由上式对 p 求偏导获得；数值与剂量归 I-137。

## 第九节 硬约束三：驱动器带宽对拍内谐波的过滤量核算

### 9.1 链模型

沿用冻结规范（ltv/hss_spec.json 执行链条文）：G(w) = wn^2 / (wn^2 -
w^2 + j*2*zeta*wn*w) 再乘 exp(-j*tau_d*w)。幅值通过率

    R_k = wn^2 / sqrt( (wn^2 - (2*pi*k*f)^2)^2 + (2*zeta*wn*2*pi*k*f)^2 )

延迟只转相位不衰减幅值。名义参数取现行在案辨识集（I118 系数集六通道：
共振频率 2.488 至 2.542 赫兹、阻尼比 0.05 至 0.70、纯延迟 0.021 至 0.115
秒），机主给定的核算口径对（带宽 2.4 赫兹对拍频 2 赫兹）与该辨识集
同源。

### 9.2 逐自由度的过链账

- mu（零频）：R_0 = 1 精确通过，无相移；阶跃式偏置改写受链瞬态斜率限制，
  归 I-138 斜率契约。
- A（基波载体）：翼面有效振幅 = R_1 乘指令振幅。共振频率与拍频之比落在
  1.1 至 1.3 带内且阻尼比小于约零点五八时 R_1 大于一（共鸣抬升）；在案
  辨识集拍动通道的阻尼比跨该线两侧，抬升与压低并存，抬升幅度与台架摆幅
  比口径同源互证（现行在案摆幅比即 R_1 的实测形）。
- f（频率）：平移全部谐波在链响应曲线上的采样位置，R_k 随 f 单调重排；
  拍频向共振频率靠近时基波抬升与高次抑制同时加强。
- s（不对称）：调频把能量从基波散布到高次（占空比越偏散布越宽），高次
  被链过滤，故翼面实收的不对称小于指令不对称；散布量与过滤量的数值表
  归验收结果文件。剂量工作必须在翼面实收口径下进行（此为本核算的第一
  设计后果）。
- psi（相位漂移）：每谐波各自获得链相移 arg G(k*w)（含延迟项 -k*w*tau_d），
  翼面实收相位漂移 = psi + arg G_alpha(k) - arg G_phi(k)（俯仰链与拍动链
  参数逐通道不同）。在案辨识集两链参数差给出的实收漂移修正量数值归验收
  结果文件。

### 9.3 设计意图载波声明

设计意图只许搭载在第一与第二谐波（k 属于 {1, 2}）；第三及以上谐波声明
为不可送达（名义链下 R_3 不超过 R_2 的一半、逐次递减）。依据：9.2 各条
与验收结果文件的通过率表。该声明把 I-137 的剂量空间限制在链能复现的
形状子空间内，防止对被过滤形状分量做无效寻优。

### 9.4 与旧模板的指令侧宽带对照

旧模板每周期两次速度跳变的宽带成分在链共振频率邻域的激励量，与光滑族
同占空比下同频段的激励量，两者对照数值归验收结果文件；本族在指令侧
消除了该宽带源（结构差异，不是参数差异）。

## 第十节 稳定边界接口总表

| 边界 | 内容 | 后果 |
|------|------|------|
| 一 | 正值性 min_u H(u) >= 0.1（安全线），硬边界为零 | 越界则相位停摆、周期失效、乘子接口失效 |
| 二 | Hopf 径向：收缩率 2*kappa*A^2，初值 r0 > 0，原点为删除集 | 振幅指令阶跃无过冲单调收敛；瞬态期间相位不受污染（定理四） |
| 三 | 参数轨迹连续性：p(t) 属于 C 零以上，斜率上限归 I-138 | 自由度逐拍改写合法；拍间跳变违反本接口 |
| 四 | 双翼频率共用量：f 不得左右差动 | 差频导致相位差无界累积、翼间相干性丧失 |
| 五 | 俯仰链与拍动链参数逐通道独立 | 实收相位漂移修正必须逐通道核算（9.2 第五条） |
