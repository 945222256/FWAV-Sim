# I-173 理论步骤供式：七步工序第三步至第六步的公式、判据与验收阈值

供式队伍：L4（周期时变与混合飞行线，事项 I-172 名下交付，供 I-173 使用）。
接收队伍：L2（工序建设与持有）。接口契约见文末。复用资产：I-102 三通
道线性化工具（ltv/hss_i102_stab.py）、I-079 周期判读工具
（ltv/hss_i079_adapter.py）、I-047 判读核（ltv/hss_floquet.py）。

## 第三步：模态分解

**输入**（承接第二步线性化产出的状态矩阵 A，n 乘 n 实矩阵，配平点标
签与状态名清单齐备）。

**公式**：特征分解 λ_i, v_i = eig(A)。连续时间读数：阻尼比
ζ_i = −Re(λ_i)/|λ_i|，固有频率 ω_i = |λ_i|（弧度每秒），报告频率
f_i = ω_i/(2π)（赫兹）。模态归类按 ζ 与 f：ζ≥1 过阻尼实模态；
0<ζ<1 振荡模态；ζ<0 不稳定模态；|Im(λ)|<10⁻³ 判非振荡。模态通道归
属按特征向量最大分量对应的状态名。

**判据**：全部 Re(λ_i)<0 判稳定；任一 Re(λ_i)≥0 列入不稳定清单并给
通道归属与主导分量。

**验收阈值**：本步无阈值判定（描述性步骤），产出表必须含 λ 实部虚
部、ζ、f、通道归属五列，逐模态一行，不稳定模态置顶。

## 第四步：可控性与可观性（含格拉姆矩阵）

**输入**：A，输入矩阵 B（n 乘 m），输出矩阵 C（p 乘 n），采样窗长 T
（默认取主导模态时间常数的五倍）。

**公式**：可控格拉姆矩阵 W_c = ∫₀ᵀ e^{Aτ} B Bᵀ e^{Aᵀτ} dτ（用矩阵
指数级数或增广矩阵指数法计算，禁止离散近似除非声明步长与误差）。
可观格拉姆矩阵 W_o = ∫₀ᵀ e^{Aᵀτ} Cᵀ C e^{Aτ} dτ。秩判据用
rank([B, AB, …, A^{n−1}B]) 与 rank([C; CA; …; CA^{n−1}]) 交叉验证。
模态级判据：对每个特征值 λ_i，左特征向量 w_i 满足 w_iᵀB=0 判该模态
不可控；右特征向量 v_i 满足 Cv_i=0 判不可观。最小能量读数：
ε_i = 1/√(w_iᵀ W_c w_i)（把第 i 模态激励到单位能量所需的最小输入能
量倒数量度）。

**判据**：任一模态不可控且不稳定判严重缺陷（控制无法触及该模态，参
照 I-172 合成上反角判不可行的同类机理：发散源方程无控制输入项）；
可控但 ε_i 高出均值两个数量级以上判弱可控（工程上视作近似不可控并
报数）。

**验收阈值**：格拉姆矩阵条件数不超 10¹² 为数值可信线（超过须换双精
度增广法复算并声明）；不可控且不稳定模态数必须为零，否则整条链判不
通过。

## 第五步：稳定裕度

**输入**：开环传函矩阵 L(s) = C(sI−A)⁻¹B 加回路传函（单回路用
L(s)=C(sI−A)⁻¹B·k 回路增益形式；多回路按通道逐个断开）。

**公式**：增益裕度 GM = 1/|L(jω_π)|，ω_π 为相位穿越频率（相位等于
−180 度）；相位裕度 PM = 180° + ∠L(jω_c)，ω_c 为增益穿越频率
（|L|=1）。拍频系统的裕度在谐波域按 I-044 规范的边带耦合路径口径计
算（传函矩阵在 s_j 加减 k 倍拍角频率各边带展开后取中心频点），本步
允许用拍平均 A 的单频点近似，近似声明必须随报告。

**判据**：经典最低要求 GM ≥ 6 dB 且 PM ≥ 30°（对应开环增益翻倍与
附加 30 度滞后仍稳定）；对近零阻尼共振模态（ζ<0.05）另加共振峰判据：
共振频点拍平均增益不超 10 dB，超过判激励将泵能（轮五十二边带陷波系
数错教训的在案形态）。

**验收阈值**：GM≥6 dB 且 PM≥45° 判裕；GM≥6 dB 且 30°≤PM<45° 判贴
线（必须附数值）；任一不达标判不通过。共振峰超 10 dB 单独列缺陷不
随裕度合算。

## 第六步：周期口径复核

**输入**：配平点的周期状态矩阵族 A(t) = A0 + Σ_k [Ac_k cos(kω_stroke t)
+ As_k sin(kω_stroke t)]（有周期项时）或常数 A0（无周期项时），拍
频 f_stroke，工具为 I-079 判读核。

**公式**：单周期状态转移矩阵 Φ(T) 由四阶龙格库塔积分（步数四千）。
周期增长倍率 μ_i = |eig(Φ(T))|，弗洛凯指数实部 σ_i = ln(μ_i)/T。
拍平均口径的对照读数由常数矩阵特征值直接换算 σ = Re(λ)。

**判据**：max μ_i < 1 判拍周期内稳定；μ_i ≥ 1 判增长并给每拍百分比。
拍平均口径与周期口径的差值超 20% 时两口径并列报告（差异本身是周期
调制重要性的量度，I-084 稳定段判别实验的方法先例）。

**验收阈值**：工具精度门沿用 I-047 冻结值（解析例倍率相对误差不超
1%、指数实部绝对误差不超每秒 0.02，I-079 已按机器精度达标）；判读
门为 max μ_i < 0.999 判稳定、0.999 至 1.001 判近中性（报数并提示
裕度薄，I-079 二度坡度批先例）、≥1.001 判增长。

## 接口契约（L2 冻结用）

1. 输入文件：JSON，键 state_names（字符串数组）、A、B、C（二维数
   组）、f_stroke_hz、trim_label、periodic（可选，含 Ac 与 As 数组
   族）；缺键整链拒绝，不提供静默默认。
2. 输出文件：JSON，键 modes（第三步表）、gramian（第四步含
   controllable_index 与 modal_eps 数组）、margins（第五步含 GM_dB、
   PM_deg、resonance_peak_dB 与判读词）、floquet（第六步含 mu 数组
   与 re_per_s 数组与判读词）、verdict（四步合并判读词：过、贴线、
   不过，贴线必须附数值）。
3. 工具绑定：第三四步允许 scipy.linalg 与 numpy；第五六步绑定
   ltv/hss_floquet.py 与 ltv/hss_i079_adapter.py，L2 只做管线收编
   不改内核公式。
4. 首次正式执行（十度横侧可控性）的预期读数方向：I-102 已判十度存
   在侧滑主导不稳模态且发散源方程无控制输入，本工序第四步应独立复
   现该判（不可控且不稳定模态非零），这是工序上线即抓到真问题的验
   证样例。

供式背书：以上公式与判据由 L4 队按在案工具与冻结规范编写，数值出处
可溯（I-102 提交 8a63308、I-047 提交 0f4ed9c、I-079 提交 7d105ac），
L2 冻结接口后本文件为理论部分的唯一权威源，改动须经 L4 复核。
