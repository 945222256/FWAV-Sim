# I-067 机主说明（2026-10-04，L2 关单附页）

## 做了什么

三件事。第一，对该事项的链路断裂定性做了逐环节查证：读取一队当天三次采集的原始数据流，确认第一跑的指令恒零源于发射即坠后的接地联锁，二三跑的滚转指令实际到达过十度目标值，链路断裂的原定性不成立。第二，新增坡度链路纯 Python 自检工具，四条检验覆盖关闭态、开启到达、斜坡率保真与阶跃对照、俯仰保持联动，全部通过，链路自检从此可进自动检查。第三，修复查证中发现的真缺陷：坡度试验开启而斜坡率未显式给出时，配置默认阶跃档被静默继承，直跑启动器漏带斜坡率键即降级成阶跃切入，违反冻结配方与历史在环教训的斜坡处方；修复后默认取冻结配方值每秒零点二五弧度并打印回显，显式给出时以显式值为准。

## 结果是什么

复现采集跑按一队直跑的漏带条件执行，修复生效实锤：运行日志出现默认斜坡回显，滚转指令以精确的每秒零点二五弧度在五点七秒爬到十度目标，与自检预测时刻吻合，坡度分量保持到坠地。链路侧验收全过。

## 为什么

该事项是一队盘旋数据采集与科目一的共同依赖。链路不通则采集被堵；斜坡被静默降级则切入形态违反冻结配方，采集数据与配方声明不符。修复把配方声明、环境键、配置、控制器指令四层焊成一条保真链，消除静默降级路径。

## 下一步
