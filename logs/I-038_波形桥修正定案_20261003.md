# I-038 波形环境桥顺序缺陷：修正定案（2026-10-03，L2 施工）

## 一、结论先行

原缺陷表述「力模型从未收到波形覆盖参数」经六跑在环对照与纯 Python 探针检验后修正为：**波形六键在旧树上分四条通道生效，其中力模型的波形形状参数确实失效，但幅值与频率两条通道一直是活的；失效的部分经关节路径间接漏进物理，形成力与运动不一致的混合工作点。**修复仍属必要且已生效，两轮工作点迁移在环验证的结论仍不可信，重跑要求维持。

## 二、修正后的通道账

旧树（提交 810ed15 的父提交 d69a214）上六个波形键的实效：

| 键 | 力模型通道 | 实效 |
|---|---|---|
| FLAPPER_WAVE_FREQ | 每步同步（驱动线把控制器频率写进模型两翼） | 一直生效 |
| FLAPPER_WAVE_AMP | 每步驱动线读取配置类属性后直接写模型两翼幅值 | 一直生效 |
| FLAPPER_WAVE_SPLIT | 翼构造函数体读取，构造发生在桥之前 | 力模型失效；经关节运动学对象（桥后构造）改变扭转程序，经关节质量耦合间接进物理 |
| FLAPPER_WAVE_LAG | 同上构造期读取 | 力模型失效；偏航抵消通道激活时经每步滞后写入进力模型 |
| FLAPPER_WAVE_MEAN | 构造期读取 | 力模型失效，无其他通道 |
| FLAPPER_WAVE_ALPHA | 模块导入期固化的默认参数 | 力模型失效，无其他通道 |

纯 Python 探针证据：旧树上构造翼实例后改配置类属性，实例的分裂比保持旧值，翼态逐位不变，构造后的翼对类属性完全聋。

## 三、六跑对照实验证据

六跑全部为十五秒标准锁运行，档案按元数据标签定位（教训：ident_latest 指针在并行施工下有竞态，本次 D 跑的指针捕获曾被隔壁 30 秒窗采集覆盖，档案定位一律以 sidecar 标签为准）。

| 跑 | 树 | 环境 | 升力均值牛 |
|---|---|---|---|
| A | 现 HEAD | 默认 | 2.1069 |
| B | 现 HEAD | 幅值 25 | 2.1060 |
| C | 旧树 | 幅值 25 | 2.1059 |
| D | 旧树 | 默认 | 2.1067 |
| EO | 旧树 | 分裂比 0.30 | 2.1084 |
| EN | 现 HEAD | 分裂比 0.30 | 2.0995 |

关键比对：

1. D 对 A 零差异列。默认路径物理跨提交逐位稳定，两树之间无漂移。
2. C 对 D、B 对 A 自首行起力列即不同。幅值覆盖在两棵树上都直达力模型，通道账第一二行实证。
3. EO 对 D 的首差行只出现在关节角列（扭转程序带分裂比新值），力列自第四十四行起以末位数字级差异进入并放大。分裂比在旧树上经关节路径间接漏进物理，通道账第三行实证。
4. EN 对 A 自首行起力列即不同。新树上分裂比直达力模型，修复生效实证。
5. EN 对 EO 有差异。同一分裂比覆盖在两树上物理不同，旧树是关节耦合的间接混合态，新树是力模型直达的正确态。

## 四、对两轮迁移验证结论的影响

两轮工作点迁移在环验证实际跑的是混合工作点：控制器增益、频率、幅值是新值，力模型的波形形状（分裂比、滞后、均值、攻角）是旧值，关节视觉是新波形。升力与配平表现由力模型主导，因此「迁移无效」的原结论缺少力模型侧证据，不可信，须用修复后的桥重跑出新结论。重跑要求维持。

## 五、回归不退步证明

1. 默认路径：D 对 A 零差异列，即修复提交前后不设波形变量时物理逐位不变；此前 T6BR 门已证同一命题。
2. 基准套件：每次提交后自动运行的快档（契约自检加悬停基准）持续全绿；巡航与盘旋科目分数与修复前同族无退步。
3. 修复代码本身的默认路径等价另有两道在环门背书（T6BR、T6M）。

## 六、移交 L1 的重跑配方

用声明式实验管线重放，配置要点：场景为命令 g 盘 python.bat 加 main_sim.py，模式 isaac，时长按原验证口径；参数节带原两轮迁移的全套波形键（FLAPPER_WAVE_FREQ、MEAN、SPLIT、LAG、AMP、ALPHA）与其余原验证开关；锁节声明 standard；判据节按原验证的判据来源。摘要登记后一条命令重放。原验证的开关取值在转弯线终账第十节，由 L1 按原值填入。

## 七、遗留微发现

两树同幅值覆盖的对拍 B 对 C 自首行起存在力列末位级差异，默认态下两树逐位相同，即合并施工在覆盖态下引入了未定源的细微差别，不影响主线判定，登记备查不作立项。
