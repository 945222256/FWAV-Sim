# 失败形态

形态为释放即欠升下沉，随后进入地面接触带滞留。释放后高度自三米单调下行，六秒起
高度在零点二一至零点三六米带内小幅起伏至窗尾，竖直速度均值近零，拍频自一点九赫兹
爬升至二点七赫兹附近，前向速度全程保持在四点三至四点六米每秒，姿态角始终在带内。
该形态与模拟后端基准的同判据通过形态不同，模拟侧在相同钉版下升力比为一点零零零二
且高度保持三米。

失败形态含一项必须完整登记的簿记事实。本数据流 Fz 列记录的是气动回调单次触发的施
加值，而本配置下气动回调每个物理步恰好触发两次，因此 Fz 列读数恰为每步施加合计量
的二分之一。证据为钳位前原值列 Frz 与 Fz 列之比的中位数在全部时间窗均为二点零零零
零，且全程零触限。按每步合计口径换算，飞行窗平均合计量约为体重的一点零零零七倍。
判据二的冻结文本定义升力为每步施加的世界系气动合力竖直分量，模拟后端的
last_F_world 属性即每步全额施加值，Isaac 后端的同名属性为单次触发值，两后端在该属
性的每步语义上存在二倍差。本次裁定严格按冻结口径以 Fz 列计，不改判据，不因换算口
径改判。

# 场景钉版一致性核对

本次施工被允许分析的层面为场景钉版是否与模拟侧完全一致，核对结果为一致，共四项。

第一项为气动模型类。Isaac 侧经桥接覆写后，modules/aero_solver 的工厂函数
create_aero_callback 对 sane_dickinson 名走本模块 AeroPhysicsCallback 分支，构造
FlapperAeroModel 冻结版。模拟后端 MockBackend 的 build_aero_model 对同名构造同一
类。两类实例化的是同一模块的同一类。

第二项为桥接生效时序。覆写发生在气动回调注册之前，运行日志行号顺序为五百八十五覆
写行先于五百八十六注册行。

第三项为释放初始状态。两侧均读 config 现值，位置零零三点零米，俯仰负零点一四三二
四六弧度，前向速度三点九五米每秒，拍频初值一点八赫兹。

第四项为标准锁与标注。运行按铁律三全量携带标准锁与标注环境变量，标注
FLAPPER_TAG 为 T6X_ISAAC，已随数据流旁挂元数据落盘。

# 更正附录：升力列口径对齐与重评结果

首版裁定按 Fz 列计判据二得零点五零零四而判不通过。经核，Fz 列为气动回调单次触发
值，本配置下回调每物理步触发两次，每步合计为 Fz 列两倍，Frz 列即每步合计，全窗
两列之比中位数为二点零零零零，与 docs 任务二垂直动量账归因文档定案的点火率分摊
口径互证。判据二的冻结定义为后端每物理步施加的气动合力竖直合计分量，与提交
e365142 模拟后端基准文件头逐字一致，首版评估取列与该定义不符，属实现取列错误而
非判据变更。评估器已改取 Frz 列并对同一份数据流重评，判据二重评为一点零零零七，
三条判据全部通过，总结论为 Isaac 侧悬停基准通过。首版误读结果保留于本文件上文，
口径裁决登记为事项 I-027。更正后的双后端状态为：模拟后端半边与 Isaac 后端半边
对同一组冻结判据全部通过，同一 FlightController 类未加修改。
